# obsidian-vault-doctor

## 原则

这是只读诊断，不自动删除、移动、重命名或修复笔记。先读 `.obsidian-cc/knowledge-map.md`，按真实映射工作；没有映射就扫描全库结构但不猜目录语义。

## 检查项

1. 检索覆盖：索引是否缺失/陈旧，KnowledgeMap 排除范围是否符合预期。
2. 链接健康：断链、孤儿笔记、重复或近似标题。
3. 知识复用：长期未触达但与近期活跃主题相关的旧笔记。
4. 审核积压：统一知识审核中心中待处理/已接受未应用的候选（只能报告，不能代替用户确认）。
5. 结构卫生：异常大文件、命名不一致、明显空笔记；只给证据和建议。

## 输出

默认只在对话里给：概览、按影响排序的问题、证据路径、建议下一步。用户明确要求保存时，只写 KnowledgeMap 已映射的“生成产物”位置；未映射就先问，不创建 `reports/`。

## 禁区

- 不改任何用户笔记或附件。
- 不把诊断结果当长期知识候选。
- 不使用 legacy review/apply 管线；候选统一指向知识审核中心。
