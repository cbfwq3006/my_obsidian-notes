# 岗位工作项目总表_模板

> 用途：承接 [[祝文娟个人能力树_录音版]] 的第一阶段训练，把手上所有工作先倒出来。先粗后细，不求一次完美。

---

## 使用方法

1. 先把想到的工作项目全部填进去，不要纠结分类。
2. 每个项目只要先填 3 项：触发时间、输出结果、当前痛点。
3. 后续再补输入材料、资料入口、是否可 skill 化。
4. 能重复发生的事项，优先做 skill。

---

## 本周填表要求

- 至少补充到 20 个工作项目。
- 每个项目先填“触发时间、输出结果、当前痛点”。
- 标出最值得优先 skill 化的 3 个项目。
