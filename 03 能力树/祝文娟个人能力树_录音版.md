# 祝文娟个人能力树_录音版

> 构建依据：2026-07-16 私教首次沟通录音转写。
> 核心目标：把零散的 AI 使用、党建工作经验、资料整理经验，沉淀成可复用的工作系统；在本职工作做好的前提下，逐步实现顺利下班。

---

## 一、根：我的真实目标

### 结果目标

把本职工作做扎实，不靠长期加班硬扛，逐步做到“工作质量不下降、重要事项不遗漏、材料不反复返工、能相对准点下班”。

### 当前卡点

1. 工作范围太大：党建部核心岗，党建、工会、材料、考核、提醒、台账、检查都要参与。
2. 资料太散：发文、收文、钉钉、邮件、飞书、日报、各类台账分散在不同入口。
3. AI 已经能用，但偏“点状使用”：能帮忙写材料、查资料、做提醒，但没有按岗位工作项系统沉淀。
4. 脑子容易乱：不是不会做，而是工作项、资料、skill、逻辑框架没有统一盘清。
5. 有完美主义倾向：想一次做好，容易迟迟不行动；skill 需要先粗后细、边跑边迭代。

## 二、总树干：四项训练主线

私教沟通中确定的主策略是：**子弹驱动系统沉淀**。

意思是：不要先追求完美体系，而是从真实任务出发，把每一次具体工作当成“子弹”，打完一发就沉淀一次 SOP、skill、模板、清单，系统自然长出来。

| 训练主线 | 解决什么问题 | 近期成果 |
| --- | --- | --- |
| 1. 能力树和知识体系系统化 | 先把我到底要练什么看清楚 | 本页能力树、能力树总览、角色树 |
| 2. 岗位业务梳理 | 把手上的事盘清楚，不发散 | 工作项目清单、年度党建导航 |
| 3. AI/Skill 应用与迭代 | 把点状 AI 用法沉淀成固定 skill | 每个工作项至少 1 个可调用 skill |
| 4. 逻辑与思维能力训练 | 解决“想不清楚、说不清楚、写不系统” | 汇报结构、材料框架、问题拆解能力提升 |

## 十、第一阶段训练计划

### 第1周：岗位工作项目总盘点

输出物：`岗位工作项目总表`

至少列出：

- 工作项目名称
- 触发时间
- 输入材料
- 输出结果
- 常用资料入口
- 能否 skill 化
- 当前痛点

### 第2周：选 3 个高频事项做 skill

建议优先：

1. 督导材料拆解 skill
2. 完成情况撰写 skill
3. 支部学习计划核查 skill

### 第3周：建立年度党建导航

按 1-12 月梳理固定事项、固定材料、固定口径、固定截止时间。

### 第4周：训练 skill 迭代

每次 AI 输出不满意，不只是手改，而是记录：

- 初稿哪里不对
- 我怎么改的
- 以后 skill 应该增加什么规则
