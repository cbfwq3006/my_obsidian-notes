# 党建方向能力树

> 构建依据：YouCore《能力树（框架）搭建指南》截图。
> 核心规则：能力树不是把知识按专业领域塞进仓库，而是围绕“党建岗位要把工作做好”，拆成 **素质、能力、技能、知识** 四层，并且从具体工作任务自下而上提炼。

---

## 一、搭建原则

截图里的核心要求可以简化成三句话：

1. **不要只按知识分类**：如果只把党建资料分成“理论知识、制度知识、材料知识”，工作时还是不好找、不会用。
2. **要围绕岗位工作搭建**：先问“我党建岗位到底要做哪些事”，再拆每件事需要哪些步骤、技能和知识。
3. **一级分类用素质、能力、技能、知识**：这样不会漏掉“细致、责任心、政治敏感性、逻辑能力”等真正影响结果的部分。

---

## 二、党建能力树总框架

```text
党建方向能力树
├─ 素质：做党建工作必须长期具备的底层品质
├─ 能力：跨场景迁移的思维和处理能力
├─ 技能：可以通过训练掌握的具体操作方法
└─ 知识：支撑技能运行的制度、理论、案例和工具
```

---

## 三、素质层：决定党建工作能不能做稳

| 素质 | 在党建工作中的表现 | 当前训练方式 |
| --- | --- | --- |
| 政治敏感性 | 知道哪些材料、表述、口径不能随便写 | 重要材料定稿前做口径检查 |
| 责任心 | 截止时间、报送事项、支部问题不遗漏 | 每日工作日报+飞书提醒 |
| 细致严谨 | 考核数据、支部评分、台账完成情况不出错 | 重要表格双重复核 |
| 服务意识 | 不只催报材料，还帮助支部知道怎么改 | 问题反馈时同步给模板和标准 |
| 保密意识 | 对党委会、干部、整改、考核资料有边界 | 文件分类、权限和外发检查 |
| 求真务实 | 不写空话，不为了材料而材料 | 所有成效都匹配佐证材料 |
| 学习耐心 | 党建制度多、变化快，能持续补课 | 每月沉淀一个制度卡片 |

---

## 四、能力层：决定党建工作能不能做清

| 能力 | 解决的问题 | 对应党建场景 |
| --- | --- | --- |
| 结构化思维能力 | 事情多时不乱，能分层分类 | 年度党建导航、能力树、汇报框架 |
| 需求拆解能力 | 上级一句话要求，能拆成材料清单 | 督导检查、考核报送、专项材料 |
| 问题诊断能力 | 能判断支部问题到底是缺频次、缺质量还是缺闭环 | 三会一课检查、党建考核 |
| 统筹推进能力 | 多条线并行时能抓节点、抓责任 | 学习教育、七一表彰、整改台账 |
| 材料表达能力 | 能把做过的事写成机制、成效和经验 | 总结、汇报、通报、简报 |
| 沟通协调能力 | 让支部、部门、领导知道各自要做什么 | 催办、反馈、提醒、协同报送 |
| 复盘迭代能力 | 每次报送后能沉淀模板、清单、skill | skill 更新、模板优化 |
| AI驾驭能力 | 把 AI 变成工作系统，而不是临时问答 | 日报、材料初稿、核查、归档 |

## 五、技能层：党建岗位要练成的操作手册

### 1. 政治建设技能

| 技能 | 关键步骤 | 输出物 |
| --- | --- | --- |
| 第一议题材料准备 | 收集上级精神→提炼学习要点→形成议题材料→留痕归档 | 第一议题材料、学习清单 |
| 中心组学习组织 | 定主题→备材料→发通知→组织学习→整理记录 | 学习方案、记录、总结 |
| 正确政绩观学习教育 | 学习安排→查摆问题→制定台账→督促整改→总结成效 | 问题清单、整改台账、汇报 |
| 党课材料审核 | 看主题→看联系实际→看问题检视→看整改措施 | 审核意见、修改稿 |

### 2. 组织建设技能

| 技能 | 关键步骤 | 输出物 |
| --- | --- | --- |
| 三会一课检查 | 下载记录→核对频次→核对主题→核对质量→形成问题清单 | 核查表、问题反馈 |
| 主题党日安排 | 明确主题→下发通知→收集资料→检查执行→形成通报 | 通知、资料包、通报 |
| 发展党员流程管理 | 申请→积极分子→发展对象→预备党员→转正 | 发展党员导航、材料清单 |
| 组织生活会管理 | 前期学习→谈心谈话→对照检查→批评整改→材料归档 | 全套模板、整改台账 |
| 支部换届指导 | 任期核查→请示批复→选举组织→结果备案 | 换届材料包 |

### 3. 考核督导技能

| 技能 | 关键步骤 | 输出物 |
| --- | --- | --- |
| 考核指标拆解 | 读指标→拆标准→列证据→定评分口径 | 指标拆解表 |
| 支部材料核查 | 收材料→按项核对→标问题→人工复核→反馈支部 | 核查清单 |
| 党建考核评分 | 定规则→采数据→打分→复核→形成排名 | 评分表、排名表 |
| 考核通报撰写 | 总体情况→主要问题→原因分析→整改要求 | 考核通报 |
| 督导材料准备 | 拆上级要求→找佐证→建目录→补缺项→打包报送 | 督导材料包 |

### 4. 整改闭环技能

| 技能 | 关键步骤 | 输出物 |
| --- | --- | --- |
| 问题清单管理 | 收集问题→分类分级→明确责任→设定时限 | 问题清单 |
| 整改台账填报 | 问题→原因→措施→进展→成效→佐证 | 整改台账 |
| 完成情况提炼 | 从日报和文件中找做了什么→提炼机制→匹配佐证 | 完成情况表述 |
| 回头看复核 | 对照原问题→查整改证据→判断是否销号 | 销号清单 |

### 5. 宣传思想技能

| 技能 | 关键步骤 | 输出物 |
| --- | --- | --- |
| 宣传选题策划 | 找节点→找人物→找场景→找亮点 | 选题表 |
| 简报通讯撰写 | 事实→意义→做法→成效→下一步 | 简报、通讯稿 |
| 党建品牌提炼 | 场景→问题→做法→机制→成效 | 品牌案例 |
| 意识形态材料整理 | 收集情况→分析风险→形成总结→提出措施 | 意识形态报告 |

### 6. 材料工程化技能

| 技能 | 关键步骤 | 输出物 |
| --- | --- | --- |

| 工作总结 | 做了什么→成效如何→问题在哪→下步怎么干 | 季度/半年/年度总结 |

| 技能 | 关键步骤 | 输出物 |

## 六、知识层：党建技能背后的弹药库

| 知识类别 | 要积累什么 | 放在哪里 |
| --- | --- | --- |
| 理论知识 | 习近平新时代中国特色社会主义思想、正确政绩观、国企党建要求 | 理论学习卡片 |
| 制度知识 | 党章党规、发展党员细则、基层组织工作条例、党内组织生活制度 | 制度汇编 |
| 公司知识 | 集团、省公司、市公司重点部署、年度工作会议精神 | 公司战略与重点任务 |
| 考核知识 | 党建考核指标、评分规则、优秀案例、常见扣分项 | 考核指标库 |
| 材料知识 | 通知、总结、报告、通报、简报、谈话稿写法 | 材料模板库 |
| 证据知识 | 什么材料能证明什么工作已经完成 | 佐证材料映射表 |
| 工具知识 | Obsidian、飞书、钉钉、Excel、Word、Codex、Skill | AI工具知识库 |

## 八、第一阶段训练路径

### 第一步：先画党建全年运行导航

按月份列出固定工作：

| 月份 | 固定事项 | 输出物 | 对应技能 |
| --- | --- | --- | --- |
| 1月 | 支部书记述职、年度党建考核收口 | 述职报告、考核通报 | 考核督导、材料写作 |
| 2月 | 组织生活会、民主评议党员 | 对照检查、整改清单 | 组织建设、整改闭环 |
| 3月 | 评优评先、主题实践活动 | 推荐表、通报、宣传稿 | 宣传思想、组织推进 |
| 4-6月 | 一季度考核、学习教育、半年总结 | 考核通报、台账、总结 | 考核督导、政治建设 |
| 7月 | 七一表彰、二季度考核、发展对象培训 | 表彰材料、考核材料 | 组织建设、宣传思想 |
| 8-9月 | 党员教育培训评估、党建品牌提炼 | 自评报告、案例 | 党建融合、材料工程化 |
| 10-12月 | 年终考核、年度总结、下一年计划 | 总结、计划、材料包 | 统筹推进、证据整理 |

### 第二步：每个固定事项拆成操作步骤

只要能写出步骤，就能变成 SOP。

### 第三步：每个 SOP 补知识和能力

不要只写“会做什么”，还要补“为什么这么做、依据是什么、容易错在哪里”。

### 第四步：高频 SOP 变成 skill

优先顺序：

1. 督导材料拆解 skill
2. 完成情况撰写 skill
3. 支部学习计划核查 skill
4. 党建考核通报 skill
5. 发展党员导航 skill
