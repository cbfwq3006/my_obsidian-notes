# 立足岗位做贡献 服务发展当先锋工作沉淀

本文件夹用于沉淀“立足岗位做贡献、服务发展当先锋”主题实践活动的季度推进方法、支部操作指引、二季度催报过程、钉钉一对一通知流程和可复用模板。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `01_季度推进SOP.md` | 每季度如何从“催表”转为“定题、领题、破题、评题”的标准流程。 |
| `02_DWS钉钉一对一通知SOP.md` | 如何用党务人员明细表，通过 DWS 批量发送钉钉单聊通知。 |
| `03_通知话术模板.md` | 可直接复用的二季度催报、三季度启动、逾期提醒话术。 |
| `04_2026年二季度发送复盘.md` | 本次 2026 年 7 月 20 日实际发送过程、问题和处理结果。 |
| `tools/send_dingtalk_notice_from_party_staff.py` | 可复用脚本模板：读取党务人员表、匹配钉钉用户、发送单聊消息、输出结果表。 |

## 使用原则

1. 先把活动翻译成支部能执行的动作，再催材料。
2. 一对一通知前必须先生成预览或发送结果表，避免误发。
3. 手机号匹配失败时，可用姓名搜索补发；姓名搜索无结果或结果不唯一时，不发送。
4. DWS 发消息前必须确认登录状态、行为授权和通知正文。
5. 每次批量发送后保留结果表，作为过程痕迹和问题复盘依据。
