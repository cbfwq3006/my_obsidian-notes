## 固定表述口径

| 事项 | 可复用口径 | 使用位置 |
| --- | --- | --- |
| 工作定位 | 公司党委将“立足岗位做贡献、服务发展当先锋”作为推动党建与生产经营深度融合的重要抓手 | 方案、PPT、500字说明开头 |
| 党委推动 | 党委会研究实施方案及创建计划，印发实施方案和季度考核内容及评分细则 | 党委部署、过程性材料目录 |
| 活动载体 | 党员示范岗、党员先锋岗、党员突击队、党员先锋队、干部帮扶进网格 | 活动开展情况 |
| 过程推进 | 党员亮身份、设立党员示范岗、党员先锋岗公示、先锋队授旗、干部认领网格短板 | 过程性材料、PPT |
| 成效写法 | 用项目签约、收入增幅、目标完成率、服务指标、通信保障次数、抢险恢复数据支撑 | 总结、典型案例 |

## 新人先核对

| 问题 | 怎么核 |
| --- | --- |
| 有没有党委推动 | 找党委会议题、会议记录、实施方案和印发通知 |
| 有没有支部落实 | 找支部申报表、公示、月度台账、打分表、认定表 |
| 有没有专业线参与 | 找市场、政企、网络、职能线规则、评分和结果 |
| 有没有业务成效 | 找收入、签约、排名、服务指标、故障抢修、成本压降等数据来源 |
| 有没有典型案例 | 至少有个人典型、先锋队典型、急难险重典型 |
| 有没有考核上传闭环 | PDF文件名和省公司3.4.2条目一致，源文件可追溯 |
