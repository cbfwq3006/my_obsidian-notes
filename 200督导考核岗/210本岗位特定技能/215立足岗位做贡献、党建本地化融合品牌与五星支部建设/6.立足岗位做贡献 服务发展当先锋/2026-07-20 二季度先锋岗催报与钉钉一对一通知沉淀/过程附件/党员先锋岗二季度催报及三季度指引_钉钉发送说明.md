# 党员先锋岗二季度催报及三季度指引钉钉通知方案

## 一、今天怎么说

先发一对一钉钉消息，口径控制在“三件事”：催二季度结果、启动三季度安排、明确反馈时限。

### 一对一消息模板

{姓名}同志好，请协助落实{部门}党支部“立足岗位做贡献、服务发展当先锋”主题实践活动两项工作：

1. 报送二季度结果。请对照《党员先锋岗考核细则》和负面清单，报送 2026 年二季度（4-6 月）党员先锋岗评选推荐结果；本季度无推荐对象的，也请反馈“二季度无推荐”。
2. 启动三季度工作。请支部围绕三季度（7-9 月）中心任务和短板指标，确定党员先锋岗创建对象、党员先锋队或党员领题攻坚事项，做到季初定题、季中推题、季末评题。
3. 同步建立过程台账。三季度不等到季末集中补材料，每月至少记录一次进展、一次数据变化、一次典型做法。

请于 7 月 23 日（周四）18:00 前反馈：二季度党员先锋岗推荐情况或无推荐说明、三季度攻坚事项和创建对象、需要公司层面协调的问题。相关表格按原方案附件执行，操作方法可参考《支部一眼看懂操作指引》。收到请回复。

## 二、今天具体怎么做

1. 7 月 20 日上午或下午，给 27 名党务人员逐一发送钉钉单聊消息。
2. 同步把《支部一眼看懂操作指引》发到党务人员工作群，避免每个人重复问“填哪个表”。
3. 建一个反馈台账，字段为：单位、党务人员、二季度是否反馈、是否推荐先锋岗、三季度是否定题、需协调事项、备注。
4. 7 月 22 日上午，对未回复人员点对点提醒一次。
5. 7 月 23 日 18:00 截止收集，7 月 24 日形成汇总表，列出已报、未报、无推荐、拟推荐名单和三季度攻坚事项。

## 三、支部反馈材料口径

二季度只收三类结果：

| 类型     | 支部反馈内容              | 备注                    |
| ------ | ------------------- | --------------------- |
| 有推荐对象  | 附件4：党员先锋岗认定表，必要佐证材料 | 推荐对象要有岗位实绩、群众评价或数据支撑。 |
| 无推荐对象  | 回复“二季度无推荐”并简要说明     | 不强行凑数，成熟一个推荐一个。       |
| 暂不符合条件 | 说明原因和下一步创建对象        | 转入三季度继续创建。            |

三季度只要求先定三件事：

| 内容   | 要求                                |
| ---- | --------------------------------- |
| 创建对象 | 明确党员先锋岗创建对象或党员领题人员。               |
| 攻坚事项 | 聚焦经营发展、客户服务、网络支撑、职能服务、网格短板中的具体问题。 |
| 季度目标 | 写清目标值、完成时限、责任人和结果证明方式。            |

## 四、钉钉一对一发送步骤

当前 dws 未登录，需先完成登录：

```powershell
dws.cmd auth login --format json
dws.cmd auth status --format json
```

登录成功后，先按手机号匹配钉钉用户：

```powershell
dws.cmd contact user search-mobile --mobile 15639108350 --format json
```

确认能返回 userId 后，再发送单聊消息：

```powershell
dws.cmd chat message send --user <userId> --text "消息正文" --title "二季度先锋岗催报及三季度活动指引" --format json
```

建议正式发送前先预览，不要直接批量发。批量发送人数为 27 人，未超过单次 30 人上限。
