## 年度材料包最低目录

| 目录 | 放什么 |
| --- | --- |
| 1.党委部署 | 党委会议题、会议记录、实施方案、创建计划 |
| 2.制度规则 | 季度考核内容、评分细则、负面清单、支部操作通知 |
| 3.党员先锋岗 | 申报表、公示、打分表、认定表、季度汇总、通报 |
| 4.党员先锋队 | 备案表、专业线规则、月度推进、评分表、结果汇总 |
| 5.干部进网格 | 网格短板清单、认领台账、帮扶记录、成效数据 |
| 6.急难险重 | 山火抢险、通信重保、旺季营销等专项材料 |
| 7.典型案例 | 个人典型、团队典型、应急保障典型 |
| 8.考核上传 | 500字说明、过程性材料PDF、典型案例PDF、上传凭证 |

## 500字说明写法

| 段落 | 写法 |
| --- | --- |
| 第一段 | 写党委部署和活动总体定位，说明党建优势转化为发展动能 |
| 第二段 | 写党员示范岗、党员先锋岗、党员突击队、干部进网格和项目签约数据 |
| 第三段 | 写应急抢险，突出党委指挥、党员突击、抢通恢复和社会评价 |
| 第四段 | 写通信重保和旺季营销，突出零差错、零中断、零投诉和党员攻坚 |

## 典型案例写法

| 类型 | 推荐结构 |
| --- | --- |
| 个人典型 | 身份岗位 -> 主要难题 -> 党员带头做法 -> 数据成效 -> 带动作用 -> 可推广经验 |
| 先锋队典型 | 攻坚背景 -> 建队情况 -> 责任分工 -> 过程推进 -> 结果数据 -> 经验启示 |
| 应急抢险典型 | 灾情险情 -> 党委响应 -> 党员突击 -> 阶段攻坚 -> 恢复成效 -> 机制固化 |
| 通信重保典型 | 任务背景 -> 保障方案 -> 党员值守 -> 网络优化 -> 零差错结果 -> 社会评价 |

## 新人注意

- 这项不是发展党员材料，核心是“党员发挥先锋模范作用”和“党委推动党建业务融合”。
- 年度考核最怕只有宣传稿，没有党委部署和过程台账；从季度开始就要归档。
- 典型案例必须有事实和数据，不能只写“冲锋在前、担当作为”。
- 省公司上传PDF要保留同名Word源文件，后续抽查或改口径时能快速修改。
