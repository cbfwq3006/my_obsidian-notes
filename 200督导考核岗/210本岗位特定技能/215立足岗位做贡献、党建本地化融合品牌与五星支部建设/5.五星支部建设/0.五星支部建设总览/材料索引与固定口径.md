| 段落 | 写法 |
| --- | --- |
| 开头 | 写公司党委高度重视创建工作，列通报、党委研究、指导帮扶、典型宣传等数据 |
| 支部过硬星 | 写“三会一课”、线上线下学习、支委班子、责任清单、党建闭环管理 |

| 党业融合星 | 写党建引领业务、业务检验党建，客户服务、网络保障等载体 |
| 精神文明星 | 写企业文化、先进评选、乡村振兴、社区帮扶、员工关爱和文化活动 |
