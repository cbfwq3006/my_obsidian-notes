# 9.党建考核上传与资料归档

| 序号 | 事项 | 检查点 | 所需资源 | 工具模板 |
| --- | --- | --- | --- | --- |
| 1 | 对照考核条目 | 本项对应1.4.4.4.2“五星”支部创建过程（含500字说明） | 省公司党建考核目录 | 上传材料清单 |
| 2 | 整理情况说明 | 放500字说明，概括组织推动、五颗星、帮扶指导、典型宣传 | 创建总台账 | 500字说明 |

| 5 | 整理党委研究 | 放党委专题研究材料和年度创建情况报告 | 党委会材料、创建报告 | 专题研究材料包 |

| 8 | 核证据链 | 每项结论能找到通知、通报、会议记录、照片、台账或数据来源 | 原始材料 | 证据链核查表 |
| 9 | 导出上传版 | 按PDF目录导出上传版，文件名保留1.4.4.4.2编号 | Word、PDF | 上传版PDF |
| 10 | 留存源文件 | 保存Word、Excel、PPT、图片、PDF和发布截图 | 电子归档目录 | 年度归档清单 |

## 上传版推荐目录

| 目录 | 放什么 |
| --- | --- |
| 1.情况说明 | 500字说明 |
| 2.组织推动 | 7-11月县分公司“五星”支部创建通报 |
| 3.过程指导 | 党务人员培训、帮扶指导、成效点评与后进督导 |
| 4.年度创建情况 | 党委专题研究和创建情况报告 |
| 5.县分评价 | 博爱、孟州、沁阳、武陟、修武、温县评价 |
| 6.县分亮点 | 六县围绕五颗星创建亮点 |
| 7.典型宣传 | 先进典型宣传截图和原稿 |

## 上传前核查

| 核查项 | 标准 |
| --- | --- |
| 五颗星是否齐全 | 支部过硬星、高质量发展星、政治生态星、党业融合星、精神文明星均有材料 |
| 六县是否覆盖 | 博爱、孟州、沁阳、武陟、修武、温县均有评价和亮点 |
| 过程是否完整 | 通报、培训、帮扶、党委研究、评价、宣传均有证据 |
| 数据是否一致 | 500字说明、创建报告、县分亮点中的数据口径一致 |
| 问题是否闭环 | 存在不足有下一步计划或整改台账 |
| 图片是否可读 | 每张图有文字说明，能看出对应事项 |

## 新人注意

- 年底做上传版时，不要只放县分公司亮点，组织推动和党委专题研究更关键。
- 如果某县某颗星材料弱，要先反馈补材料，再进入上传版。
- 源PDF只是一年的样例，下年要按当年实际数据替换，不能沿用2025年数字。
