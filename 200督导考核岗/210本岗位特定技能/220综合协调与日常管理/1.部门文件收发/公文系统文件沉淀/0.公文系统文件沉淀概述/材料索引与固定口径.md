# 材料索引与固定口径

`D:\存档` 里真正要长期维护的，是公文正文、公司收文、部门收文、考核佐证和索引工具，不是下载源文件本身。

| 目录 | 作用 | 新人怎么用 |
| --- | --- | --- |
| `2025年5月-8月10日收发文` | 主要的年月收发文沉淀区，里面分 `发文` 和 `收文` | 每次归档先往这里续接最新月度内容 |
| `2025年8月10日后云公文` | 云公文切换后的新来源 | 后续新下载内容优先看这里 |
| `2024年9月收发文` 到 `2026年6月收发文` | 月度连续归档区 | 只做增量，不回头重排历史结构 |
| `2022-2024党群发文`、`2024党群发文` | 历史专卷 | 只补正文，不改原专卷名字 |
| `2024年考核相关佐证文件` | 考核佐证和证据材料 | 需要迎检时从这里抽证据 |
| `system\公文索引工具` | 索引脚本和虚拟环境 | 只用于处理和更新，不放正文 |
| `关于组织机构调整及排序优化的通知`、`申琳`、`祝文娟`、`郑苗` | 专题或个人口径的单独沉淀 | 保留原始命名，不强行并成月度目录 |

## 固定口径

- 只认 `正文名称、正文文号、发布时间、文件形式` 四列主数据。
- `汇总文件目录_当前最终版.xlsx` 是当前最终版，`汇总文件目录_责任矩阵V2.0.xlsx` 不修改。
- `~$*` 临时锁文件、`存档.rar`、纯下载缓存不进最终索引。
- 附件、目录、清单、收发文链接页都保留，但不当成正文主件。
- 同一公文有 PDF、DOC、DOCX 多种格式时，优先保留最完整、最稳定可打开的主件。
