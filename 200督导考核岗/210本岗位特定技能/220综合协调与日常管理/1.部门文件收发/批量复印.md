# 下载内容自动归档规则

## 新口径

`210本岗位特定技能` 只沉淀 SOP、操作指引、方法、提示词、脚本说明等“怎么做”的内容。

`230领域知识` 沉淀制度、红头、PDF、政策原文、上级通知等“依据是什么”的内容。

`240过程材料归档` 沉淀支部报送表、打分表、截图、照片、过程附件等“这次任务形成了什么证据”的内容。

`999待归档` 只放暂时无法判断主题的材料。

## 执行脚本

脚本位置：

`E:\祝姐的codex项目\archive_downloads_to_obsidian.py`

一键运行：

`E:\祝姐的codex项目\归档下载到Obsidian.cmd`

默认扫描最近 3 天文件，只复制，不移动，不删除下载源文件。

## 默认扫描位置

- `C:\Users\Lenovo\Downloads`
- `D:\Downloads`
- `D:\DingTalkDownload`
- `D:\BrowserControlledDownload`
- `D:\云公文Download`

## 判断规则

1. 文件名含 `SOP、操作指引、流程、方法、沉淀、skill、提示词` 等，归入 `210本岗位特定技能` 对应主题。
2. 文件名含 `红头、通知、方案、意见、办法、细则、制度、规定、条例、汇编、会议精神、关于` 等，且是 PDF、Word、TXT，归入 `230领域知识` 对应主题。
3. 表格、图片、压缩包、支部报送附件等过程材料，归入 `240过程材料归档` 对应主题和月份。
4. 判断不准的，归入 `999待归档\YYYY-MM`。
5. 同名同大小同哈希文件不重复复制。
6. 每次运行生成 CSV 日志，位置在 `999待归档\_归档日志`。

## 纠偏命令

如果发现原始附件误入 `210本岗位特定技能`，运行：

`python E:\祝姐的codex项目\archive_downloads_to_obsidian.py --relocate-skill-raw --execute`

该命令会把 `210` 下的 PDF、Office、图片、压缩包等原始材料迁移到 `230` 或 `240`，保留 `.md` SOP 和 `tools/scripts/assets` 中的工具文件。

## Codex 使用约定

以后 Codex 下载或生成材料时：

- SOP、操作手册、复用流程放 `210`。
- 红头文件、制度原文、政策 PDF 放 `230`。
- 支部报送表、截图、证明材料、阶段附件放 `240`。
- 不确定的先放 `999待归档`，不要硬塞进 `210`。
