## 推荐结构

```text
党建工作部2026年X季度工作总结及X季度工作计划

开头：一句话说明本季度总体推进情况。

一、X季度工作总结
（一）党委层面工作
1. 强化理论武装，提升政治引领力
2. 扎实开展专项学习教育，推动思想对标对表
3. 深化专项监督与整改，推动责任闭环

（二）基层党支部工作
1. 规范组织生活，强化制度执行
2. 强化基本培训，提升队伍素质
3. 规范党员发展，夯实组织基础
4. 强化考核通报，压实党建责任

（三）宣传及专项工作
1. 加强宣传引导，营造良好氛围
2. 完善宣传体制机制，强化组织保障
3. 抓实意识形态阵地管理

二、存在问题和不足

三、下季度工作计划
```

## 写作要点

| 模块 | 写法 | 不要这样写 |
| --- | --- | --- |
| 开头 | 写总体主线和季度重点 | 空泛写“高度重视、全面推进” |
| 工作总结 | 每段写“动作+结果+数据” | 按日期列流水账 |
| 阶段成效 | 写机制、闭环、评选、通报、成果 | 只写参加会议 |
| 问题不足 | 写具体短板和影响 | 写“认识还需提高” |
| 下季度计划 | 写重点任务、节点和交付物 | 写无期限的原则性要求 |

## 新人注意

- 季度总结要比月报更“归纳”，必须把重复事项合并。
- 季度计划要承接年度工作要点，不能只写临时事项。
- 涉及党建数据时，季度累计数要和月度表、党委会台账、支部报送表一致。
