## 常用数据口径

| 数据 | 来源优先级 | 写法 |
| --- | --- | --- |
| 党委会期数、第一议题数量 | 党委会台账、会议纪要、三重一大录入材料 | `组织党委会X期，开展“第一议题”学习X项` |
| 中心组学习次数 | 中心组学习记录、学习计划、签到材料 | `完成党委理论学习中心组学习X次` |
| 支部数量 | 党组织台账、党建考核支部名单 | `督促X个基层党支部规范开展组织生活、材料报送和问题整改` |
| 问题台账数量 | 学习教育台账、整改整治台账、巡察整改台账 | `查摆问题X个，形成整改台账并按期销号` |
| 宣传篇数 | 联通先锋、公众号、党群工作动态、报送统计 | `编审信息X篇，上传平台信息X篇，向上推荐X篇` |
| 党员发展数量 | 发展党员计划、政审表、预备党员转正材料 | `完成发展对象政审X人、入党积极分子材料审核X人` |
| 党建品牌和评选数量 | 季度品牌评选、立足岗位做贡献、五星支部材料 | `完成X季度评选，选树X个优秀案例/支部/岗位` |

## 不能混用的口径

| 容易混用 | 正确处理 |
| --- | --- |
| 周计划和本周完成 | 周报里“本周完成情况”写已经完成或实际推进，“下周计划”写未来动作 |
| 月度汇总和季度总结 | 季度总结不能直接粘三个月月报，要归并为工作线和阶段成效 |
| 半年总结和年度总结 | 半年总结重在下半年攻坚，年度总结要提炼全年体系、经验和下一年目标 |
| 党委层面和支部层面 | 党委会、中心组、全面从严治党写党委层面；三会一课、主题党日、党员发展写支部层面 |
| 成绩和措施 | 成绩必须有结果或数据，措施必须有对象、节点和预期成果 |

## 新人固定动作

| 步骤 | 做法 |
| --- | --- |
| 找材料 | 先按月份找同周期文件，再到专项文件夹补证据 |
| 建底稿 | 复制上一期格式，另存为本期文件名 |
| 换事实 | 删除旧期数据，按当期台账重填 |
| 核数据 | 每个数字旁边在草稿里标注来源，终稿前删除标注 |
| 改标题 | 标题、正文周期、计划周期、文件名四处一致 |
| 留痕 | 保留初稿、修改稿、终稿、报送截图或反馈记录 |
