## 报告固定结构

| 部分 | 写什么 |
| --- | --- |
| 开头 | 上级党委领导、年度背景、主体责任落实总体情况 |
| 一、工作开展情况 | 政治建设、思想建设、组织建设、党风廉政建设和反腐败工作、体制机制 |
| 二、存在问题 | 理论学习、责任传导、支部主体责任、监督体系等方面 |
| 三、下步举措 | 政治建设、思想建设、组织建设、作风建设、党建业务融合 |

## 新人注意

- “全面从严治党主体责任”不是纪检组单线工作，党委是主体，纪检是监督。
- 报告中的数字必须能追溯到党委会台账、学习台账、纪检监督台账或部门确认。
- 涉密文件不要放进上传版PDF；但台账里要能说明文件名称、形成时间和保管位置。
