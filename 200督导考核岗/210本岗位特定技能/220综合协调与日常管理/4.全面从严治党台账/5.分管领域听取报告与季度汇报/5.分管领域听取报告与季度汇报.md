# 5.分管领域听取报告与季度汇报

| 序号 | 事项 | 检查点 | 所需资源 | 工具模板 |
| --- | --- | --- | --- | --- |
| 1 | 建分管单位清单 | 每名班子成员分管哪些部门、单位、支部要列清 | 班子分工、支部清单 | 分管领域清单 |
| 2 | 发报告通知 | 上半年和下半年分别通知分管部门提交全面从严治党落实情况 | 钉钉、部门联系人 | 听取报告通知 |
| 3 | 收支部汇报材料 | 汇报要写政治建设、廉洁风险、作风建设、党建融合、问题和措施 | 支部汇报材料 | 支部汇报模板 |
| 4 | 组织听取报告 | 保存会议记录，体现班子成员听取汇报、提出要求 | 会议记录、照片 | 听取报告会议记录 |
| 5 | 汇总问题清单 | 对各单位共性问题和个性问题逐项登记 | 支部汇报、会议要求 | 分管领域问题清单 |
| 6 | 准备季度汇报 | 班子成员按季度向党委书记汇报分管领域管党治党情况 | 季度材料、问题清单 | 季度管党治党汇报 |
| 7 | 跟踪整改闭环 | 将季度汇报和听取报告中的问题转入整改台账 | 整改台账 | 整改跟踪表 |

## 支部汇报推荐结构

| 部分 | 内容 |
| --- | --- |
| 工作开展 | 理论学习、组织生活、党风廉政、党建业务融合、重点任务落实 |
| 风险防控 | 廉洁风险点、合规风险、数据安全、招投标、费用、客户服务等 |
| 存在问题 | 一项问题一条，不要写大段空话 |
| 下步措施 | 明确责任人、完成时限、验证方式 |

## 季度汇报推荐结构

| 部分 | 内容 |
| --- | --- |
| 政治引领 | 学习贯彻党中央决策部署和上级党委要求 |
| 一岗双责 | 分管领域党建、党风廉政、作风建设与业务同部署同推进 |
| 监督检查 | 调研、约谈、风险防控、制度修订、专项监督 |
| 问题整改 | 上季度问题整改进展、本季度新发现问题 |
| 下一步 | 下季度重点任务和风险防控措施 |

## 新人注意

- 听取报告材料要分“上半年”“下半年”，不要混成年度总结。
- 季度向党委书记汇报要连续留4份，缺一季度就要尽快补齐过程依据。
- 支部汇报不能只写成绩，必须让各单位报问题和整改措施。
