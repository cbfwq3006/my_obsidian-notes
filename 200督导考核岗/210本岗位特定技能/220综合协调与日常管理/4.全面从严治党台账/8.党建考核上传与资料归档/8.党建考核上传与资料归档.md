## 1.4.1最低材料包

| 目录 | 必备材料 |
| --- | --- |
| 1.党委分析研判 | 年初研究、上半年分析研判、年度分析研判党委会材料 |
| 2.年度任务安排和落实台账 | 年度党建工作要点、主体责任年度任务安排、落实台账；涉密不上传、可抽查 |
| 3.主体责任报告 | 上半年落实全面从严治党主体责任情况报告、年度报告 |
| 4.党内法规执行 | 党委专题研究党内法规会议纪要、专题研究材料、法规清单落实情况 |
| 5.班子成员履责 | 所在支部安排督促、分管领域检查督促、上下半年听取报告、季度向党委书记汇报 |
| 6.监督检查整改 | 监督检查、廉洁教育、风险防控、作风建设、问题整改台账 |

## 上传前最后核对

| 核查项 | 标准 |
| --- | --- |
| 制度频次 | 全面从严治党专题研究不少于2次，党内法规执行专题研究不少于1次 |
| 主体责任 | 党委层面有任务安排、会议研究、报告和整改闭环 |
| 一岗双责 | 班子成员材料按人归档，季度连续，上下半年听取报告齐全 |
| 监督整改 | 有问题清单、整改措施、责任部门、完成时限、验收方式 |
| 涉密材料 | 不上传涉密正文，只保留说明和可抽查路径 |
| 数据一致 | 半年、年度报告和材料索引中的数字口径一致 |

## 新人注意

- 考核上传版不是把所有原始材料塞进去，而是按目录证明“该做的做了、做完有痕、问题有改”。
- 党委会、主体责任报告、班子成员季度汇报是本项最容易被抽查的三类材料。
- 上传前把文件名统一为“考核编号+材料名称”，例如`1.4.1-1本年度党委分析研判全面从严治党工作情况.pdf`。
