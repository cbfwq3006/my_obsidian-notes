支委会“三重一大”，指重大决策、重要人事、重大项目、大额资金四类事项，核心是集体研究、民主集中、会前酝酿、会议决定 。下面按国企/支部常用口径，直接列可直接抄的清单：

一、重大决策事项（支部必议）

- 贯彻上级决策、年度党建/业务计划、重大改革方案。

- 支部重要制度制定/修订、意识形态、党风廉政、安全稳定重大事项 。

- 机构设置、岗位调整、绩效分配、职工奖惩、职称评审、评优评先 。

- 关系员工切身利益的重大问题（薪酬、福利、劳动保护等） 。

- 重大突发事件、信访维稳、风险处置方案 。

- 其他全局性、政策性、敏感性重要事项 。

二、重要人事任免事项（支部前置/把关）

- 中层及以上管理人员推荐、提名、任免、调整、奖惩、考核 。

- 后备干部推荐、党代表/人大代表/政协委员人选推荐 。

- 关键岗位、核心岗位人员选聘、调动、解聘 。

- 违纪党员、员工的处理意见（党纪/政务处分） 。

三、重大项目安排事项（支部前置研究）

- 基建工程、技改项目、信息化建设、重大维修项目 。

- 大宗物资/服务采购、设备购置、资产处置（房产、车辆、设备） 。

- 对外合作、投资、担保、租赁、招投标等重大经营事项 。

- 重大营销、客户、渠道拓展项目，网格/班组重要资源配置 。

四、大额资金使用事项（支部前置审核）

- 年度预算、决算及大额资金（如超5000元，按单位标准）支出、调整。

- 专项资金、项目资金、福利费、工会费等大额使用 。

- 对外捐赠、赞助、借款、大额坏账核销 。

五、支委会“三重一大”核心规则（必记）

1. 前置研究：行政“三重一大”先经支委会前置把关、政治合规审查，再上经理办公会。

2. 集体决策：到会支委≥2/3，一人一票、末位表态、记名表决，过半数通过。

3. 全程留痕：会议记录完整存档，终身追责。

4. 不设党委的独立法人国企：支委会可直接决策“三重一大”，无需前置。

六、联通一线支部常用示例（直接用）

- 网格划分、班组调整、客户经理/装维班长任免。

- 营业厅装修、设备更新、大宗终端采购。

- 营销活动方案、重大客户优惠政策、渠道合作签约。

- 超标准费用支出、福利费发放、困难员工补助。
