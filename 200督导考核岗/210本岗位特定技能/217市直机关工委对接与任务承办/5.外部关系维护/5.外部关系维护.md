# 5.外部关系维护

目标：把与市直机关工委的日常对接从“临时找人、临时翻记录”变成可交接台账。新人接手后，能知道找谁、问什么、留什么痕、归哪里。

| 序号 | 事项 | 检查点 | 所需资源 | 工具模板 | 交付物/留痕 |
| --- | --- | --- | --- | --- | --- |
| 1 | 建联系人台账 | 从通知落款、工作群、邮件、电话记录中提取联系人；不确定时只填来源，不臆造信息 | 工委通知、邮件、聊天记录 | `工委联系人台账.xlsx` | 联系人台账 |
| 2 | 建任务闭环台账 | 每个工委任务都登记来源、要求、责任人、办理结果、报送时间和留痕路径 | 全年任务记录 | `工委任务承办台账.xlsx` | 年度任务台账 |
| 3 | 管理领取资料 | 入党积极分子培养考察登记表等纸质资料要记录领取日期、数量、领取人、用途、去向 | `D:\工委\领取资料` | `D:\工委\领取资料\2026年发展党员\报工委\2026年申请入党积极分子培养考察登记表领取登记表(焦作联通).xlsx` | 领取登记表 |
| 4 | 维护常用模板 | 将高频表格按类别归档：发展党员、双报到、书记项目、两优一先、党代表、困难党员、三类党员 | `D:\工委` 分类目录 | `D:\工委\汇总索引.csv` | 常用模板索引 |
| 5 | 做季度复盘 | 每季度统计工委任务数量、逾期风险、反复退回问题、常用联系人变化 | 任务台账 | 季度复盘表 | 复盘记录 |
| 6 | 年度移交 | 年底整理年度任务清单、模板包、重要报送材料和问题清单 | 全年归档 | 移交清单 | 年度交接包 |

## 联系人台账字段

| 字段 | 填写要求 |
| --- | --- |
| 单位/部门 | 如市直机关工委相关科室；不知道科室时写通知来源 |
| 联系人 | 从通知、邮件或工作群提取 |
| 电话/邮箱 | 按原文记录，不确定不补猜 |
| 负责事项 | 发展党员、两优一先、培训会议、双报到等 |
| 来源 | 写明来自哪份通知或哪次任务 |
| 最近联系时间 | 每次关键沟通后更新 |
| 备注 | 口径要求、偏好格式、特殊提醒 |

## 任务闭环台账字段

| 字段 | 填写要求 |
| --- | --- |
| 接收日期 | 收到通知或任务的日期 |
| 任务名称 | 与通知标题一致 |
| 分类 | 通知承接/材料报送/会议活动/党代表评优/资料领取 |
| 上级截止 | 工委要求的截止时间 |
| 内部截止 | 自己设定的提前截止时间 |
| 责任部门 | 党建部、支部、相关专业部门 |
| 报送材料 | 逐项列文件名 |
| 状态 | 未开始/收集中/审核中/已报送/已归档 |
| 留痕路径 | 最终材料所在路径 |

## 日常对接原则

| 原则 | 做法 |
| --- | --- |
| 先书面后口头 | 能在通知和模板里找到的，不反复口头问；口头确认后写入台账 |
| 先内部核清再外部询问 | 不带着明显缺项直接问工委 |
| 重要事项留痕 | 报名、报送、盖章、延期、口径变化都截图或邮件确认 |
| 敏感信息少扩散 | 身份证、困难党员、三类党员等材料只发给必要人员 |
| 模板统一管理 | 不让各支部使用自己保存的旧模板 |

## 年度交接清单

| 类别 | 必须移交 |
| --- | --- |
| 联系人 | 工委联系人台账、工作群说明、常用邮箱 |
| 任务 | 年度工委任务承办台账 |
| 模板 | 发展党员、两优一先、双报到、书记项目、党代表等常用模板 |
| 过程材料 | 通知、分办、审核、退回、报送截图 |
| 最终材料 | 电子版、扫描版、公示或表彰材料 |
| 问题清单 | 容易退回的问题、常用口径、下一年需跟进事项 |
