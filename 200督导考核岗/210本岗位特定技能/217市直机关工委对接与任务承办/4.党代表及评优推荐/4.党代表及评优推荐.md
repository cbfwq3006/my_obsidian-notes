## 党代表推荐必查

| 检查项 | 标准 |
| --- | --- |
| 推荐条件 | 与工委通知条件一致 |
| 登记表 | 信息完整，党组织名称、职务、身份准确 |
| 干部信息 | 干部任免审批表或基本信息审核表与登记表一致 |
| 荣誉证明 | 荣誉证书图片清晰，奖项名称可识别 |
| 无犯罪证明 | 姓名、身份证或对象信息准确，扫描清晰 |
| 报送版 | 电子版和扫描版均可打开 |

| 先进基层党组织 | 党组织全称、班子建设、党员队伍、组织生活、党建业务融合 |

## 退回修改原则

| 问题 | 处理 |
| --- | --- |
| 姓名、单位、党组织名称不一致 | 立即退回，要求全材料统一 |
| 缺证明材料 | 台账标红，限时补齐 |
| 事迹材料空泛 | 要求补具体数据、案例、职责和结果 |
| 扫描件不清晰 | 重新扫描，不用照片压缩版替代 |
