适用范围：市直机关工委来文、工作提示、通知承接、材料报送、会议培训、发展党员、双报到、书记项目、党代表推荐、两优一先、资料领取和日常关系维护。

## 一、先按任务类别分流

| `D:\工委` 分类 | 归入 SOP | 典型材料 | 处理重点 |
| --- | --- | --- | --- |

## 二、新人接手默认动作

1. 打开 `D:\工委\汇总索引.csv`，确认要处理的是哪类工委任务。
2. 找到上级通知正文，先看四件事：报送对象、报送内容、报送时限、报送方式。
3. 建立当次任务文件夹，建议命名为 `YYYYMMDD+工委+任务名称`。
4. 建一张任务台账，字段至少包括：任务来源、接收时间、截止时间、责任部门、需报材料、模板路径、当前状态、问题记录、发送留痕。
5. 凡是对工委报送，都保留电子版、扫描版、发送截图或邮件记录。
6. 任务办结后，把最终版同步归档到对应分类，更新台账状态为“已办结”。

## 三、所有工委任务通用检查

| 检查项 | 通过标准 |
| --- | --- |
| 通知来源 | 能找到工委正式通知、工作提示或明确转办记录 |
| 截止时间 | 台账中写明日期和具体时间，内部截止早于工委要求 |
| 模板版本 | 使用通知附件或最新一次模板，不拿旧表直接改 |
| 责任分工 | 能看出谁提供数据、谁审核、谁报送 |
| 材料命名 | 文件名含单位、事项、日期或对象，不能只叫“表格”“最终版” |
| 报送留痕 | 有邮件、钉钉、系统截图或发送记录 |
| 归档闭环 | 最终版、扫描版、过程版和台账都能找到 |

## 四、不能问领导也能处理的判断规则

| 场景 | 默认处理 |
| --- | --- |
| 通知没说是否盖章 | 先按“电子版定稿+可盖章扫描版”准备，报送前向对方确认；若截止紧，先报电子版并说明盖章版随后补 |
| 多个部门都涉及 | 由党建部门建总台账，按材料内容分给相关支部或专业部门提供 |
| 上级模板和历史模板不同 | 使用上级最新模板，历史模板只作参考 |
| 支部逾期不报 | 到点前提醒一次，到点后在台账标记“未反馈”，同步给部门负责人 |
| 材料不完整 | 一次性列清缺项和修改要求，限时退回 |
