# 2.材料报送审核

目标：把工委要求报送的各类材料从“各单位反馈”审核到“可以对外报送”。重点是台账化、一次性退回、定稿留痕。

| 序号 | 事项 | 检查点 | 所需资源 | 工具模板 | 交付物/留痕 |
| --- | --- | --- | --- | --- | --- |
| 1 | 建报送台账 | 字段包括：事项、责任单位、应报材料、已报材料、缺项、退回原因、最终状态、报送时间 | Excel | `D:\工委\汇总索引.csv` | `工委材料报送审核台账.xlsx` |
| 2 | 审发展党员材料 | 核名单、培训报名表、发展党员需求统计、发展对象指标、政审联审通知、领取登记表 | `D:\工委\发展党员` | `D:\工委\发展党员\2026年发展党员`；`D:\工委\发展党员\6\2 工委提供发展对象指标5人` | 发展党员报送包 |
| 3 | 审双报到和机关病材料 | 双报到活动统计表、机关病纠治台账、填报版和盖章版要一致 | `D:\工委\双报到` | `D:\工委\双报到\6\5 双报到机关病` | 双报到/机关病报送包 |
| 4 | 审书记项目材料 | 申报表、通知、完成情况报告要能对应年度；项目名称、牵头人、目标任务一致 | `D:\工委\书记项目` | `D:\工委\书记项目\4\4 工委通知0416`；`D:\工委\书记项目\1\1 报省公司4个台账信息\机关大讲堂培训汇总\202511 市直机关工委公文写作培训` | 书记项目申报/总结材料 |

## 通用审核台账字段

| 字段 | 填写要求 |
| --- | --- |
| 任务名称 | 与工委通知标题保持一致 |
| 材料类别 | 发展党员/双报到/书记项目/党费/困难党员/三类党员/党建述职/党课统计 |
| 责任单位 | 支部或部门全称 |
| 应报材料 | 按通知逐项列出 |
| 已收材料 | 写文件名，不写“已交” |
| 缺项 | 缺什么写什么 |
| 退回原因 | 具体到字段或附件 |
| 最终状态 | 待收/退回/已定稿/已报送/已归档 |

## 分类审核标准

| 类别 | 必查项 |
| --- | --- |
| 发展党员 | 姓名、支部、入党阶段、培训报名表、需求统计表、发展对象指标、政审联审要求 |
| 双报到 | 活动时间、参与人员、社区或服务对象、活动成效、统计表与证明材料一致 |
| 书记项目 | 项目名称、项目目标、牵头领导、推进措施、完成情况、年度一致 |
| 党费报送 | 金额、人数、缴纳期间、凭证或图片清晰度 |
| 困难党员 | 困难类别、慰问对象、金额或物资、个人信息保护 |
| 三类党员摸排 | 分类口径、人员名单、干部任免审批表、汇总表一致 |
| 党建述职/组织生活会 | 统计表、整改台账、组织生活会汇总表字段完整 |

## 退回话术

〔支部/部门〕：你单位报送的〔事项名称〕材料已初审，需修改以下问题：1.〔缺项或错误字段〕；2.〔格式或口径问题〕；3.〔需补充证明或盖章扫描〕。请于〔时间〕前反馈修改版，文件名统一为“修改后+单位+事项+日期”。
