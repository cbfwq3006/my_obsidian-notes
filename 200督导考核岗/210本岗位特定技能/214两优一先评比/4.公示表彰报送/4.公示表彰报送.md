## 最终归档清单

| 类别 | 必须有 |
| --- | --- |
| 通知模板 | 上级通知、填表说明、所有空白模板 |
| 过程材料 | 下发通知、各支部反馈、审核台账、退回修改记录 |
| 定稿材料 | 汇总表、审批表、事迹材料、证明材料 |
| 公示材料 | 公示稿、公示截图、公示反馈或无异议记录 |
| 报送材料 | 电子版、扫描版、报送截图/邮件 |
| 表彰材料 | 表彰决定、表彰名单、现场人员名单、颁奖顺序、照片视频 |

## 新人易错点

| 易错点 | 处理办法 |
| --- | --- |
| 公示名单和最终报送名单不一致 | 公示后如调整，必须重新留调整依据，必要时重新公示 |
| 扫描件漏页 | 扫描后逐页打开检查，不只看文件是否生成 |
| 只保存最终版 | 过程版、退回版、扫描版都要留，便于以后复盘 |
| 表彰照片散乱 | 按级别和奖项建文件夹，如 `集团级优秀党员`、`省级先进基层党组织`、`市级优秀党务工作者` |
