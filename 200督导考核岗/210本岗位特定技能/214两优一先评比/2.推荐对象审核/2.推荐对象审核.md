# 2.推荐对象审核

目标：把各支部推荐对象从“能报”审核到“可上报”。审核不是只看有没有表，要核资格、名额、材料、证明和文字一致性。

| 序号 | 事项 | 检查点 | 所需资源 | 工具模板 | 交付物/留痕 |
| --- | --- | --- | --- | --- | --- |
| 1 | 汇总各支部材料 | 每个对象至少有汇总表、推荐审批表、事迹材料；先进基层党组织必须有党组织推荐审批表 | 各支部报送文件 | `D:\两优一先\市级两优一先\5\4 两优一先各支部提供`；`D:\两优一先\市级两优一先\5\4 市级两优一先评选\市公司报送材料` | 初版审核台账 |
| 2 | 核名额 | 每类推荐数不超过通知名额；同一人不重复占用多个个人奖项，特殊情况需领导确认 | 通知、名额表、汇总表 | 各级 `推荐汇总表` | 名额核对结果 |
| 3 | 核对象资格 | 优秀共产党员核党员身份；优秀党务工作者核党务职责；先进基层党组织核党组织全称 | 党统信息、支部名单、岗位信息 | 审核台账 | 资格问题清单 |
| 4 | 核审批表 | 表头级别、奖项名称、姓名、支部、出生年月、入党时间、职务等字段完整；签字盖章栏按通知要求预留 | 推荐审批表 | 工委、省级、市级、集团级对应模板 | 可退回修改清单 |
| 5 | 核事迹材料 | 是否聚焦奖项类别；是否有数据、案例、党建和业务结合；是否有夸大、空话、错别字 | 事迹材料 | 历史样例：集团级报送电子版、省级报送材料、工委报送材料 | 事迹材料修改意见 |
| 6 | 核证明材料 | 按通知要求收集党风廉政、信访、审计、无犯罪、直系亲属无犯罪等材料；没有要求的不主动加码，但上级模板已有的必须补齐 | 纪检、审计、人力、公安证明等 | `D:\两优一先\工委两优一先\4\4 工委表彰相关表报送\对“两优一先”推荐对象党风廉政情况的意见.docx`；`信访情况证明.docx`；`审计情况证明.docx`；各类 `无犯罪证明` | 证明材料包 |
| 7 | 退回修改 | 退回时一次性列清问题，不反复零散提；保留退回记录 | 审核台账、聊天记录 | 退回清单 | 修改闭环记录 |

## 审核台账字段

| 字段 | 填写要求 |
| --- | --- |
| 推荐级别 | 工委/集团级/省级/市级 |
| 奖项类别 | 优秀共产党员/优秀党务工作者/先进基层党组织 |
| 推荐对象 | 个人姓名或党组织全称 |
| 推荐单位 | 支部或部门全称 |
| 名额状态 | 符合/超额/需调整 |
| 审批表 | 已收/缺失/需修改 |
| 事迹材料 | 已收/缺失/需修改 |
| 汇总表 | 已收/缺失/需修改 |
| 证明材料 | 已齐/缺廉洁意见/缺信访/缺审计/缺无犯罪 |
| 退回原因 | 写具体问题，不写“格式问题” |
| 最终状态 | 待收/初审通过/退回修改/定稿/已报送 |

## 必查一致性

| 项目 | 核对办法 |
| --- | --- |
| 姓名 | 审批表、汇总表、事迹材料、证明材料、照片文件名一致 |
| 党组织名称 | 与党统或正式文件一致，不随意简称 |
| 奖项名称 | “优秀共产党员”和“优秀党员”不要混写；“先进基层党组织”和“先进基层党支部”按通知口径写 |
| 时间 | 入党时间、任职时间、事迹年度、表彰年度不能互相矛盾 |
| 数据 | 经营数据、党建数据、荣誉数据必须能找到来源 |

## 退回话术

〔支部名称〕：你支部报送的〔对象/奖项〕材料已初审，需修改以下问题：1.〔问题一〕；2.〔问题二〕；3.〔问题三〕。请于〔时间〕前反馈修改版，文件名统一为“修改后+支部+奖项+姓名/党组织”。逾期将按当前材料状态进入汇总。
