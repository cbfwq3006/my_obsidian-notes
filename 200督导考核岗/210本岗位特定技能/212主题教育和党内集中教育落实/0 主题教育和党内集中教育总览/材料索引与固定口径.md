## 已提取的关键事实口径

| 事项 | 2025年材料口径 | 后续复用方法 |
| --- | --- | --- |
| 学习教育启动 | 自2025年3月以来，根据党中央统一部署，在省公司党委指导下开展深入贯彻中央八项规定精神学习教育 | 换年度时先改背景和上级依据 |
| 组织领导 | 党委召开专题会议研究学习教育工作13次，印发实施方案，成立工作专班 | 写方案和总结时作为“压实责任”样例 |
| 学习研讨 | 组织读书班，党委理论学习中心组学习5次，第一议题学习15次，基层支部通过主题党日、三会一课实现全覆盖 | 年度台账要能支撑这些数字 |
| 培训分类 | 举办支部书记轮训2期、中央八项规定精神暨习近平经济文选联学班2期，培训86人次 | 写党员教育培训说明时按“分层分类”统计 |
| 党员教育培训 | 线上依托联通学习平台、国资e学等组织全体党员培训4期，线下举办专题培训15期；支部书记培训6期覆盖140人次；党务骨干培训覆盖84人次 | 每年按实际培训台账替换数字 |
| 查摆整改 | 党委层面查摆6类突出问题和4类纳入集中整治问题；基层支部查摆10类问题 | 问题台账必须和总结报告一致 |
| 警示教育 | 组织观看警示教育片、通报典型案例、赴焦南监狱开展现场警示教育，撰写心得体会 | 归档时保留通知、签到、照片、心得和信息稿 |
| 四下基层 | 领导班子围绕基层调研、安全检查、现场办公等形成台账，记录问题和整改进展 | 群众评估和开门教育材料要引用这个台账 |

## 新人先核对的信息

| 信息 | 怎么核 |
| --- | --- |
| 上级部署要求 | 找上级通知，确认主题、对象、时间、材料目录和报送口径 |
| 本单位实施方案 | 看是否党委研究、是否成立专班、是否明确方法步骤和责任分工 |
| 学习培训覆盖 | 核党委、支部、党员三个层面是否都有记录和数据 |
| 问题整改闭环 | 核每个问题是否有来源、责任、措施、进展、销号 |
| 群众评估 | 核群众意见是否有收集渠道、办理情况和反馈结果 |
| 考核上传材料 | 核PDF目录与省公司党建考核条目一致，源文件可追溯 |
