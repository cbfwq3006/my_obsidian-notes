## 优先做成 Skill 的建议

### 第一优先级：220综合协调与日常管理

原因：最高频，覆盖周计划、月年度总结、文件收发、台账、领导交办事项，能直接提升日常效率。

### 第二优先级：211党建责任制考核评价

原因：规则稳定、输入输出明确，适合做成考核指标拆解、材料归集、问题整改建议生成 skill。

### 第三优先级：213党组织书记抓基层党建述职评议考核

原因：每年固定发生，流程清晰，材料标准化程度高。

### 第四优先级：219党员发展工作

原因：流程刚性强、材料多、容错率低，适合做清单式 skill。

## 每个技能文件夹后续建议沉淀内容

每个目录后续可逐步补充：

1. `流程.md`：这项工作从接通知到办结的完整步骤。
2. `材料模板.md`：通知、报告、台账、汇总表常用模板。
3. `检查清单.md`：发布、报送、归档前必须检查的事项。
4. `常用表述.md`：总结、汇报、整改、推进类高频语言。
5. `案例库.md`：过往已完成材料和典型案例。

## 当前建议

不要一次性把 10 个方向都做成 Codex skill。先从最高频、最稳定的一个做起：

> 党建工作周期性总结材料生成 / 综合协调与日常管理

跑通一个，再复制方法到其他方向。
