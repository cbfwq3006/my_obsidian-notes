## 新人必须先核的信息

| 信息 | 怎么核 |
| --- | --- |
| 当年发展指标 | 找市公司指标文件和市直机关工委计划文件，确认指标数和结构要求 |
| 储备人员是否成熟 | 看申请时间、积极分子时间、培养考察记录是否满足时间要求 |
| 系统和纸质是否一致 | 河南党员管理平台、联通先锋/支部纸质材料、年度台账三方核对 |
| 政审和培训是否完成 | 未完成不得进入接收预备党员环节 |
| 党委审批是否超期 | 支部党员大会后一般3个月内审批，转正审批也一般3个月内完成 |
