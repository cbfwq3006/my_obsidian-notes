# 5.问题整改提升

| 序号 | 事项 | 检查点 | 所需资源 | 工具模板 |
| --- | --- | --- | --- | --- |
| 1 | 汇总反馈问题 | 按支部汇总年度党建考核反馈问题，问题要来自考核结果和反馈意见 | 反馈通知、支部反馈意见 | `2024年度党建考核反馈信息表new.xlsx` |
| 2 | 建整改台账 | 表头至少包括党支部名称、问题、整改措施、责任人、完成时限、完成情况 | 反馈信息表 | 整改落实台账 |
| 3 | 拆解整改措施 | 每条措施要对应问题，写清具体动作、频次、责任人、可验证结果 | 各支部整改方案 | 党建考核整改落实台账完成情况目录 |
| 4 | 明确完成时限 | 可立行立改、长期坚持，也可填具体日期；日期必须能解释 | 各支部反馈 | 完成时限列 |
| 5 | 跟踪完成情况 | 要写实际完成情况，不能只写“已整改”；最好有数据、会议次数、台账、活动成果 | 支部证明材料 | 完成情况列 |
| 6 | 约谈一般等次支部 | 年度党建考核结果为“一般”的支部，安排支部书记约谈并留记录 | 年度通报、约谈记录 | 谈心谈话目录、约谈记录 |
| 7 | 复核整改质量 | 看是否真整改、是否反弹、是否形成制度机制 | 联通先锋、会议记录、支部台账 | 季度督导检查表 |
| 8 | 形成整改闭环 | 半年/年底复核后标注完成情况，省公司检查前整理成佐证 | 整改台账、证明材料 | 省公司检查目录 |

## 整改台账写法

| 字段 | 写法 |
| --- | --- |
| 问题 | 具体到事项，例如“三会一课记录不规范”“支委会议题漏项”“党建与中心工作融合成效不明显” |
| 整改措施 | 写动作和机制，例如“统一记录模板、每月抽查、季度通报、纳入党员评议” |
| 责任人 | 写到支部书记、支委成员或具体党务人员 |
| 完成时限 | 能定日期就定日期；长期坚持要说明阶段性检查节点 |
| 完成情况 | 写实际结果，例如召开培训次数、建立台账、完成率、业务融合成效、问题是否销号 |

## 常见整改问题对应措施

| 问题类型 | 可用整改抓手 |
| --- | --- |
| 上级重点工作落实不到位 | 建任务清单、支委会专题研究、明确责任人、月度督导 |
| 三基建设薄弱 | 统一记录模板、开展党务培训、月度抽查、季度通报 |
| 党建业务融合不深 | 建“党建+业务”项目、党员突击队、党员示范岗，指标纳入绩效 |
| 党建信息质量不高 | 指定信息员、明确数量质量标准、建立素材库、审核后报送 |
| 述职问题剖析不深 | 提前调研、从思想认识/制度执行/作风表现剖析原因，措施量化可检验 |
| 非合同制党员管理不足 | 建动态台账，组织关系应转尽转，同学习、同管理、同考核 |
