# 时间管理 — 角色态度

---

## 愿景

> 掌握时间管理的系统性方法，做到高效工作、按时下班，把省下来的时间投入到自我成长和家庭陪伴中。让"到点下班"成为习惯，而非奢望。

## 目标

### 半个月目标（2026年7月15日-7月31日）
- [ ] 连续记录一周时间消耗，找出"时间黑洞"
- [ ] 建立每日工作规划SOP，每天到岗前10分钟规划
- [ ] 每周至少3天按时下班

### 三个月目标（2026年7月-10月）
- [ ] 每周5天都能按时下班（偶尔例外不超过1天）
- [ ] 形成稳定的时间管理习惯，不再需要刻意提醒
- [ ] 将时间管理方法抽象迁移到通用体系

## 里程碑

- [ ] 里程碑1：第一次连续3天按时下班（目标：2周内）
- [ ] 里程碑2：连续一周按时下班（目标：1个月内）
- [ ] 里程碑3：时间管理SOP进入"自动化期"（目标：2个月内）

## 当前状态

**已有能力**：
- 【待填写：你目前已经尝试过的时间管理方法】

**最大痛点**：
1. 总是到点走不了，临时任务打乱计划
2. 工作效率不高，同样的事花的时间比别人多
3. 没有系统的时间管理方法，靠感觉做事

**知识漏洞诊断**：

| 痛点 | 缺什么知识 | 怎么补 |
|------|-----------|--------|
| 走不了 | 缺**程序性知识**（按时下班SOP）+ **事实性知识**（时间消耗记录） | 先记录→找原因→建SOP |
| 效率不高 | 缺**概念性知识**（深度工作理论）+ **程序性知识**（每日规划SOP） | 学深度工作→建规划SOP→刻意练习 |
| 靠感觉做事 | 缺**程序性知识**（任务优先级SOP） | 学四象限→每天用→养成习惯 |
