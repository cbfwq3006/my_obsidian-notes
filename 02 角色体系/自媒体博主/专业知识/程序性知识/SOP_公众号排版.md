# 公众号排版流程

> 使用 gzh-design skill 将文章排版为公众号 HTML 格式

## 步骤

### 1. 安装排版 Skill

安装地址：[https://github.com/isjiamu/gzh-design-skill](https://github.com/isjiamu/gzh-design-skill)

在 WorkBuddy 中搜索并安装 `gzh-design-skill`。

### 2. 采集文章内容

将目标文章（如微信公众号文章）的 URL 提交给 AI，采集原文内容。

示例 URL：`https://mp.weixin.qq.com/s/w9dCLGw8tVDvRHsHXC73uQ`

### 3. 使用 Skill 排版

调用 `gzh-design` skill，指定配色风格（如"摸鱼绿"），将采集到的内容排版为公众号 HTML。

> 排版关键词：炸裂GPTLive.md → 摸鱼绿配色 → 公众号 HTML 输出

### 4. 复制发布

将生成的 HTML 复制到公众号编辑器中，预览确认后发布。
