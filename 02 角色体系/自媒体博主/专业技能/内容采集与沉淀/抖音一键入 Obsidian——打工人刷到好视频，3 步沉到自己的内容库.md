## 内容创作者的素材库困境,三个真相

**真相一:官方下载有水印。*  
你想把视频沉到自己的笔记库,下载下来的视频带着抖音 ID 角标 + 滚动水印。*这是平台防盗链的硬约。*,App 内部根本绕不过去
**真相二:复制粘贴丢信息。*  
视频 = 画面 + 声音 + 文字。文案你复制得到(如果有字幕),画面你截屏存得到,但**声音里的「讲者逻辑。*——那些口播里临时蹦出的金句、即兴发挥的转折——全丢了
**真相三:50 条视频整理一周。*  
更扎心的是:就算你一个个手动存下来,**这些素材躺在微信收藏 / 抖音收藏 / 手机相册 / 便签 4 个地。*,等你想用的时候已经找不到
内容创作90% 的痛点不是「看不到好东西」,是。*看到 留下**」的链路断了

## Douyin Capture:本地抓+ 无水+ Whisper 转写

`Douyin Capture` 是一款给 Obsidian 用的抖音内容导入插件。核心做的事只有一件:**把抖音分享链接变成你 Vault 里的结构化笔。*
![[attachments/笔记同步图片/20f2cfe63899ca1c81ff15607d0b563f_MD5.jpg]]

它和市面上其抖音保存"工具3 个本质不同:

| 维度 | Douyin Capture | 抖音 App 收藏 | 微信传输 | 浏览器扩|
| :-- | :-: | :-: | :-: | :-: |
| 视频画质 | **无水。* | 有水| 有水| 看源 |
| 文案提取 | **自动** | | | 看源 |
| 视频转文| **本地 Whisper** | | | |
| 隐私 | **本机处理** | 云端 | 云端 | 看源 |
| 一致结构笔| **。* | | | |
| 综合效率 | ⭐⭐⭐⭐| ⭐⭐ | ⭐⭐ | ⭐⭐|

> 横向对比说明:装1 次后 条抖音分享链3 1 篇结构化笔记
### 4 个核心能
### 两种导入模式

「提取文案」—完整流水线:视频Whisper 转写、图文用 desc 配文

「提取视频」—仅下载无水印视频并嵌入笔记,**不转。*(适合先批量下完再统一处理
**链接形式全覆。*  
`v.douyin.com` 短链、`www.douyin.com/note|video` 长链、`iesdouyin.com/share/...` 分享码、整段分享文案——都能识别
**容错降级**  
文案成功但视部分配图失败时,**仍会创建笔记**并给出降级说明。不会因为网络抖一下就白干
**隐私**  
无需抖音 Cookie、无需付费语音 API。*数据全部本机处理**。这点对我来说很重要——我不想让云端知道我存了哪些视频

## 怎么用:3 步搞
**1 步:启动本地后端**(≤ 2 行安装步骤)

```
git clone https://github.com/lyxdream/obsidian-content-capture-backend.git
cd obsidian-content-capture-backend && python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install-r requirements.txt
python web/app.py
```

> 默认监听 [http://127.0.0.1:5050](http://127.0.0.1:5050)。*终端保持运行**,关闭后插件无法提取
**2 步:装插。*

方式 A(推荐)
Releases 下载

`main.js + manifest.json + styles.css`

解压
`/.obsidian/plugins/douyin-capture/`

方式 B
设置 第三方插浏览 "Douyin Capture" 启用

**3 步:用起。*  
点击左侧 ribbon 。*摄像机图。* 弹窗粘贴分享链接 选「提取文案」或「提取视频」→ 等进度条走完 笔记自动落到 `Douyin/2026-06-08-作标题.md`
### 3 个关键配
| 选项 | 默认 | 实际含义 |
| :-- | :-- | :-- |
| **后端地址** | [http://127.0.0.1:5050](http://127.0.0.1:5050) | 必须`web/app.py` 监听的一|
| **Whisper 模型** | `small` | 越大越准越慢;视频多先用 `tiny` 跑通流|
| **笔记文件。* | `Douyin/` | 相对 Vault 根目录,建议按子类分子文件夹 |

设置页顶部会实时显示**后端连接状。*(● 已连/ 未连接),出问题一眼能看到

## 我打算这样用 个场景框
### 场景一:内容选题池(我实测:23 条视2 小时整理完)

上周五晚上我把抖音收藏夹里攒了三个月的视频全拖了出来—3 条,全是Obsidian、效率工具、AI 工作流的
以前这种事我根本不会干3 条视频,光是「打开→看→复制文案→记要点→存到对应文件夹」这条链就够我放弃三次
这次我把每条分享链接粘贴Douyin Capture 弹窗,选「提取文案」,Whisper 转写完—。*一条大90 秒到 3 分钟**,取决于视频长度3 条视频全部跑完大2 小时
处理完之后,我的 `Douyin/选题/` 文件夹里躺着 23 篇笔记,每条都有标题、话题标签、完整文案和本地视频。我花了 15 分钟扫一遍,挑出 6 条可以立刻写成公众号文章
放在以前,这 6 条选题大概率还躺在微信收藏夹的「稍后在看」里——「稍后」就是「不会」
### 场景二:竞品研究素材
我关注了 7 个同赛道Obsidian 博主,其3 个主要在抖音发内容。他们做的选题、用的案例、切的角度——在公众号后台看不到,但抖音推荐算法天天推给我
装好 Douyin Capture 之后,我建了 `Douyin/竞品/` 文件夹,按账号名分子目录。刷到一条就抓一条,Whisper 转写之后可以全文搜索
上周日我搜了一下「Obsidian 插件」这个关键词—3 条竞品视频的文案里,8 条提到了我还没写的插件。等于别人帮我做了一遍选题调研
### 场景三:方法论学+ 个人反
抖音上有一类博主我不追、但每次刷到都会看完——讲底层方法论的。比如一个做8 年公关的人讲「怎么写回应声明」,一个律师讲「谈判时3 个话术陷阱」
这类视频不看画面也能学到 80%。Douyin Capture Whisper 转写就是干这个的:我把转写出来的文案当文本精读,然后在笔记末尾加一段「我的反思」——「我认同什么」「我反对什么」「我能用在哪儿」
转写后的文案可以全文搜索。哪天写文章想引用那条公关回应声明的方法论,搜一个关键词就能跳出来
### 场景四:灵感碎片
不是每条抓下来的视频都值得写满一整篇笔记。有些视频就一句话让我眼前一亮——一个产品经理讲「用户不需要功能,用户需要结果」,一个设计师讲「好设计就是删到不能再删」
我把这类视频统一丢进 `Douyin/灵感/` 文件夹,不做分类、不写反思。就让它躺在那里。写文章卡壳时翻一翻,经常翻出惊喜
