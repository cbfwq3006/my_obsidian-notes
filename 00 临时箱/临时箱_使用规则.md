# 临时箱使用规则

> 临时箱是你随时随地学习的"收件箱"。
> 看到有启发的文章、突然想到一个有趣的点、听到别人一个有趣的观点 → 立刻记到临时箱 → 晚上空闲时间再整理沉淀。

---

## 四条核心规则

### 规则一：随手记，不纠结分类

临时箱不需要分类，只需要快速记录。分类是后续整理时做的事。

**记录格式**（新建一个 .md 文件，文件名用日期+关键词）：

```markdown
# 2026-07-15_关于XX的灵感

> 来源：微信公众号文章 / 读书 / 突然想到 / 听别人说

## 内容

（原文摘录或你的灵感记录）

## 我的思考

（一句话写你的初步想法）
```

### 规则二：每日清理，不过夜

临时箱是"中转站"，不是"仓库"。内容最多停留 24 小时，就必须被处理到正式位置。

处理流程：
1. 判断这条内容属于哪个**角色**？
2. 判断是**事实性/概念性/程序性**知识？
3. 写入对应位置：
   - 角色内容 → `02 角色体系/[角色名]/专业知识/[三类知识]/`
   - 通用内容 → `01 通用体系/[对应子目录]/`
4. 写入时保留双向链接，关联到知识框架
5. 处理完的文件移动到 `00 临时箱/已归档/`

### 规则三：沉淀时必须思考

从临时箱整理到正式位置时，不是简单的"复制粘贴"，而是要：
- 用自己的话重新表述
- 建立"一拖三"关联：
  - **拖1**：这个新知识属于哪个更大的框架/模型/理论？
  - **拖2**：新知识和哪个已有知识可以相互印证或对比？
  - **拖3**：学了这个知识，产生了什么新问题？

### 规则四：定期回顾已归档

每周回头看一次 `已归档/` 目录，检查：
- 有没有当时觉得有用、现在发现其实没用的？（可以删除）
- 有没有当时没理解透、现在有新感悟的？（补充到正式笔记中）

## 文件命名规范

```
YYYY-MM-DD_关键词.md

示例：
2026-07-15_关于有限选择的灵感.md
2026-07-15_金字塔原理读书笔记.md
```




周亦见方法：
**怎么用 Obsidian + AI 建一个自己的知识库系统**。别被 1600 多行吓到，你先只记住下面这套用法。

**一句话理解**  
这个系统就是把你学到的东西，按“我是谁、我要解决什么问题、这东西以后怎么用”整理起来。不是收藏资料，而是把资料变成以后能直接拿来解决问题的 SOP、方法、清单。

**你每天怎么用**

1. 看到有用的东西，先别分类，直接丢进 `00 临时箱`  
    比如文章、会议纪要、工作方法、别人一句有启发的话，都先放进去。
    
2. 每天或每周让 AI 帮你整理临时箱  
    你可以直接说：
    
    ```
    帮我处理知识库临时箱，把内容按角色和知识类型整理到对应位置。
    ```
    
3. 整理时只问三个问题：
    
    ```
    这条内容属于我的哪个角色？
    它是事实、概念，还是步骤方法？
    以后我遇到什么场景能用它？
    ```
    
4. 最重要的是沉淀成“怎么做”  
    例如不要只存“汇报要有逻辑”，而要存成：
    
    ```
    SOP_向领导汇报一件事.md
    
    1. 先说结论
    2. 再说背景
    3. 再说当前进展
    4. 再说需要领导拍板什么
    5. 最后说下一步安排
    ```
    

**目录你只需要懂这三个**

```
00 临时箱
```

放所有还没整理的东西。你不用想分类，先丢进去。

```
01 通用体系
```

放所有角色都能用的能力，比如：沟通、汇报、时间管理、AI工具、写作、思考方法。

```
02 角色体系
```

放跟你具体身份有关的知识，比如：党建工作人员、办公室人员、母亲、学习者、自媒体博主等。

**最关键的分类**  
你只要会分这三类就行：

```
事实性知识 = 是什么
```

比如名单、时间、政策名称、联系人、数据、案例。

```
概念性知识 = 为什么
```

比如一个模型、一个原理、一个判断标准。

```
程序性知识 = 怎么做
```

比如 SOP、流程、步骤、清单。这个最重要。

**最适合你的简单用法**  
你可以先按工作来用，不要一开始搞太复杂。

每天工作中产生的材料，可以这样处理：

```
今天这些材料，帮我整理进个人知识体系：
1. 哪些是事实性知识？
2. 哪些是概念性知识？
3. 哪些能沉淀成 SOP？
4. 分别建议放到哪个目录？
```

如果你学了一篇文章，就这样问：

```
我刚看完这篇内容，请帮我提炼：
1. 这篇文章最有用的 5 个点
2. 哪些可以变成我工作中的 SOP
3. 应该放到知识库哪个位置
4. 帮我整理成 Markdown 笔记
```

如果你遇到一个工作难题，就这样问：

```
我现在遇到的问题是：【具体问题】
请帮我分析：
1. 这是哪个角色的问题？
2. 我缺事实性、概念性、还是程序性知识？
3. 我应该补什么？
4. 帮我生成一个可执行 SOP。
```

**你先从这 4 个动作练起**

1. 有东西先丢 `00 临时箱`
2. 每天让 AI 整理一次临时箱
3. 所有重要内容尽量变成 SOP
4. 每周看一次：哪些 SOP 真正在工作中用上了

你不用一次学完整份文档。你先记住这句话就够了：

**临时箱收集，角色体系归位，三类知识分类，最后尽量变成 SOP。**
