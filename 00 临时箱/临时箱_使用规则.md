# 临时箱使用规则

> 临时箱是你随时随地学习的"收件箱"。
> 看到有启发的文章、突然想到一个有趣的点、听到别人一个有趣的观点 → 立刻记到临时箱 → 晚上空闲时间再整理沉淀。

---

## 四条核心规则

### 规则一：随手记，不纠结分类

临时箱不需要分类，只需要快速记录。分类是后续整理时做的事。

**记录格式**（新建一个 .md 文件，文件名用日期+关键词）：

```markdown
# 2026-07-15_关于XX的灵感

> 来源：微信公众号文章 / 读书 / 突然想到 / 听别人说

## 内容

（原文摘录或你的灵感记录）

## 我的思考

（一句话写你的初步想法）
```

### 规则二：每日清理，不过夜

临时箱是"中转站"，不是"仓库"。内容最多停留 24 小时，就必须被处理到正式位置。

处理流程：
1. 判断这条内容属于哪个**角色**？
2. 判断是**事实性/概念性/程序性**知识？
3. 写入对应位置：
   - 角色内容 → `02 角色体系/[角色名]/专业知识/[三类知识]/`
   - 通用内容 → `01 通用体系/[对应子目录]/`
4. 写入时保留双向链接，关联到知识框架
5. 处理完的文件移动到 `00 临时箱/已归档/`

### 规则三：沉淀时必须思考

从临时箱整理到正式位置时，不是简单的"复制粘贴"，而是要：
- 用自己的话重新表述
- 建立"一拖三"关联：
  - **拖1**：这个新知识属于哪个更大的框架/模型/理论？
  - **拖2**：新知识和哪个已有知识可以相互印证或对比？
  - **拖3**：学了这个知识，产生了什么新问题？

### 规则四：定期回顾已归档

每周回头看一次 `已归档/` 目录，检查：
- 有没有当时觉得有用、现在发现其实没用的？（可以删除）
- 有没有当时没理解透、现在有新感悟的？（补充到正式笔记中）

---

## 文件命名规范

```
YYYY-MM-DD_关键词.md

示例：
2026-07-15_关于有限选择的灵感.md
2026-07-15_金字塔原理读书笔记.md
```
