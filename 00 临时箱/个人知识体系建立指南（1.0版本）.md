## 工作流程概述

AI 代理执行本指南时，按以下六个阶段顺序执行。**全程有三个暂停点（询问用户）**，其余均由 AI 全自动完成：

| 阶段 | 内容 | 执行方式 |
|------|------|---------|
| **Phase 1** | 初始化仓库：创建 `00 临时箱/`、`01 通用体系/`、`02 角色体系/` 目录结构；生成 `知识体系总纲.md` 和 `临时箱_使用规则.md` | 🤖 全自动 |
| **Phase 2** | 搭建通用体系：创建 `通用体系/` 下所有子目录和索引文件 | 🤖 全自动 |
| **Phase 3** | 搭建角色体系：**先问用户 4-6 个核心角色**，用户回复后全自动创建所有角色目录和框架文件 | ⚠️ 询问用户 → 然后全自动 |
| **Phase 4** | 内容填充：将课程资料自动转换成 Markdown 并写入 Obsidian 对应位置 | 🤖 全自动 |
| **Phase 5** | 设置自动化维护：**询问用户偏好时间**，然后创建定期自动化任务（处理临时箱、周报提醒） | ⚠️ 询问时间 → 然后全自动创建 |
| **Phase 6** | 绑定IMA碎片收集箱：**询问用户是否有IMA账号**，有则引导绑定作为碎片知识入口；没有则跳过 | ⚠️ 询问用户 → 引导绑定或跳过 |

> ⚠️ **关键规则**：除了 Phase 3 询问角色、Phase 5 询问时间偏好、Phase 6 询问IMA账号，其余所有步骤均由 AI 全自动完成，无需再征求用户意见。
> 
> 询问角色的标准话术见「六、分步搭建：角色知识体系构建 → 6.1」。

## 第一部分：认知基础（第1-3课）

### 一、学习的核心本质：为角色赋能

**核心结论**：学习的目的不是"知道更多"，而是"扮演好角色"。

#### 1.1 两个角色

每个人身上都有两个角色：
- **自我角色**：身心健康、情绪管理、终身学习
- **社会角色**：下属、主管、父母、伴侣、创作者……

"过不好这一生"的本质，就是扮演不好现在的、或想成为的那个角色。

#### 1.2 两个学习方向

| 方向 | 说明 | 比喻 |
|------|------|------|
| **自上而下** | 根据角色关键场景，针对性弥补能力缺口，有规划地去学习 | 先列清单再采购 |
| **自下而上** | 随时随地学习，一切人事物都是你角色的学习材料 | 途中发现好东西加入购物车 |

两种方法都要用。最终目的都是：获取角色所需的知识和技能。

#### 1.3 角色梳理法——人事物关系法

AI代理在执行时，必须先问用户4-6个核心角色（标准提问模板见第四节）。

手动梳理方法：

| 维度 | 问题 | 推导角色 |
|------|------|---------|
| **人** | 身边有哪些重要的人？ | 父母→子女角色，配偶→伴侣角色，孩子→家长角色，下属→领导角色 |
| **事** | 每天在做什么核心的事？ | 负责销售→销售负责人，运营公众号→自媒体博主 |
| **物** | 投入了金钱和时间的物品？ | 专业相机→摄影爱好者，编程软件→开发者 |

#### 1.4 学习飞轮模型（底层逻辑）

有效学习必须包含四个环节，**缺一不可**：

```
输入 → 理解 → 沉淀 → 输出
 ↑                    │
 └───── 反馈迭代 ─────┘
```

| 环节 | 知识体系的作用 |
|------|--------------|
| **输入** | 精准导航：明确知识缺口，有目的地获取信息 |
| **理解** | 高效连接：新知识挂接到已有知识网络，快速内化 |
| **沉淀** | 外接大脑：结构化存储，随用随取 |
| **输出** | 系统调用：遇到问题不是靠灵感，而是靠体系 |

> **判断标准**：一个合格的知识体系，必须同时是**精准的学习导航、高效的理解工具、可靠的记忆仓库、实用的问题解决方案**。

#### 1.5 双轨结构：通用体系 + 角色体系

这是整套方法论的骨架。

```
知识体系
├── 通用知识体系（底盘/操作系统）
│   ├── 通用能力：可迁移能力（元认知、执行、沟通、领导）
│   ├── 通用技能：工具使用能力（AI、Office等）
│   └── 通用知识：跨学科基础常识（心理学、经济学、逻辑学等）
│
└── 角色知识体系（武器/应用软件）
    └── 每个角色含三个要素：
        ├── 角色态度：愿景 + 目标 + 当前状态
        ├── 专业技能：达成目标所需的方法论
        └── 专业知识：
            ├── 事实性知识：离散信息点（数据、参数、名单）
            ├── 概念性知识：模型、原理、理论（金字塔原理、SCQA等）
            └── 程序性知识：SOP、步骤、流程、清单（最高优先级）
```

**关键原则**：
- 通用体系决定人生**下限**，角色体系决定人生**上限**
- 通用体系的知识可以从角色实践中**抽象迁移**而来
- **70%功利性学习**（为角色） + **30%非功利性学习**（拓展视野）

#### 1.6 三类知识的定义与优先级

| 类型 | 核心问题 | 定义 | 例子 | 优先级 |
|------|---------|------|------|--------|
| **程序性知识** | 怎么做？ | 可执行的步骤、流程、SOP、检查清单 | 收文办理流程、向上汇报四步法 | ⭐ 最高 |
| **概念性知识** | 为什么？ | 模型、原理、理论、底层逻辑 | 金字塔原理、马斯洛需求层次 | ⭐⭐ 次高 |
| **事实性知识** | 是什么？ | 零散的信息点、数据、案例 | 政策文件名称、关键人物关系 | ⭐⭐⭐ 基础 |

**判断口诀**：
- 不知道怎么做 → 缺**程序性知识**（去看SOP、教程、指南）
- 知道步骤但做不好/不理解 → 缺**概念性知识**（去读经典教材、深挖底层逻辑）
- 都会了但没东西用 → 缺**事实性知识**（去收集案例、数据、素材）

> **最终目标**：一切知识最终都要沉淀为**可执行的程序性知识（SOP）**。概念性知识和事实性知识是支撑程序性知识落地的"弹药"。

### 六、分步搭建：角色知识体系构建（⚠️ AI 询问点：用户角色）

> **课程原文（第六课）**：
> 新建对应角色的笔记本（如"公众号博主""销售""宝妈"）
> 按专用知识体系构成，建立三个分区组：**态度、专业技能、专业知识**
> 专业知识下分：事实性知识、概念性知识、程序性知识

#### 6.1 ⚠️ AI 询问点：先问用户 4-6 个核心角色

**⚠️ 此步骤不可跳过！** 在搭建任何角色体系之前，AI必须先向用户提问。

**标准提问模板**：

> "在开始搭建之前，我需要先了解：你现在生活中有哪些核心角色？请列出**4-6个**你最想用知识体系来管理的角色。
> 
> 这些角色可以是职业身份（如产品经理、销售负责人）、家庭身份（如父亲、丈夫）、副业或兴趣身份（如自媒体博主、摄影爱好者）；也可以把某个持续的挑战当成角色（如备考CPA、学英语）。
> 
> 请按重要性排序，每个角色用一句话说明定位。例如：
> - P0 产品经理：负责公司核心产品线，需要提升向上汇报和需求分析能力
> - P1 父亲：有一个6岁的孩子，希望解决亲子沟通和教育问题
> - P2 自媒体博主：副业创作，目标是公众号涨粉到10万
> - P3 养身体：最近体检多项超标，需要系统管理饮食和运动"

**AI收到回复后**：
1. 用户列了 >=4 个角色 → 全部采纳，按用户给定的优先级排序
2. 用户列了 <4 个角色 → 追问"还有没有其他你想管理的角色？哪怕是暂时的目标（如考证、学技能）也行"
3. 所有角色统一编号：P0（最高优先级）、P1、P2……**P3 固定留给"自我角色"**（身心健康与个人成长，一切角色的根基）

> **✅ 用户回复角色后，以下所有步骤全自动执行，无需再询问用户。**
> AI 依次自动完成：创建角色目录结构 → 写入知识框架文件 → 填充角色态度模板 → 进入 Phase 4 内容填充。

#### 6.2 为每个角色搭建目录结构（🤖 用户已提供角色，以下全自动执行）

对每个角色，创建以下结构（**对照课程原文**）：

```
角色体系/[角色名]/
├── [角色名]_知识框架.md    ← 该角色的索引入口（必须创建）
├── 角色态度/
│   └── 角色态度.md            ← 愿景、目标、当前状态
├── 专业技能/
│   └── (技能笔记).md         ← 方法论笔记
└── 专业知识/                ← ★ 只有这里才分三类文件夹 ★
    ├── 事实性知识/
    │   └── (事实性笔记).md
    ├── 概念性知识/
    │   └── (概念性笔记).md
    └── 程序性知识/            ← 最优先建，SOP精华
        └── (SOP文件).md
```

#### 6.3 角色三要素的填写规范（🤖 全自动：用 AI 推断+默认值填充）

| 要素 | 说明 | 填写规范 |
|------|------|---------|
| **角色态度** | 愿景 + 目标 + 当前状态 | 写清楚：我想把这个角色做到什么水平？半年/一年的具体目标是什么？ |
| **专业技能** | 达成目标所需的方法论 | 列出1-3项核心技能，每项技能创建一个笔记文件 |
| **专业知识** | 支撑技能落地的基础信息 | 按事实性/概念性/程序性三类分别存储 |

**示例**（自媒体博主角色）：

```
角色态度：
  愿景：用接地气的文字，影响10万普通人，帮他们提升思考能力
  短期目标：半年公众号涨粉10万
  里程碑：达到50万粉丝

专业技能：
  - 内容创作（选题、结构、表达）
  - 账号运营（数据分析、读者互动、排版）

专业知识/程序性知识：
  - SOP_选题到发布.md（找选题→列提纲→写初稿→配图→校对→发布→复盘）
专业知识/概念性知识：
  - SCQA故事模型.md
  - 算法推荐原理.md
专业知识/事实性知识：
  - 平台规则.md
  - 热点话题清单.md
```

## 第三部分：落地执行（第7-12课）

### 七、精准定位：3步找到你的学习重点

> **课程原文（第七课）**：梳理角色问题 → 梳理所需知识 → 找到知识差距

#### 7.1 两个学习方向（复习）

| 方向 | 说明 | 对应 |
|------|------|------|
| **自上而下** | 根据角色需要，有规划地去学习（主动寻找知识漏洞） | 功利性学习 |
| **自下而上** | 随时随地学习，一切人事物都是你角色的学习材料 | 非功利性学习 |

就像超市买菜：有人先列清单再采购（自上而下），有人途中发现好东西也加入购物车（自下而上）。

#### 7.2 三步梳理法（对标课程原文）

**第一步：梳理各角色面临的问题**

问自己：我这个角色，当前最头疼的3个问题是什么？

示例（公众号博主角色）：
- 问题1：定位不清晰
- 问题2：创作没灵感
- 问题3：变现路径不清晰

**第二步：梳理解决问题所需的知识**

解决问题需要**四类知识**（课程原文）：
- 角色知识体系中的三类：事实性知识、概念性知识、程序性知识
- 通用知识（心理学、经济学等）

**第三步：找到自己的差距（知识漏洞）**

| 表现 | 缺什么知识 | 怎么补 |
|------|------------|---------|
| 不知道怎么做 | 缺**程序性知识** | 去学步骤、流程、SOP |
| 知道步骤但做不好/不理解 | 缺**概念性知识** | 去读经典教材、深挖底层逻辑 |
| 都会了但没东西用 | 缺**事实性知识** | 去收集案例、数据、素材 |

> **课程重点**：概念性知识不要小瞧！同样的方法，新手和老手功力完全不同，区别就在概念性知识（对原理的深刻理解）。

#### 7.3 拆分思维（课程核心方法论）

大目标拆成可执行的小单元。

示例：公众号博主"定位"问题 → 拆成：
1. 列出可能的定位（缺**程序性知识**：不知道步骤）
2. 判断什么才是好定位（缺**概念性知识**：不知道标准）
3. 验证定位是否符合市场（缺**事实性知识**：缺少案例和数据）

**每遇到不会的，就继续拆分**，直到把问题彻底解决。

AI辅助提示词（T01）：

```
我目前的角色是：【角色名】
面临的核心问题是：【列出3个主要问题】

请帮我分析：
1. 解决每个问题，分别需要什么知识？（按事实性/概念性/程序性分类）
2. 我目前最缺的是哪一类知识？
3. 针对最缺的知识类型，推荐3个具体的学习资源。
```

### 八、计划制定：可落地的学习计划3步法

> **课程原文（第八课）**：优先级 → 材料方法 → 时间节点

#### 8.1 三个步骤搞定学习计划

**第一步：明确优先级**

根据每个角色所面临问题的**紧急程度**和**重要程度**来安排学习顺序。

| 维度 | 说明 |
|------|------|
| **紧急程度** | 问题的时间限制（不解决会多快出问题？） |
| **重要程度** | 不解决问题带来的损失？解决了获得的收益？ |

→ 打分排序，优先学分数最高的。

⚠️ **提醒**：不要为了逃避问题而把顺序往后排。你迟早要面对。

**第二步：明确材料与方法**

（1）学习材料分类（课程原文）：

| 类型 | 说明 | 示例 |
|------|------|------|
| **输入型** | 向外的学习 | 书籍（工具书/理论书）、网络（AI/专业社区）、高手（付费咨询/课程） |
| **输出型** | 向内打磨 | 实践（以实际问题为材料）、输出（写教程/教别人/写文章） |

（2）材料选择四原则（课程原文）：

| 原则 | 说明 | 判断标准 |
|------|------|---------|
| **与能力匹配** | 不要小马拉大车 | 翻开第一页是"津津有味"还是"硬着头皮"？后者立刻换 |
| **与问题匹配** | 紧急问题选拿来能用的，长期问题选底层逻辑 | 下周交年终总结→搜模板；想提升写作→读《金字塔原理》 |
| **多材料验证** | 同一问题至少看3个不同来源 | 3个高手都提了同一个点 → 这就是真理 |
| **含输出/实践** | 通过实践、输出倒逼输入 | 学完立刻写一篇教程，或教别人 |

**第三步：明确时间节点**

| 时间类型 | 说明 | 用法 |
|---------|------|------|
| **系统性时间** | 整块较长时间（如每晚） | 用于深度学习（看书、听课） |
| **碎片化时间** | 零散时间（等车、走路） | 用于轻量化学习（听小课、刷笔记） |

示例（销售知识学习计划）：
- 一个月内，用每晚的系统性时间看书听课
- 这月的碎片休息时间，网上刷文章并收藏，再找系统性时间专门做笔记

#### 8.2 AI辅助制定计划提示词（T02）

```
基于我的角色【角色名】和面临的核心问题【列出问题】，
请帮我制定一个为期【X周】的学习计划：

1. 按优先级排序，列出我最需要学习的3个知识点
2. 为每个知识点推荐：输入型材料（书/课/文章）和输出型材料（实践/教别人）
3. 帮我把时间分配好：哪些用系统性时间，哪些用碎片化时间
4. 给出具体的每周任务清单（细化到"周一晚上：读XX书第3章"）
```

### 九、高效输入：筛选→粗加工→精加工阅读模型

> **课程原文（第九课）**：核心围绕知识漏洞解决实际问题，而非逐字逐句阅读。

#### 9.1 三步阅读模型

```
筛选（约5%内容） → 粗加工（提炼知识） → 精加工（深度理解）
```

**第一步：筛选**

- 快速浏览材料（目录、自序），标注有用内容（通常仅 **5%**）
- **同时选择多份材料交叉阅读**，相互验证补充，避免单一材料的局限性
- 围绕你的知识漏洞："这本书能解决我的哪个具体问题？"

示例：想学习"正确定位" → 迅速把书扫一遍 → 标注出与"定位"相关的内容范围 → 一本书可能只有5%需要深加工。

**第二步：粗加工**

对筛选出的内容进行初步阅读，**提炼四类知识**：

| 提炼目标 | 说明 | 示例 |
|---------|------|------|
| **程序性知识** | 可执行的步骤、流程 | 定位的三步法 |
| **概念性知识** | 模型、原理、理论 | 什么是好定位的标准 |
| **事实性知识** | 零散的信息点、数据 | 平台规则、热点话题 |
| **重要案例** | 帮助理解的真实例子 | 某博主的成功定位案例 |

⚠️ **不需要每种知识都提炼**，根据你的目的灵活提炼：
- 知道步骤但做不好 → 重点提炼**概念性知识**（好定位的标准是什么？）
- 完全不知道怎么做 → 重点提炼**程序性知识**（定位的步骤）

**第三步：精加工**

深入理解知识，解决"每个字都认识，连起来不懂"的问题。

**精加工五法（课程原文"七多理解法"的实操版）**：

| 方法 | 说明 | 示例 |
|------|------|------|
| **多例子** | 用具体案例理解抽象理论 | 听不懂"商业模式"？代入楼下煎饼摊、零售店 |
| **多知识关联** | 把新知识和旧知识进行关联 | "商业模式"和"战略"有什么关系？和"用户需求"呢？ |
| **多材料阅读** | 阅读多个来源的材料 | 这本书没懂的地方，另一本书可能讲得特别清楚 |
| **多问为什么** | 深入追问底层逻辑 | "为什么要七分热？十分不行吗？" → 搞懂烹饪底层逻辑 |
| **多视角** | 从不同角度分析知识 | 正面、反面、不同用途和视角，看到局限性 |

> **课程金句**：书读百遍，其义自见。没读懂时，不妨多读几遍。

#### 9.3 AI辅助阅读提示词

**筛选阶段（T03）**：
```
我要解决的知识漏洞是：【具体描述】
请帮我快速筛选下面这段内容中，对解决我的问题最有价值的5%：
【粘贴内容或上传文件】
```

**粗加工阶段（T04）**：
```
我从【材料来源】中筛选出了以下内容，目标是学习【程序性知识/概念性知识/事实性知识】：
【粘贴筛选出的内容】

请帮我：
1. 提炼出所有的步骤/流程/模型/原理/数据
2. 按"事实性/概念性/程序性"三类分好
3. 用我自己的话重新表述一遍
```

**精加工阶段（T05）**：
```
我正在学习【知识点】，但理解还不够深。
请用以下方法帮我精加工：
1. 举3个生活中的具体例子
2. 和我已有的知识【列出已有知识】建立关联
3. 回答我的追问：【提出3个"为什么"问题】
```

### 十、科学沉淀：知识分类存储与管理技巧

> **课程原文（第十课）**：分门别类把知识放到对应角色的专业知识里。

#### 10.1 沉淀的核心原则

**重点永远是程序性知识**——因为我们学习的目的是应用。只有应用，你才能让知识长成你身体的一部分。

#### 10.2 表格化沉淀法（课程原文推荐）

在Obsidian中创建笔记，用**三栏表格**记录：

```
| 总步骤 | 细分步骤 | 应用体会 |
|---------|---------|---------|
| 第一步：XXX | 1. XXX<br>2. XXX | 【实践后填写】 |
| 第二步：XXX | 1. XXX<br>2. XXX | 【实践后填写】 |
```

- **总步骤**：承载解决问题的全过程（程序性知识）
- **细分步骤**：再拆分，更可执行
- **应用体会**：每次实践之后的感悟（**这是知识内化的关键！**）

如果内容很多，也可以**不用表格**，而是每个步骤单独建一个文件。

#### 10.3 文件管理（课程原文）

除了笔记，还可能有电子书、Word、Excel等文件。

两个办法：
1. **直接把文件传到云端笔记本**（适用于文件不多的角色）
2. **在本地按角色管理文件**（用Everything等工具快速检索）

> **课程建议**：强烈推荐安装一个可以一键检索电脑文件的软件，比如Everything。你只需要输入文件名的关键字，它就能帮你迅速找到并打开。

#### 10.4 备份

用云盘（如百度云）备份你的重要文件，防止系统崩溃。

### 十一、实践转化：3种知识应用方法

> **课程原文（第十一课）**：知识沉淀完了，下一步就该应用了，不然就会躺着吃灰。

#### 11.1 三种应用方法

| 方法 | 说明 | 课程原文对应 |
|------|------|---------------|
| **落地实践** | 去解决生活中的实际问题 | 把知识体系里尘封已久的知识，用各种方法表达出来 |
| **将知识讲给他人（费曼学习法）** | 从自我输出到讲给外行，通过输出暴露知识漏洞 | 费曼学习法有三个层次（见下） |
| **模拟实战** | 设置虚拟场景和问题，模拟知识应用过程 | 复习时给自己设置虚拟场景："如果我遇到xxx这样的问题，会怎么运用xx知识来解决？" |

#### 11.2 费曼学习法三层次（课程原文）

| 层次 | 说明 |
|------|------|
| **第一层** | 单纯的输出，没有输出对象。就是讲出来或写出来给自己。 |
| **第二层** | 有输出对象，输出对象们对你的领域也有一定的了解，比较容易懂你在说什么。 |
| **第三层** | 有输出对象，并且他们是对你的领域完全不了解的人（比如一个小孩子）。你要把你的知识，给他们讲懂。这就特别考验你对知识本质的理解。 |

#### 11.3 模拟实战的意义（课程原文）

> 我们更强调在真实的场景中去应用知识，但是，很多人的问题就在于，真正遇到问题时，想不到要用什么知识来解决。而这，就是模拟实战的意义。

**做法**：复习某个知识点时，去给自己设置一个虚拟场景和问题，或者回忆之前的某件具体事情，问自己："如果我遇到xxx这样的问题，会怎么运用xx知识来解决它呢？"

如果不断重复模拟实战，你会更有可能在之后的真实战场中，及时反应，并调用知识解决问题。

### 十二、高效复习：激活知识的4大核心方法

> **课程原文（第十二课）**：复习可解决四大问题：加深知识记忆与理解、促进知识应用、让知识体系更有序、提升知识可迁移性。

#### 12.1 两个复习时间

| 时间类型 | 说明 |
|---------|------|
| **专用时间** | 每周制定计划，针对性复习特定板块知识 |
| **碎片时间** | 等车、走路等零散时间，随时复习知识体系 |

#### 12.2 四个复习方法（课程原文）

| 方法 | 说明 | 怎么做 |
|------|------|------|
| **自我测试** | 通过自问自答测试，分为增强记忆型和增强理解型 | 不断给自己设置问题→自问自答，一旦回答不上来，就开始回顾笔记或者进行新一轮学习 |
| **知识输出** | 把知识讲给他人、写文章、发朋友圈 | 费曼学习法三层次 |
| **模拟实战** | 设置虚拟场景和问题 | 见11.3节 |
| **整理体系（核心！）** | 定期整理知识体系，抽象程序性知识形成通用方法，建立概念性知识关联模型 | 见12.3节 |

#### 12.3 整理体系的两个作用（课程原文重点）

**作用一：让知识体系更加有序**

> 长时间不整理知识体系，随着记录的知识越来越多，你的体系几乎一定会越来越乱。你必须像定期打扫房间一样，定期整理你的知识体系，从而让它更简洁，你在使用时也会更愉悦。

**作用二（更强！）：迁移知识**

> 对于程序性知识，在整理体系时，你可以对流程进行抽象。
> 比如，你做了一个销售某电子产品的流程式知识体系，你就可以把这个销售流程进行抽象、加工，提炼出更加"高级"的知识，比如"如何读懂对方需求"、"如何掌握别人的心理"、"如何说服别人行动"。而这些"高级知识"，就可以应用到其他完全不同的领域。

**概念性知识的迁移**：

> 对于这类知识，你在整理体系时，要做到：**建立模型**。
> 说人话就是：不断建立知识之间的关联，形成一个整体。
> 建议：你最终要交付每个领域的各种可视化的模型。试着这样做：把你学到的各种知识都写到一个白板上，它们可能是概念、模型、公式、理论等，然后不断画出它们之间的关联。

**底层逻辑**：

> 然后，你可以通过自己抽象，也可以直接去学习经典的理论，将模型上升到人性这一更为抽象的层面，你甚至可以上升到哲学层面。
> 这样，你一定会对这些知识有更为本质的认知。你也会更容易将其迁移到其他领域。

#### 12.4 复习的用途总结（课程原文）

| 用途 | 说明 |
|------|------|
| 加深记忆理解 | 时常复习，对知识的掌握，印象会更深、理解会更深 |
| 促进应用 | 复习时主动思考"这个知识可以用到哪里" |
| 优化体系秩序 | 定期整理，知识体系更有序 |
| 提升迁移能力 | 抽象程序性知识、建立概念性知识模型，提升可迁移性 |

## 第四部分：进阶优化（第13-15课）

### 十三、系统思维：打造互联互通的知识网络

> **课程原文（第十三课）**：用系统思维看待知识，抛弃散点思维，建立知识的流程化、模型化认知。

#### 13.1 从"建"到"拼"：系统思维的本质

前十二课我们一直在"拆"：把建立知识体系这件事，拆成一个个具体的动作、一堂堂独立的课程。

但今天，我们要做一件相反的事：**把它们再拼回去**。

就像你手里有了一堆拼图块，如果只看单块，你永远不知道它是什么。只有把它们拼在一起，你才能看到完整的画面。那才是你真正的"知识体系"。

**系统思维**，就是把拼图拼在一起的能力。

#### 13.2 回望：十二节课共同完成了什么？

把前十二课，想象成一张**作战地图**：

| 课程 | 对应作战环节 |
|------|------------|
| 第1课：学习本质 | 确定"为谁而战"——你的角色 |
| 第2课：学习飞轮 | 理解"战争规律"——输入→理解→沉淀→输出 |
| 第3-5课：双轨体系 | 绘制"战区地图"——通用体系与角色体系的骨架 |
| 第6-7课：找漏洞、定计划 | 制定"作战计划"——找差距、排优先级 |
| 第8-9课：高效阅读、萃取SOP | 演练"单兵技能"——把书读薄再读厚 |
| 第10-11课：输出、复习 | 完成"战后总结"——输出倒逼输入、复习保持飞轮惯性 |
| 第12课：系统梳理 | 打造"互联互通"——整理体系、迁移知识 |

如果单看每一块碎片，你可能只觉得"哦，这是个有用的方法"。

但把它们拼在一起，你会发现：**这十二节课，其实只是在反复打磨一件事——让你的"学习飞轮"转起来**。

#### 13.3 系统思维的三个核心认知

**认知一：学习的飞轮，必须围绕你的核心角色来转动**

> 没有角色，飞轮就是空转。

角色，就是飞轮的中心轴。没有这根轴，轮子转不起来，或者转着转着就散了。

比如你是个团队主管：
- 输入时 → 带着"这个知识能帮我管好团队吗"的筛子
- 理解时 → 把它和"小王最近总迟到"这种具体问题联系起来
- 沉淀时 → 把它归入"领导力"这个文件夹
- 输出时 → 在明天的周会上试着用一下

**角色，让飞轮的每一圈都有了意义。**

**认知二：双轨体系，就是学习飞轮的载体**

- 通用体系 = 底座（飞轮的底盘）
- 角色体系 = 转盘（飞轮的叶片）
- 三类知识（事实性/概念性/程序性）= 飞轮上的叶片，每一片都在推动飞轮加速

**认知三：让飞轮转起来的"动力系统"，就藏在第6-11课里**

| 课程 | 对应飞轮动力 |
|------|------------|
| 第6课：找到知识漏洞 | 找到飞轮堵点（疏通它，飞轮才能继续转） |
| 第7课：制定不痛苦的学习计划 | 让飞轮转起来不费劲（把大任务拆小，塞进生活缝隙） |
| 第8-9课：高效输入与萃取 | 飞轮的"第一圈"（输入和理解） |
| 第10课：输出与应用 | 飞轮的"第二圈"（输出倒逼新一轮输入） |
| 第11课：高效复习 | 飞轮的"惯性维持系统"（保持转动，不减速） |

#### 13.4 系统思维的实操：随时随地刻意练习

> **课程金句**：我建议你在做任何一件事的时候，都能习惯性地问自己一句：**这件事中，我能用到哪些知识？**

然后，选择其中一项知识，进行**刻意练习**。

**刻意练习的两个场景**（课程原文）：

| 场景 | 做法 | 复盘重点 |
|------|------|------------|
| **可以照着笔记做**<br>（如写公文、做PPT） | 打开Obsidian中的SOP → 一步一步照着做 → 做完后记录感受 | 步骤本身对不对？需不需要改？ |
| **不能照着笔记做**<br>（如实时沟通、开会发言） | 行动前脑中过一遍目标步骤 → 事后立即回忆对照 | 做的时候真的用上了吗？如果没闪过，为什么？怎么让它下次能闪？ |

**复盘迭代（五问复盘法）**：

```
问1：刚才我用的是哪个SOP的哪个步骤？
问2：我实际做了什么？（如实描述，不要美化）
问3：和SOP上的对比，哪里一样？哪里不一样？
问4：不一样的地方，是SOP有问题，还是我执行有问题？
问5：如果我再来一次，我会在哪一步做什么改变？
```

**迭代记录**（必须写进Obsidian！）：

在SOP文件底部添加表格：

```markdown
## 迭代记录

| 日期 | 使用场景 | 效果 | 需要改进的地方 |
|------|---------|------|--------------|
| 06-14 | 周二跟张总做周报时刻意用了第一步"结论先行" | 张总没打断我，但说完后他追问了数据 | 下次准备时把数据提前整理好，放在话术第二句 |
```

#### 13.5 知识内化的四个阶段

| 阶段 | 标志 | 时间预估 | 操作 |
|------|------|---------|------|
| **新手期** | 必须打开Obsidian照着做 | 前3-5次 | 允许对着清单一步步来 |
| **熟练期** | 不用看笔记也能做，但偶尔会漏步骤 | 第5-15次 | 事后复盘对照，补漏 |
| **自动化期** | 不假思索就能做对，成为肌肉记忆 | 第15-30次 | 可以把这个SOP归档为"已内化" |
| **迁移期** | 不看笔记，且能根据不同场景灵活调整 | 30次以上 | 把这个SOP的通用原理存入通用体系，迁移到其他角色 |

> **核心认知**：SOP只是拐杖，最终目的是**丢掉拐杖还能走稳**。当一个SOP进入"自动化期"，就可以开始聚焦下一个SOP了。

### 十四、AI赋能：全流程学习效率升级

> **课程原文（第十四课）**：AI可在四个方面辅助学习——制定计划、输入知识、沉淀知识、复习知识。

#### 14.1 AI辅助学习的四个方面

| 环节 | AI能做什么 | 具体做法 |
|------|-----------|---------|
| **制定学习计划** | 帮助定位知识漏洞，推荐学习资源 | 问AI："我要提高xx能力，目前知识体系里还缺少哪一环节？我需要学什么？" |
| **输入知识** | 筛选、粗加工、精加工全流程辅助 | 筛选：把文本/电子书扔给AI，1秒选出需要的内容范围<br>粗加工：让AI把内容整理成有结构、有条理的知识点<br>精加工：让AI举例子、打比方、给出参考资料 |
| **沉淀知识** | 帮助分类存储，萃取SOP | 把信息投给AI，让它整理出事实性、概念性、流程性知识 |
| **复习知识** | 帮助测试、模拟实战、提炼迁移 | 让AI基于知识体系出题测试<br>让AI出模拟场景，你用知识来解决，它来批改<br>让AI帮你做提炼、抽象，使知识更容易迁移 |

#### 14.2 AI使用的三大陷阱（课程重点警告！）

> **课程原文**：AI是强力工具，但用错了反而降低学习效果。

| 陷阱 | 表现 | 解法 |
|------|------|------|
| **过度依赖AI**<br>（最大陷阱！） | 把整本书丢给AI生成摘要，看完摘要就觉得自己"读完了"。让AI帮你拆解所有文章，拆完就存入笔记库，从不自己思考。 | **AI帮你省掉的是体力活，不是脑力活。** "判断这个知识值不值得学"、"这个SOP适合我的场景吗"、"复盘时发现的问题该怎么改进"——这些需要你亲自做的事，AI永远替代不了。 |
| **提示词太模糊** | 用"帮我总结一下这篇文章"这种模糊提示词，得到的结果泛泛而谈、抓不住重点。 | 提示词必须具体，明确告诉AI："你是谁（角色）、要什么（输出格式）、不要什么（剔除的东西）"。 |
| **存了不回头看** | AI拆解得再好、SOP生成得再漂亮，存进知识库后就再也没打开过。 | 知识体系的价值不在于"存了多少"，而在于"用了多少"。**记住：事前翻牌 + 事后对照，是让AI辅助的知识体系活起来的唯一方法。** |

#### 14.3 AI辅助的正确姿势（课程结论）

> **利用AI辅助学习的核心是什么？抓住学习底层逻辑，灵活设计应用方法。**

- 你负责**判断、选择和创造**。
- AI只负责**搜索、整理和结构化**。
- 每次AI辅助完成后，**必须自己做一次**（输出/实践），才能内化成自己的。

### 十五、持续迭代：知识体系的长期维护与优化

> **课程原文（第十五课）**：系统梳理知识体系的用法，讲把知识体系更好落地需要注意的5件事。

#### 15.1 定期制定学习计划

> **课程重点**：一定要定期制定学习计划。最好一周一次，至少一月一次。

**两个建议（课程原文）**：

| 建议 | 说明 |
|------|------|
| **针对问题，功利性学习** | 用之前介绍的方法，对每个角色要面临的问题进行梳理，并识别自己的知识漏洞，再展开针对性的学习。这是最基本的要求。 |
| **围绕体系，非功利性学习**<br>（进阶建议！） | 若我们只针对问题进行学习，难免会受制于问题本身，视野、见识打不开。因此，建议在制定计划时，若学有余力，去进行一些**非功利性学习**。这种学习，目的就在于：**去偶遇一些对你的角色有帮助的知识**。 |

示例：若你是一个宝妈，你就可以计划在碎片时间没有目的地去听听育儿类的播客、或者听几本教育类书籍，没准就能学到一个宝贵经验。

#### 15.2 随时随地学习

> **课程建议**：准备一个类似于备忘录的工具，随时随地记下你觉得有启发的灵光一闪。

**做法**：
1. 看到有启发的文章、突然想到一个有趣的点、听到别人一个有趣的观点 → 立刻记到备忘录（如IMA、Obsidian手机版）
2. 到了晚上空闲时间再整理，一条一条进行思考，并沉淀到知识体系中

**两个好处**：
1. 随时的学习补充知识
2. 每次沉淀，都需要打开笔记本 → 意味着之前的知识又会被过目一遍 → **这又达到了复习的效果！**

#### 15.3 定期复习知识体系

> **课程原文**：时常复习，你对知识的掌握，印象会更深、理解会更深、应用会更容易。你的知识体系也会更加有序、更加容易迁移。

用**自我测试、知识输出、模拟实战、整理体系**四种方法，激活知识体系。

#### 15.4 系统梳理与迁移（课程最核心的进阶心法！）

> **课程原文**：整理体系，其实有两个作用。第一个很明显，就是为了让知识体系更加有序。但还不是最关键的。"整理体系"还有一个更强的作用：**迁移知识**。

**程序性知识的抽象与迁移**（课程原文）：

> 对于程序性知识，在整理体系时，你可以对流程进行抽象。
> 比如，你做了一个销售某电子产品的流程式知识体系，你就可以把这个销售流程进行抽象、加工，提炼出更加"高级"的知识，比如"如何读懂对方需求"、"如何掌握别人的心理"、"如何说服别人行动"。而这些"高级知识"，就可以应用到其他完全不同的领域。比如销售保险、与合作伙伴谈判、与领导沟通等。
> 
> 这些场景在本质上，与销售电子产品特别类似，它们都需要与人进行沟通、最终解决某个问题。
> 
> **这就是知识的可迁移性。若你的迁移能力特别强，你就能达到一通百通的境界——"四两知识，拨千斤困难"。**

**抽象的方向**：将程序性知识抽象成**通用能力/通用技能/通用知识**，存入通用体系。

**概念性知识的模型化**（课程原文）：

> 对于概念性知识，你在整理体系时，要做到：**建立模型**。
> 说人话就是：不断建立知识之间的关联，形成一个整体。
> 
> 从实操的角度来说，我建议你用**底层逻辑为核心**来建立知识之间的关联。也就是以经典理论为树干，将其他知识看成其树枝、树叶。

**两个关键**（课程原文）：
1. 建立知识的关联，形成模型
2. 抽象出模型的底层逻辑

> 比如，本门课是讲学习方法的，讲了很多技巧方法，但这一切的背后，都是围绕一个底层逻辑：即之前讲到的**学习飞轮：输入→理解→沉淀→输出**。
> 你之后学到的各种学习技巧，也都可以往这个底层逻辑里面填。

**抽象出底层逻辑之后**：同样，放到**通用知识体系**中的通用知识这个分区中。

#### 15.5 终身学习的的心态

> **课程金句**：人的努力，最怕的就是：**低质量重复**。那为何会低质量重复？关键就在于，没有新的优质信息的摄入。而破解之道只有一个：**终身学习**。

终身学习不是口号。很多人虽然总嘴上说自己是终身学习者，可事实是他们每天都在自己的舒适圈里学习，不基于自己的实际问题学习。一学就会，一干就废。

合理地制定学习计划，可以解决这个问题。

> **课程最后一句话**：能读完这十二课的你，已经超越了绝大多数人。但超越不是终点，行动才是。你的任务，不是再往脑子里装更多东西，而是让你已经拥有的东西，开始自动运转。

## 补充章节（非课程原章节，实践精华）

> 以下三章是课程方法论的**实践延伸**，在15节课程中没有作为独立章节出现，但是对于真正"用起来"非常关键。建议在对标课程主线搭建完成后，再阅读这三章。

### 补一、快速查阅策略

知识体系的命门不是"存了多少"，而是"用的时候能不能一秒找到"。如果每次查笔记都要翻半天文件夹，体系就是死的。

#### 补1.1 三层查阅体系：从快到深

| 层级 | 方式 | 适用场景 | 操作 |
|------|------|---------|------|
| **第一层：秒查** | Obsidian 全局搜索 (`Ctrl+O`) | 记得关键词，直接跳到目标笔记 | 输入文件名关键词，回车即达 |
| **第二层：速览** | 知识框架入口 → [[双向链接]] | 知道属于哪个角色/领域，需要导航 | 打开总纲 → 点角色框架 → 点具体笔记 |
| **第三层：深挖** | 反向链接面板 + 图谱视图 | 探索"这个知识连着哪些知识" | 打开笔记 → 右侧反向链接面板 → 查看谁引用了这篇 |

#### 补1.2 日常查阅的四个标准入口

AI代理在搭建时，必须确保以下四个入口文件内容完整：

```
入口1: 知识体系总纲.md（根目录）
  → 角色地图、快速导航 [[链接]]、工作流概览
  → 用法：每天打开Obsidian第一眼看到的页面

入口2: 通用体系_知识框架.md（通用体系/）
  → 三大板块索引 + 各子领域 [[链接]]
  → 用法：需要跨角色通用能力时从这里进

入口3: [角色名]_知识框架.md（角色体系/[角色名]/）
  → 该角色的态度、技能、三类知识全索引
  → 用法：扮演某角色前/后，从这里翻牌和对照

入口4: 程序性知识目录（角色体系/[角色]/专业知识/程序性知识/）
  → 所有SOP的一览页（可通过 Obsidian 的 MOC 笔记汇总）
  → 用法：执行任务前快速扫一眼相关SOP
```

#### 补1.3 MOC（Map of Content）笔记：手工打造知识地图

除了文件夹自动排序，Obsidian 的核心优势是可以用 **MOC 笔记（内容地图）** 手工编织查阅路径。

**操作方法**：在关键目录中创建一个 MOC 笔记，手动用 [[双向链接]] 聚合该目录下所有子笔记。

**示例：程序性知识 MOC**（在 `角色体系/[角色]/专业知识/程序性知识/` 下创建 `[角色名]SOP总览.md`）：

```markdown
# [角色名] SOP 总览

## 场景A
- [[SOP_场景A步骤1]]
- [[SOP_场景A步骤2]]

## 场景B
- [[SOP_场景B步骤1]]
- [[SOP_场景B步骤2]]
```

**MOC 的核心价值**：
- 文件夹只能按一种逻辑排序（如按知识类型），MOC 可以按**任意维度**重新组织（按场景、按难度、按使用频率）
- 一个笔记可以出现在多个 MOC 中，就像一本书可以在图书馆的多个索引中出现
- MOC 就是你的个性化"搜索引擎优化"——让你用直觉就能找到想要的知识

### 补二、建立新旧知识的深度关联

知识体系的底层操作系统是**网络**，不是**仓库**。仓库里的东西放进去就忘了，网络里的节点越多、连线越密，新的知识就越容易"挂"上去——这就是知识的复利效应。

#### 补2.1 新知识落地的"一拖三"法则

每次存入一份新笔记，**强制做三件事**——不是可选项，是必做项。

```
新知识笔记
    │
    ├── 拖1 ──→ [[已有概念1]]：这个新知识和它什么关系？
    ├── 拖2 ──→ [[已有概念2]]：这个新知识能不能解释/补充它？
    └── 拖3 ──→ [[新产生的问题]]：学了之后产生的新疑问
```

**"一拖三"的执行标准**：

| 关联类型 | 必须回答的问题 | 写入笔记的位置 | 示例 |
|---------|--------------|---------------|------|
| 拖1：上位关联 | 新知识属于哪个更大的框架/模型/理论？ | 概念性知识 > 知识关联 | 学了"有限选择"→ 关联到 [[决策心理学]] |
| 拖2：平行关联 | 新知识和哪个已有知识可以相互印证或对比？ | 概念性知识 > 知识关联 | 学了"有限选择"→ 关联到 [[非暴力沟通]] 中的"提供选择" |
| 拖3：导出关联 | 学了这个知识，产生了什么新问题？ | 笔记底部 | 学了"有限选择"→ 新增问题："教育场景下'有限选择'有没有副作用？" |

#### 补2.2 跨角色知识网络：让一个知识服务多个角色

**核心逻辑**：知识在角色A中产生 → 提炼通用原理 → 迁移到角色B/C → 存入各自的程序性知识 → 用 [[双向链接]] 串联。

**完整操作链**（以"有限选择"从育儿迁移到管理为例）：

```
Step 1：在[丈夫/父亲]角色的实践中验证
  场景：让孩子在两件衣服中选一件（红?蓝?），减少对抗
  ↓
Step 2：提炼通用原理
  本质："赋予控制感，减少反抗心理"
  ↓
Step 3：迁移到[秘书/下属沟通]
  场景：向领导汇报时，不要问"您看怎么改？"（开放式），
       而是问"按A方案走还是B方案走？"（有限选择式）
  ↓
Step 4：迁移到[自媒体博主/读者互动]
  场景：文末引导评论时，"你觉得是A还是B？" 比"你怎么看？"回复率高
  ↓
Step 5：用Obsidian连起来
  [[有限选择_育儿版]] ←→ [[向上汇报SOP]] ←→ [[评论区互动SOP]]
  三者都链接到通用知识中的 [[决策心理学]]
```

#### 补2.3 制作"知识关联地图"

每隔一段时间（建议每月），拿出来一张纸或白板工具，做一个练习：

**操作**：
1. 写下最近1个月新存入的5-10个核心概念
2. 写下已有的核心概念（从框架文件里找）
3. 画线连接它们，在线上写："A和B的关系是______"
4. 把画出的连线中最重要的3-5条，更新到对应的 Obsidian 笔记的"知识关联"区域

**判断标准**：如果某个概念连不出一条线 → 这条知识可能还没真正理解，回去重新用"七多理解法"精加工。

### 补三、刻意练习闭环：从知道到做到

整套体系最关键的"最后一公里"。**知道SOP和能用SOP之间，隔着一万次刻意练习。** 缺少这一环，前面搭的骨架、存的笔记全白费——体系再好看，用不出来就是零。

#### 补3.1 刻意练习的核心原则

**一个核心认知**：不要试图一次性把所有SOP都用好。每次只聚焦**一个SOP的某一个步骤**，集中火力。

**三个硬规定**：

| 规定 | 说明 | 反例 |
|------|------|------|
| **只选一项** | 每次刻意练习只聚焦一个知识/一个SOP的一个步骤 | "我今天要同时练习汇报、倾听和会议主持" ❌ |
| **具体到场景** | 提前锁定练习的时机和场景 | "下次有机会试一下" ❌ → "明天跟张总的周报就用" ✅ |
| **事后立即复盘** | 练完必须对照SOP和实际行动，记录差距 | 凭感觉说"还行" ❌ → 打开SOP逐条对照 ✅ |

#### 补3.2 刻意练习四步闭环**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   ① 选枪 ──→ ② 开枪 ──→ ③ 照镜子 ──→ ④ 磨枪               │
│   选定一个      在真实      按SOP逐条     更新迭代记录        │
│   SOP            场景执行     对照复盘      下次优化          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**第一步：选枪（选定一个SOP的某一步）**

操作：打开本周周计划，找到"本周要刻意练习的一个SOP"，不要练习整个SOP——只聚焦**第一步**，或**以往最容易出错的那一步**。

**第二步：开枪（在真实场景中执行）**

两种情况分别处理：

**情况A：可以照着笔记做**（如写公文、做PPT、准备汇报提纲）
→ 打开Obsidian中的SOP → 一步一步照着做 → 做完后记录感受
→ 复盘核心：**步骤本身对不对？需不需要改？**

**情况B：不能照着笔记做**（如实时沟通、开会发言、临场应对）
→ 行动前脑中过一遍目标步骤 → 事后立即回忆对照
→ 复盘核心：**做的时候真的用上了吗？**（这种情况最容易"脑子里知道，嘴上忘了说"）

**第三步：照镜子（按SOP逐条复盘）**

操作：做完后，不等"有空"，**立刻马上**对照SOP复盘。延迟复盘的效果断崖式下跌。

**五问复盘法**：

```
问1：刚才我用的是哪个SOP的哪个步骤？
问2：我实际做了什么？（如实描述，不要美化，不要用"基本上""大概"）
问3：和SOP上的对比，哪里一样？哪里不一样？
问4：不一样的地方，是SOP有问题，还是我执行有问题？
问5：如果我再来一次，我会在哪一步做什么改变？
```

对于情况B（现场没法照着做）特别加一问：
> "我当时脑子里闪过要用SOP了吗？如果没闪过，为什么？怎么让它下次能闪？"

**第四步：磨枪（更新SOP的迭代记录）**

操作：在 Obsidian 中打开对应SOP文件，更新底部的"迭代记录"表格。

```markdown
## 迭代记录
| 日期 | 使用场景 | 效果 | 需要改进的地方 |
|------|---------|------|--------------|
| 06-14 | 周二跟张总做周报时刻意用了第一步"结论先行" | 张总没打断我，但说完后他追问了数据 | 下次准备时把数据提前整理好，放在话术第二句 |
```

#### 补3.3 从一个SOP练到"长在身上"要多久？

| 阶段 | 标志 | 时间预估 | 操作 |
|------|------|---------|------|
| 新手期 | 必须打开Obsidian照着做 | 前3-5次 | 允许对着清单一步步来 |
| 熟练期 | 不用看笔记也能做，但偶尔会漏步骤 | 第5-15次 | 事后复盘对照，补漏 |
| 自动化期 | 不假思索就能做对，成为肌肉记忆 | 第15-30次 | 可以把这个SOP归档为"已内化"，腾出精力练新的 |
| 迁移期 | 不看笔记，且能根据不同场景灵活调整 | 30次以上 | 把这个SOP的通用原理存入通用体系，迁移到其他角色 |

> **核心认知**：SOP只是拐杖，最终目的是**丢掉拐杖还能走稳**。当一个SOP进入"自动化期"，就可以开始聚焦下一个SOP了。

#### 补3.4 刻意练习的避坑指南

| 陷阱 | 表现 | 解法 |
|------|------|------|
| 贪多嚼不烂 | 一周列了5个SOP要练，最后一个都没练好 | 一周只练一个SOP的一个步骤 |
| 只在安全区练 | 专挑有把握的场景，回避真正难的局面 | 刻意选那个"想起来就紧张"的场景去练 |
| 练完不复盘 | 感觉"还行"就过了，从不打开SOP对照 | 用"五问复盘法"当固定仪式 |
| 复盘不记下来 | "心里有数"但不写进迭代记录 | 复盘完必须写进Obsidian的迭代记录表格中 |
| 死守SOP不放 | 情况变了还硬套，不知道灵活调整 | SOP不是教条，场景不同→应该提出对SOP的修改 |

### 补四、设置自动化维护（Phase 5）

**执行流程**：

    │   读取 `临时箱/` 目录下所有 .md 文件

    │
    ├── 第二步：分类每条内容
    │   对每条临时箱内容，判断：
    │   - 属于哪个角色？
    │   - 是事实性/概念性/程序性知识？
    │   - 应该存入哪个具体路径？
    │
    ├── 第三步：写入对应位置
    │   按判断结果，将内容写入：
    │   - 角色体系/[角色名]/专业知识/三类知识/
    │   - 或 通用体系/对应子目录/
    │   - 写入时保留双向链接，关联到知识框架

    ├── 第四步：清空临时箱

    │   移动到 `临时箱/已归档/` 子文件夹（若目录不存在则创建）

    └── 第五步：更新总纲
        更新 `知识体系总纲.md` 中的"临时箱处理记录"

### 补五、绑定IMA碎片收集箱（Phase 6）

> 碎片化知识是知识体系的重要输入来源。IMA（腾讯智能工作台）可以作为碎片知识的"随手收集箱"——看到好文章、闪过一个好想法、听到一个好观点，一键存入 IMA，后续统一整理到 Obsidian 知识体系中。

#### 补5.1 为什么需要碎片收集箱？

对照课程第15课"随时随地学习"的理念：看到有启发的文章、突然想到一个有趣的点、听到别人一个有趣的观点 → 立刻记下来 → 晚上空闲时间再整理沉淀。

IMA 的优势：
- **跨平台**：手机/电脑/网页都能用，碎片场景下随时随地记录
- **知识库**：支持创建知识库，分类存放碎片内容
- **AI 辅助**：内置 AI 可以帮助初步整理和分类碎片内容
- **与 WorkBuddy 联动**：绑定 IMA 后，AI 代理可以直接读取 IMA 中的碎片内容，自动分类写入 Obsidian 知识体系

#### 补5.2 AI 询问用户的标准话术

> 在 Phase 5 完成后，AI 自动向用户询问：

```
最后一步（可选）：

你是否已经注册了 IMA（腾讯智能工作台）账号？

如果你有 IMA 账号，我可以帮你把它绑定为碎片知识收集箱——
以后你在手机上看到好文章、闪过好想法、听到好观点，
一键存入 IMA，我会定期帮你自动整理到知识体系中。

选项：
A. 有 IMA 账号，现在就绑定
B. 没有 IMA 账号，跳过这一步
```

#### 补5.3 绑定 IMA 的流程（AI 代理执行）

**用户选择 A（有 IMA 账号）时的执行步骤**：

**Step 1：检查 IMA 连接器状态**

AI 代理检查 WorkBuddy 中 IMA 连接器是否已连接。
- 若 `ima-mcp` 状态为 `connected` → 直接进入 Step 2
- 若 `ima-mcp` 状态为 `disconnected` → 引导用户在 WorkBuddy 连接器管理页面启用 IMA 连接器

**Step 2：创建碎片收集知识库**

引导用户或由 AI 代理在 IMA 中创建一个专用知识库（如"碎片收集箱"或"临时灵感"），专门用于存放碎片化内容。

**Step 3：说明日常使用方式**

向用户说明 IMA 作为碎片收集箱的日常使用方式：

| 场景 | 操作 |
|------|------|
| 微信里看到好文章 | 转发到 IMA → 存入"碎片收集箱"知识库 |
| 突然闪过一个想法 | 打开 IMA 手机 App → 快速记录 |
| 听到别人一个好观点 | 打开 IMA 语音/文字记录 |
| 刷到一条有价值的微博/短视频 | 截图或复制链接 → 存入 IMA |

**Step 4：接入定期处理流程**

将 IMA"碎片收集箱"知识库的内容，纳入 Phase 5 已创建的"临时箱每日处理"自动化任务中：

- 扩展临时箱处理流程：不仅处理 Obsidian 本地 `临时箱/` 目录，也读取 IMA"碎片收集箱"知识库中的内容
- 将 IMA 中的碎片内容同样按角色和知识类型分类，写入 Obsidian 对应位置
- 处理完成后，可选择在 IMA 中标记为"已处理"或归档

> **注意**：IMA 绑定是可选的。如果用户选择跳过（选项 B），不会影响知识体系的正常运作——Obsidian 自身的"临时箱"机制仍然可以满足碎片收集的需求。

#### 补5.4 IMA 绑定的后续管理

| 操作 | 方法 |
|------|------|
| 修改 IMA 收集箱知识库名称 | 在 IMA App 中修改，然后告知 AI 代理更新配置 |
| 调整自动处理频率 | 说"帮我把 IMA 碎片处理频率从每天改成每周" |
| 取消 IMA 绑定 | 说"帮我取消 IMA 碎片收集箱绑定"，AI 代理恢复默认的临时箱处理流程 |

- [ ] 每个角色下创建三件套：
  - `[角色名]_知识框架.md`（索引入口）
  - `角色态度/角色态度.md`（愿景、目标、当前状态）
  - `专业技能/`（直接存笔记）

#### Phase 4：内容填充与迭代（§ 七-十五）

#### Phase 5：设置自动化维护（§ 自动化）

  - prompt: 见「补四、设置自动化维护 → 补4.3」中的 prompt 模板
- [ ] **（可选）询问用户是否设置周报提醒**：问"你希望每周几收到学习计划提醒？"，若用户同意则创建周报自动化

### 附录C：AI 提示词模板库

> 以下提示词均对标课程原文，可直接复制使用。
> **重要**：把 `[括号内容]` 替换为你的真实信息后再发给 AI。

#### T01：梳理知识漏洞（对标第七课）

```
用户角色：[你的角色名，如"公众号博主""销售负责人"]
当前面临的核心问题：
1. [问题1，如"定位不清晰"]
2. [问题2]
3. [问题3]

请帮我分析：
1. 解决每个问题，分别需要什么知识？（按 事实性/概念性/程序性 分类）
2. 我目前最缺的是哪一类知识？
3. 针对最缺的知识类型，推荐3个具体的学习资源（书/课/文章）。
```

#### T02：制定学习计划（对标第八课）

```
基于我的角色【[角色名]】和面临的核心问题【[列出问题]】，
请帮我制定一个为期【X周】的学习计划：

1. 按优先级排序，列出我最需要学习的3个知识点
2. 为每个知识点推荐：
   - 输入型材料（书/课/文章）
   - 输出型材料（实践/教别人）
3. 帮我把时间分配好：哪些用系统性时间，哪些用碎片化时间
4. 给出具体的每周任务清单（细化到"周一晚上：读XX书第3章"）
```

#### T03：筛选阅读内容（对标第九课·筛选）

```
我要解决的知识漏洞是：【具体描述，如"不知道怎么给公众号定位"】
请帮我快速筛选下面这段内容中，对解决我的问题最有价值的5%：

【粘贴内容或上传文件】

要求：
- 只保留能解决我问题的内容
- 用【】标注出关键步骤/模型/原理
```

#### T04：粗加工提炼知识（对标第九课·粗加工））

```
我从【材料来源】中筛选出了以下内容，目标是学习【程序性知识/概念性知识/事实性知识】：
【粘贴筛选出的内容】

请帮我：
1. 提炼出所有的步骤/流程/模型/原理/数据
2. 按"事实性/概念性/程序性"三类分好
3. 用我自己的话重新表述一遍（不要照抄原文）
```

#### T05：精加工深度理解（对标第九课·精加工））

```
我正在学习【知识点，如"定位"】，但理解还不够深。
请用以下方法帮我精加工：
1. 举3个生活中的具体例子（不要用抽象语言）
2. 和我已有的知识【列出已有知识，如"战略""用户需求"】建立关联
3. 回答我的追问：
   - 为什么是这个概念而不是别的？
   - 为什么不【反例】也行？
   - 这个知识能用在哪里？不能用在哪？
```

#### T06：沉淀知识（对标第十课））

```
我刚才学完了【知识点】，现在要沉淀到Obsidian仓库的以下位置：
路径：【如"角色体系/公众号博主/专业知识/程序性知识/"】

请帮我把刚才的内容整理成Obsidian笔记，格式如下：
- 如果是程序性知识：用三栏表格（总步骤|细分步骤|应用体会）
- 如果是概念性知识：先给定义，再给模型图（用文字描述），最后给例子
- 如果是事实性知识：用列表整理关键数据/案例

要求：直接输出可复制的Markdown格式。
```
