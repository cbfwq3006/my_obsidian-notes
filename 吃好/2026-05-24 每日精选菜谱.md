## 1. 蒜蓉油麦菜（蚝油）

- 配图：
- 推荐理由：油麦菜本身清脆，配蒜蓉和蚝油就很出味；大火快炒、两三分钟能出锅，适合作为晚餐青菜位。
- 适合场景：工作日晚餐配菜 / 便当蔬菜位 / 两菜一汤里的快手青菜
- 预计耗时：5–10 分钟
- 主要食材：油麦菜、大蒜、蚝油、生抽
- 简明步骤：
  - 油麦菜洗净沥干，蒜切碎。
  - 热锅少油，先爆香蒜末。
  - 下油麦菜杆和叶大火快炒。
  - 加蚝油和少许生抽翻匀，变软立刻出锅。
- 营养亮点：绿叶菜补充膳食纤维、叶酸与钾；少油快炒更适合日常控油。
- 注意事项：一定要大火快炒，避免出水后变软塌；油麦菜要尽量沥干。

## 2. 虾仁豆腐蒸水蛋

- 配图：
- 推荐理由：鸡蛋、豆腐和虾仁组合，蛋白质够、口感嫩滑，蒸一锅就能当主菜，省油也省事。
- 适合场景：晚餐主菜 / 备餐分装 / 老少都能吃的软嫩菜
- 预计耗时：20–30 分钟
- 主要食材：内酯豆腐、鸡蛋、虾仁、香葱、蒸鱼豉油
- 简明步骤：
  - 豆腐切小块放碗底，鸡蛋加温水打匀并过滤。
  - 蛋液倒入豆腐中，盖好后先蒸至半凝固。
  - 放上处理好的虾仁继续蒸熟。
  - 出锅淋蒸鱼豉油和少许香油，撒葱花。
- 营养亮点：豆腐提供植物蛋白和钙，鸡蛋和虾仁补充优质蛋白；蒸制方式更清淡。
- 注意事项：蛋液一定要过滤并控制火候，避免起蜂窝；豆腐尽量选嫩一点的。
- 来源链接：https://m.xiachufang.com/recipe/101858672/

## 3. 番茄鸡蛋汤

- 配图：
- 推荐理由：番茄的酸甜和鸡蛋的鲜香很稳妥，几乎零门槛；一碗汤就能配饭，也适合备餐时补一锅热汤。
- 适合场景：晚餐汤位 / 配米饭或面条 / 想吃清爽热汤的时候
- 预计耗时：10–15 分钟
- 主要食材：番茄、鸡蛋、葱、蒜、盐、鸡精（可选：香油、香菜）
- 简明步骤：
  - 番茄切块，鸡蛋打散。
  - 起锅少油炒番茄出汁。
  - 加水煮开后，淋入鸡蛋液。
  - 加盐和少许生抽调味，撒葱花即可。
- 营养亮点：番茄提供番茄红素和维生素C，鸡蛋补充优质蛋白；整体清淡不油腻。
- 注意事项：番茄先炒软更容易出味；鸡蛋液下锅后别急着大力搅拌。
- 来源链接：https://www.xiachufang.com/recipe/101774451/

## 4. 素炒杏鲍菇

- 配图：
- 推荐理由：杏鲍菇口感厚实，配青椒和胡萝卜一起快炒，鲜香又下饭；食材家常、做法短，适合忙碌晚餐。
- 适合场景：晚餐配菜 / 备餐便当 / 想吃点“像肉”的素菜
- 预计耗时：10–15 分钟
- 主要食材：杏鲍菇、青椒、胡萝卜、蒜、葱、姜、生抽、老抽、蚝油
- 简明步骤：
  - 杏鲍菇切细条，胡萝卜和青椒切丝，葱姜蒜切碎。
  - 热锅少油爆香葱姜蒜，先下杏鲍菇和胡萝卜丝翻炒。
  - 炒软后放入青椒丝，再加生抽、老抽、蚝油和少许盐翻炒。
  - 3 分钟左右出锅，保留菇的鲜香和蔬菜的脆感。
- 营养亮点：菌菇低脂高纤维，搭配彩椒和胡萝卜后颜色更丰富，也补充更多植物性营养。
- 注意事项：胡萝卜不易熟，适合先下；杏鲍菇不用焯水，炒软即可。
- 来源链接：https://m.xiachufang.com/recipe/104387016/

## 5. 香菇扒油菜

- 配图：
- 推荐理由：香菇增鲜、油菜清爽，是很标准的家常快手菜；带一点勾芡后更有“下饭菜”的完成度。
- 适合场景：工作日晚餐配菜 / 两菜一汤的蔬菜位 / 清爽便当
- 预计耗时：15–20 分钟
- 主要食材：鲜香菇、油菜、姜末、蒸鱼豉油、淀粉
- 简明步骤：
  - 油菜洗净，香菇去蒂切好。
  - 先把油菜汆/炒至断生，盛出摆盘。
  - 香菇加姜末炒香，调入少许料酒、盐、糖和蒸鱼豉油。
  - 用少量水淀粉收一下汁，浇在油菜上。
- 营养亮点：菌菇和绿叶菜搭配，纤维和矿物质更均衡；整体油量可控。
- 注意事项：油菜不要过火，保持脆嫩和颜色；勾芡要薄，别做得太厚重。
- 来源链接：https://m.xiachufang.com/recipe/75972/
