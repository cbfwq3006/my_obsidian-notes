## 1. 番茄豆腐汤（低脂低卡、快手）
- 配图：
- 推荐理由：一锅出、调味简单；豆腐+番茄的组合饱腹又清爽，适合作为晚餐汤菜或备餐汤底。
- 适合场景：工作日晚餐 / 轻食控油 / 便当配汤 / 想吃热乎但不想复杂
- 预计耗时：约 15–25 分钟
- 主要食材：番茄、嫩/老豆腐（任选其一更顺手）、葱姜（可选）、盐、生抽（可选）、胡椒、少量油
- 简明步骤：
  - 番茄切块；豆腐切块备用（想更整块可先焯水 30 秒）。
  - 少量油热锅，炒香葱姜（可选）后下番茄炒出汁；加水煮开。
  - 下豆腐小火煮 5–8 分钟，盐/胡椒调味；出锅前可点少许生抽增鲜。
- 营养亮点：豆腐提供优质蛋白与钙；番茄提供番茄红素与维 C；整体低脂、易消化。
- 注意事项：豆腐下锅后少翻动防碎；口味淡可用胡椒/葱花提香，盐不要重。
- 来源链接：https://m.xiachufang.com/recipe/105820781/
- 自动筛选依据：家常快手、低油；食材常见；步骤少、适合晚餐与备餐。

## 2. 鸡胸肉炒西兰花（少油快手菜）
- 配图：
- 推荐理由：一荤一素同锅快炒，适合“想吃肉但控油”的晚餐；西兰花补纤维，鸡胸补蛋白，便当也很合适。
- 适合场景：减脂晚餐 / 备餐主菜 / 便当盒 / 下班 20 分钟搞定
- 预计耗时：约 15–25 分钟
- 主要食材：鸡胸肉、西兰花、蒜（可选）、生抽/蚝油（可选）、黑胡椒、少量油
- 简明步骤：
  - 西兰花掰小朵，水开焯 1 分钟捞出沥干（更快熟、少油也能炒透）。
  - 鸡胸切片/条，少许生抽+胡椒抓匀（可加一点淀粉更嫩，非必需）。
  - 少量油下锅，先炒鸡胸至变色；下西兰花大火翻炒，尝味后出锅。
- 营养亮点：高蛋白、相对低脂；搭配十字花科蔬菜更利于控制总热量与补充微量营养。
- 注意事项：鸡胸别炒太久易柴；焯西兰花别久避免发黄；调味里已有咸味，盐慎加。
- 来源链接：https://m.xiachufang.com/recipe/102771914/
- 自动筛选依据：快手少油、适合备餐；食材容易买；“一锅快炒”结构清晰。

## 3. 口蘑炒鸡肉（清爽下饭、步骤少）
- 配图：
- 推荐理由：口蘑自带鲜味，少油也能很香；搭配鸡肉更有饱腹感，适合家常下饭或带饭。
- 适合场景：家常晚餐 / 备餐主菜 / 想吃香但不想重油
- 预计耗时：约 15–30 分钟
- 主要食材：口蘑、鸡肉（鸡胸/鸡腿肉均可）、蒜/葱（可选）、生抽、胡椒、少量油
- 简明步骤：
  - 口蘑擦洗切片；鸡肉切片/丁，少许生抽抓匀。
  - 少量油热锅先炒鸡肉至变色；加入口蘑翻炒出水。
  - 调味（生抽/胡椒），收汁到你喜欢的程度即可。
- 营养亮点：鸡肉提供优质蛋白；蘑菇类低能量密度、含多糖与矿物质，提升鲜味减少对油盐依赖。
- 注意事项：口蘑会出水属正常；火力不足可分次下锅避免“炖”成一锅；鸡肉务必熟透。
- 来源链接：https://m.xiachufang.com/recipe/100097903/
- 自动筛选依据：家常少油、步骤少；食材常见；适合作为晚餐/便当蛋白主菜。

## 4. 蒜蓉菠菜（快手补铁补叶酸）
- 配图：https://cdn.sanity.io/images/ry1mzg6n/production/2183d0d4929b006bb3e1d70f3e75d64bc21cf7e9-1280x720.jpg
- 推荐理由：5–10 分钟即可上桌的“万能蔬菜盘”；蒜香提味，少油也好吃，搭配任何主菜都不违和。
- 适合场景：工作日晚餐配菜 / 想补蔬菜纤维 / 低油饮食
- 预计耗时：约 5–12 分钟
- 主要食材：菠菜、大蒜、盐、少量油（可选：少许生抽/蚝油）
- 简明步骤：
  - 菠菜洗净（可切段）；大蒜切末。
  - 热锅少量油，下蒜末爆香；下菠菜大火快炒至塌软。
  - 少许盐调味出锅（想更鲜可点一点生抽/蚝油，非必需）。
- 营养亮点：菠菜富含叶酸、钾与膳食纤维；快炒时间短更利于保留口感与营养。
- 注意事项：菠菜出水快，别久炒；肾结石风险人群注意草酸相关饮食（可先焯水再炒）。
- 来源链接：https://www.daydaycook.com/zh-Hans/recipe/stir-fried-spinach-with-minced-garlic
- 自动筛选依据：极快手、少油；食材易买；步骤少；稳定配图可用（页面直链图片）。

## 5. 番茄炒蛋（少油版思路、非常家常）
- 配图：
- 推荐理由：可作为“救场主菜”反复做；控制油量、用番茄的酸甜提味，下饭也适合备餐盒。
- 适合场景：家常晚餐 / 便当主菜 / 冰箱只剩番茄和鸡蛋的情况
- 预计耗时：约 10–20 分钟
- 主要食材：番茄、鸡蛋、盐、少量油（可选：少许糖、葱花）
- 简明步骤：
  - 鸡蛋打散；番茄切块。
  - 少量油先炒蛋至凝固盛出；再下番茄炒出汁，回锅鸡蛋拌匀。
  - 以盐调味；可按口味点少许糖平衡酸味（可选）。
- 营养亮点：鸡蛋优质蛋白+脂溶性营养；番茄提供维 C 与番茄红素；少油做法更适合日常控脂。
- 注意事项：少油炒蛋容易粘锅，锅不够不粘可用更小火或分次；番茄炒出汁再回蛋更入味。
- 来源链接：https://www.daydaycook.com/zh-Hans/recipe/scramble-eggs-with-juicy-tomatoes
- 自动筛选依据：家常快手、食材最常见；步骤极少；适合作为晚餐/备餐高频菜。
