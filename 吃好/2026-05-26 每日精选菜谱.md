## 1. 什锦蔬菜豆腐虾仁
- 配图：
- 推荐理由：只用油和盐就能做出鲜味，色彩丰富、蛋白+蔬菜齐全，特别适合作为“工作日晚餐的省心一盘”。
- 适合场景：工作日晚餐 / 低油轻食 / 给小朋友配菜 / 便当配菜
- 预计耗时：10 分钟
- 主要食材：熟虾仁、嫩豆腐、玉米粒、胡萝卜丁、豌豆粒、盐、少量油
- 简明步骤：
  - 冷锅少油下玉米粒/胡萝卜丁/豌豆粒快速翻炒。
  - 加少量水，放入豆腐块与熟虾仁，快速翻炒。
  - 只用盐调味（可按口味加少许胡椒），出锅。
- 营养亮点：豆腐+虾仁提供优质蛋白；多色蔬菜补充膳食纤维与维生素，整体脂肪可控。
- 注意事项：虾仁若为生的需先焯/先炒至变色再与豆腐同锅；豆腐轻翻避免碎。
- 来源链接：https://m.xiachufang.com/recipe/103332968/

## 2. 高蛋白快手～虾滑豆腐青菜汤
- 配图：
- 推荐理由：一锅出汤菜，步骤少、很适合备餐；虾滑+豆腐+绿叶菜搭配，蛋白够、口味清爽。
- 适合场景：晚餐一锅汤 / 减脂期 / 午餐快手 / 加班回家
- 预计耗时：15 分钟
- 主要食材：虾滑、内酯豆腐、绿叶菜（奶白菜等）、盐/胡椒（或汤料包）、少许香油
- 简明步骤：
  - 水开后用勺挖虾滑入锅，煮开撇浮沫。
  - 加入调味（汤料包或盐/胡椒），下青菜。
  - 倒入划块的内酯豆腐，小火煮几分钟；出锅前滴几滴香油。
- 营养亮点：虾滑+豆腐双蛋白；绿叶菜补钾与维生素；汤食更利于控制油脂。
- 注意事项：虾滑球不要挖太大（会膨胀）；豆腐后下且轻翻，避免碎。
- 来源链接：https://m.xiachufang.com/recipe/106743513/
- 自动筛选依据：快手一锅出；收藏与做过人数高（“286人收藏/4人做过”），用料少且适合日常。

## 3. 香菇酿虾滑（超级简单零失败快手菜）
- 配图：
- 推荐理由：香菇当“容器”，虾滑当“馅”，煎/焖一下就很香；少油也能做出满足感，适合当主菜或配菜。
- 适合场景：家常晚餐 / 宴客小菜（不费事）/ 便当 / 想吃“肉感”但少油
- 预计耗时：20 分钟
- 主要食材：鲜香菇、虾滑、生抽、蚝油、少量淀粉、清水（可选青红椒丁/葱花/芝麻）
- 简明步骤：
  - 香菇去蒂、背面挖深一点，内侧抹少许干淀粉。
  - 填入虾滑，表面再薄抹一点干淀粉定型。
  - 轻煎至两面定型后加调好的料汁，小火焖至熟透收汁。
- 营养亮点：虾滑提供优质蛋白；香菇补充膳食纤维与多糖类成分；整体可控油。
- 注意事项：香菇尽量选大小均匀、肉厚的；焖煮时火别太大，避免外焦内生。
- 来源链接：https://m.xiachufang.com/recipe/106172400/
- 自动筛选依据：快手、步骤清晰；收藏与做过人数非常高（“2385人收藏/39人做过”），适合新手。

## 4. 鲜嫩入味的好喝，番茄豆腐虾仁汤（260大卡）
- 配图：
- 推荐理由：番茄酸甜开胃，豆腐+虾仁+蛋花让饱腹更扎实；一锅汤适合晚餐或备餐，做烩饭也很搭。
- 适合场景：清淡晚餐 / 减脂期 / 一人食 / 想要“有滋味”的低油汤
- 预计耗时：20 分钟
- 主要食材：西红柿、内酯豆腐、小虾仁、鸡蛋、蒜、小葱、薄盐生抽（可选少量番茄风味汤底/番茄酱）
- 简明步骤：
  - 少油爆香蒜片，下番茄翻炒出汁。
  - 加温水煮开，下豆腐，小火煮至入味。
  - 下虾仁，沿锅边淋蛋液成蛋花，焖 2–3 分钟；撒葱花出锅。
- 营养亮点：虾仁+蛋+豆腐提供蛋白；番茄补充维生素与番茄红素；汤类更易控油。
- 注意事项：内酯豆腐易碎，后下且轻翻；番茄不够熟可加一点番茄酱提升风味。
- 来源链接：https://m.xiachufang.com/recipe/107127707/
- 自动筛选依据：快手汤品、低油；页面显示收藏/浏览量较高（“276人收藏”），适合日常晚餐。

## 5. 无油减脂蔬菜汤（西红柿鸡蛋菠菜豆腐白玉菇）
- 配图：
- 推荐理由：真正“无油”思路，番茄打底+菌菇增鲜，豆腐和蛋花让汤更顶饱；适合清淡晚餐或备餐。
- 适合场景：轻断食/控脂期 / 晚餐汤菜 / 想清清肠胃的一天 / 配一份主食
- 预计耗时：15–20 分钟
- 主要食材：西红柿、鸡蛋、菠菜/小白菜、豆腐、白玉菇/其他菌菇、盐、白胡椒（可选少量蚝油/勾芡用面粉水）
- 简明步骤：
  - 清水煮开，下番茄煮软（可捞掉番茄皮改善口感）。
  - 下菌菇、豆腐丁煮一会儿；需要更稠可加少量面粉水勾芡。
  - 盐/白胡椒调味，下菠菜 20 秒；在沸腾处倒蛋液成蛋花，关火焖熟。
- 营养亮点：蔬菜量大、膳食纤维足；豆腐+鸡蛋补蛋白；无油更利于控能量。
- 注意事项：白胡椒少放；倒蛋液后不要搅动更嫩；菠菜最后下避免发黄。
- 来源链接：https://m.xiachufang.com/recipe/103819513/
- 自动筛选依据：无油、步骤清楚；收藏与做过人数高（“2055人收藏/15人做过”），适合日常与备餐。
