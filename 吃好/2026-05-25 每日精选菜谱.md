## 1. 超级好吃的洋葱炒鸡蛋
- 配图：
- 推荐理由：食材便宜易买、做法直观；洋葱的甜味配鸡蛋很下饭，适合补蛋白。
- 适合场景：工作日快手晚餐 / 便当配菜 / 冰箱清库存
- 预计耗时：10–15 分钟
- 主要食材：鸡蛋、洋葱（可加青椒/香菜）
- 简明步骤：
  - 洋葱、青椒切块；鸡蛋加少量盐打散。
  - 热锅冷油下蛋液，轻轻划散至凝固无焦斑，盛出。
  - 少量底油下洋葱炒至断生，加入青椒；加盐、生抽/老抽、少许糖调味。
  - 倒回鸡蛋快速翻匀，出锅前加香菜（可选）。
- 营养亮点：鸡蛋提供优质蛋白；洋葱补充膳食纤维与植物化学物。
- 注意事项：鸡蛋要“热锅冷油”更嫩；酱油与糖按口味减量，控糖可不放糖。
- 来源链接：https://www.xiachufang.com/recipe/104066632/
- 自动筛选依据：家常快手、步骤少；综合评分 7.1、多人实做；食材通用且适合晚餐。

## 2. 蒜苔炒肉
- 配图：
- 推荐理由：经典下饭菜，蒜苔爽脆、肉嫩入味；一锅快炒搞定。
- 适合场景：晚餐主菜 / 备餐分装 / 配米饭
- 预计耗时：15–20 分钟（含腌肉）
- 主要食材：蒜苔、瘦肉（或五花/肉丝）、姜蒜、小米辣（可选）
- 简明步骤：
  - 肉切片/丝，加少量淀粉+生抽（可加一点老抽上色）抓匀腌几分钟。
  - 蒜苔切短段；姜蒜/小米辣备好。
  - 热锅少油先下肉炒至变色盛出。
  - 余油爆香姜蒜（可加少量豆瓣酱），下蒜苔大火快炒。
  - 倒回肉，加入生抽、蚝油、盐调味，翻炒至蒜苔断生即可。
- 营养亮点：肉类蛋白+蒜苔纤维；快炒少油更适合日常。
- 注意事项：蒜苔别炒太久避免发黄发软；豆瓣酱偏咸，盐要后放少放。
- 来源链接：https://m.xiachufang.com/recipe/106168470/
- 自动筛选依据：家常快手、调味简单；高收藏/高实做量；适合“少油快炒”思路。

## 3. 西兰花炒虾仁
- 配图：
- 推荐理由：高蛋白、蔬菜量足；焯水+快炒很稳，口感清爽不腻。
- 适合场景：减脂晚餐 / 便当主菜 / 家庭日常
- 预计耗时：15–20 分钟
- 主要食材：西兰花、虾仁、木耳（可选）、胡萝卜、葱蒜
- 简明步骤：
  - 水开加少量盐和油，西兰花+木耳+胡萝卜焯至断生，捞出沥干。
  - 起锅少油，葱蒜炒香，下虾仁炒至变色。
  - 倒入焯好的配菜，加入生抽、盐、蚝油调味。
  - 淋少量水淀粉勾薄芡，大火翻匀出锅。
- 营养亮点：虾仁优质蛋白、脂肪低；西兰花富含维 C 与纤维。
- 注意事项：虾仁别久炒易老；勾芡要薄，想更清淡可不勾芡。
- 来源链接：https://www.xiachufang.com/recipe/107347069/
- 自动筛选依据：综合评分 7.5、多人实做；少油快炒、食材常见、步骤清晰。

## 4. 清炒芦笋（超级嫩！！！）
- 配图：
- 推荐理由：几种调味就能突出芦笋鲜甜；超快手的清爽蔬菜菜。
- 适合场景：两菜一汤里的青菜位 / 便当蔬菜 / 想吃清淡时
- 预计耗时：5–10 分钟
- 主要食材：芦笋、蒜、盐（可加少量辣椒）
- 简明步骤：
  - 芦笋削去老皮洗净，切段（可滚刀）。
  - 热锅少油，下蒜末/蒜片炒香。
  - 大火下芦笋和辣椒快速翻炒至断生。
  - 出锅前撒少量盐，立刻装盘。
- 营养亮点：芦笋含叶酸与纤维；清炒少油更利于日常控脂。
- 注意事项：火要大、时间要短，避免出水变软；芦笋老根可折断去纤维。
- 来源链接：https://www.xiachufang.com/recipe/104635401/
- 自动筛选依据：综合评分 8.0、多人实做；步骤极少、食材简单、适合快手晚餐。

## 5. 白菜炖豆腐
- 配图：
- 推荐理由：一锅热乎、成本低；白菜+豆腐的组合清淡但很满足，适合忙碌晚餐。
- 适合场景：清淡晚餐 / 宵夜热汤菜 / 一人食
- 预计耗时：约 8–10 分钟
- 主要食材：大白菜、韧豆腐、葱姜蒜、小米辣（可选）、生抽、蚝油
- 简明步骤：
  - 白菜切片洗净，豆腐切块。
  - 热锅少油，葱姜蒜炒香，下小米辣和白菜炒软。
  - 加盐、生抽、蚝油翻匀。
  - 放入豆腐，加水炖 3 分钟至汤汁微浓，撒葱花出锅。
- 营养亮点：豆腐提供植物蛋白与钙；白菜补充维生素与纤维，整体清淡。
- 注意事项：豆腐下锅后轻翻避免碎；想更清淡可减少蚝油/酱油。
- 来源链接：https://www.xiachufang.com/recipe/103727885/
- 自动筛选依据：综合评分 7.6，标注“约8–10分钟/零厨艺”；食材常见、步骤少、适合日常晚餐。
