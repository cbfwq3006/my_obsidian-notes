# obsidian-route-input

## 目标

把材料放进用户已有的系统，而不是强迫它进入 `sources/reports/memory/inbox` 固定目录。

## 流程

1. 先读 `.obsidian-cc/knowledge-map.md`；不存在时再读 legacy `vault.md`。
2. 判断材料属于：
   - 来源资料：外部原文、证据、网页/论文摘录；
   - 生成产物：分析、报告、阶段性总结；
   - 长期知识候选：未来仍会改变对人、项目、概念或决策的理解；
   - 仅当前对话：一次性、无需归档。
3. 给出“建议类别 + 已映射目标 + 理由 + 时效性”，然后停下等用户确认。
4. 来源/产物只有在对应角色已有明确写入位置且用户确认时才写；未映射先询问。
5. 长期知识只输出 `occ-knowledge-candidates` 协议，交给知识审核中心，不直接写长期目录或 legacy inbox。

## 边界

- 不自行创建顶层目录。
- 不修改 KnowledgeMap 标记为只读的材料。
- 新闻、行情、工具横评等易过期内容默认不是长期知识。
- 用户只问“放哪”时只回答，不执行写入。
