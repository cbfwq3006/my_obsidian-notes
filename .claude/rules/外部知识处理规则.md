# 外部知识处理规则

> 处理外部输入知识的标准流程

---

## 规则

### 当用户提供外部知识时

**包括但不限于：**
- 网页文章链接
- 复制粘贴的文章内容
- 截图/图片中的知识内容
- PDF/Word等文档
- 微信公众号文章
- 其他外部来源的知识资料

**处理流程：**

### 第一步：先存入临时箱

```
1. 创建文件到：00 临时箱/
2. 文件命名格式：
   - 如果有明确标题：使用原标题.md
   - 如果没有标题：根据内容总结标题.md
3. 保留完整内容（包括图片、链接等）
4. 在文件顶部添加frontmatter：
   ---
   source: [来源]
   url: [如果有URL]
   author: [作者]
   date: [发布日期]
   synced: [同步日期]
   status: pending
   ---
```

### 第二步：询问是否摄取

```
存入临时箱后，询问用户：
"已保存到 [[00 临时箱/文件名]]，是否需要摄取到wiki知识库？"

- 如果用户说"是"或"摄取" → 执行摄取流程
- 如果用户说"否"或"稍后" → 保持在临时箱
- 如果用户没有明确表示 → 仅存入临时箱，不主动摄取
```

### 第三步：摄取到wiki（可选）

只有在用户明确要求时才执行：
1. 阅读临时箱文件
2. 创建 wiki/来源/ 摘要页
3. 更新相关实体页
4. 更新相关概念页
5. 更新 wiki/index.md
6. 追加 wiki/log.md
7. （可选）将临时箱文件移动到 99 归档/已处理/

---

## 执行优先级

**高优先级：** 先存入临时箱（保护数据）
**低优先级：** 摄取到wiki（需要用户确认）

---

## 特殊情况

### 如果临时箱已有同名文件
- 检查内容是否相同
- 如果相同：提示"该内容已存在"
- 如果不同：文件名加时间戳后缀

### 如果内容很短（<500字）
- 仍然先存入临时箱
- 但提示"内容较短，可能不需要摄取"

### 如果是图片/截图
- 保存到 00 临时箱/images/
- 同时创建一个同名md文件记录图片信息

## 示例

### Claudian的操作：
```
1. 抓取文章内容
2. 创建文件：00 临时箱/文章标题.md
3. 保存完整内容
4. 回复："已保存到 [[00 临时箱/文章标题.md]]，是否需要摄取到wiki？"
```

---

## 为什么这样设计？

1. **数据安全：** 先保存再处理，避免丢失
2. **用户控制：** 让用户决定是否需要深度处理
3. **工作流清晰：** 临时箱→审核→wiki，流程可控
4. **避免过度摄取：** 不是所有内容都值得进wiki
