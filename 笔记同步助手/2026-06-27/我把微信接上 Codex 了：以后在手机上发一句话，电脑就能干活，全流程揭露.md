# 我把微信接上 Codex 了：以后在手机上发一句话，电脑就能干活

这篇我按自己的实操过程写。

目标很简单：人在手机上给微信发一句话，电脑后台收到以后，把任务交给 Codex。跑通以后，你不在电脑旁边，也能让那台机器继续干点小活。

我一开始就是想偷个懒，因为国产的AI还有openclaw都可以通过微信、飞书等远程控制，我想Codex应该也可以吧。

比如我人在外面，突然想让 Codex 检查一下文章格式，或者看一眼某个文件夹。能不能直接在微信里发一句，电脑那边自己接住、自己跑，跑完再把结果回给我？

试下来，能跑。

但它不是装个插件就完事。

微信登录、桥接服务、Codex 适配、后台常驻、日志排错，这几块都要接上。

少一块，你就会卡在一个很尴尬的状态：看起来启动了，实际上消息没进去。

![[笔记同步助手/images/0ed1315c6c4cf8d45f92fc0d1b171dda_MD5.png]]

这是我刚才实操时的记录，已经跑到“微信消息同步显示到 Codex 桌面窗口”的阶段。

## 先把原理讲明白

“微信远程控制 Codex”听起来挺玄。

拆开看，其实就是 4 层：

![[笔记同步助手/images/d0c065fb3d1efa0679b15dd0cd40689c_MD5.png]]

> 微信：你在手机上发消息。
> 
> wechat-acp：负责接收微信消息，把它变成电脑能处理的任务。
> 
> codex-acp：负责把任务交给 Codex。
> 
> Codex：在电脑上执行任务，然后把结果返回。

这里最容易误会的是：微信并没有直接控制你的电脑。

中间那层桥接服务，才是关键。

你在微信里说的话，会先被 wechat-acp 接住，再转成 Codex 能处理的任务。这样理解，后面排错就不会乱。

![[笔记同步助手/images/2397f5f83a1bbbd17a1f004d6e759312_MD5.png]]

## 先别装，检查 4 件事

我建议你先花 2 分钟确认环境。

这个比装完再排错省时间。

| 准备项 | 怎么判断 | 为什么要有 |
| --- | --- | --- |
| Windows 电脑 | 我这次是在 Windows 上跑通的 | 后台脚本、隐藏窗口、任务计划更方便 |
| 微信能正常登录 | 电脑上能扫码登录微信 | 第一次启动桥接服务时要扫码 |
| Codex 能正常打开 | 桌面端 Codex 可以进入当前项目 | 微信只是入口，干活的是 Codex |
| Node.js 和 npm | 能运行 node 和 npm.cmd | 这两个桥接包是 npm 包 |

这里插一句：如果 PowerShell 里运行 \`npm\` 报执行策略错误，先别去改系统设置，换成 \`npm.cmd\`。我刚才查版本时也碰到了，换这个就过了。

![[笔记同步助手/images/65af163da98160e816926b388017cb76_MD5.png]]

## 第一步，装两个包

打开项目目录，在终端里跑这一句：

npm.cmd install -g wechat-acp@0.8.0 @zed-industries/codex-acp@0.16.0

我这里固定了版本：\`wechat-acp@0.8.0\`，\`@zed-industries/codex-acp@0.16.0\`。这样写的好处是，别人照着跑时不容易因为版本变化踩坑。

\`wechat-acp\` 管微信这一侧，\`codex-acp\` 管 Codex 这一侧。

先不用研究它们内部怎么通信。

第一遍只做一件事：把桥搭起来。

## 第二步，启动这座桥

我这边把启动脚本做成了一个命令文件：

start-wechat-codex.cmd

第一次双击它，通常会弹出二维码。

![[笔记同步助手/images/118e0dd6766b2ae8749e7d14298836c1_MD5.png]]

用自己的微信扫。

登录成功以后，\`wechat-acp\` 才能收到你后面发的消息。

二维码没扫成功，后面所有测试都会像对空气说话。

这个二维码别发给别人，也别让别人替你扫。

它等于把你的微信入口接到这台电脑上，别图省事。

## 第三步，别凭感觉，看状态

这里我踩过一次。

窗口不见了，不一定是服务停了。

窗口还在，也不一定真的连上微信。判断它活没活，别看桌面，要看状态。

查看状态

能看到下面这些信息，就说明方向对了：

![[笔记同步助手/images/1015b8767bfc13591e44df85f73c539a_MD5.png]]

> 后台微信-Codex 桥正在运行。
> 
> 有一个 PID，比如 23084。
> 
> 微信登录凭据 token.json 已生成。
> 
> 守护程序已经启动。

PID 就是进程编号，你不用背。

看到 PID，说明后台服务在跑。

\`token.json\` 是登录凭据。

它生成以后，下次重启通常不用重新扫码。没有它，多半就是登录没走完。

![[笔记同步助手/images/c46f6b550f9b89c03884f69d5866a13d_MD5.png]]

## 第四步，把窗口收起来

刚跑起来时，后台窗口可能一直挂在桌面上。

功能不受影响，但挡着做事，挺烦。

我加了一个隐藏后台脚本，让它安静待着：

wechat-codex-ensure-hidden.vbs

再把它放进任务计划，每分钟看一眼。服务掉了就拉起来，窗口冒出来就收回去。

任务计划里大概这样设：

-   任务名：Codex WeChat Bridge Watchdog
    
-   动作：运行 wscript.exe
    
-   参数：指向 wechat-codex-ensure-hidden.vbs
    
-   频率：每 1 分钟检查一次
    

这一步不是为了酷，是为了省心。

这座桥最好像值班员一样待在后台。

你什么时候从微信发任务，它什么时候接。

别每次要用时再想：我刚才是不是忘了开？

## 第五步，先发一条小任务

现在可以用微信试一下。

别一上来就让它改项目、写长文、跑复杂脚本。

先发一句小的：

测试一下，现在能收到我的消息吗？

如果桥通了，你会看到这条消息同步到电脑上的 Codex 窗口。

然后再发一条稍微像任务的话：

请检查当前项目目录，告诉我有哪些文章文件。

这一步只确认 3 件事：

-   微信消息能进来。
    
-   Codex 能收到任务。
    
-   结果能回到微信。
    

这 3 件事通了，再往后加复杂任务才有意义。

## 第六步，出问题先看日志

如果微信没反应，或者 Codex 没收到，别一直重启。

先看日志。日志比感觉靠谱。

我这次用到的日志路径是：

C:\\Users\\Administrator\\.wechat-acp\\instances\\codex-main\\wechat-acp.log

日志里一般能看到这些线索：

![[笔记同步助手/images/1015b8767bfc13591e44df85f73c539a_MD5.png]]

> 微信是否登录成功。
> 
> 消息有没有被接收到。
> 
> 有没有找到 Codex 窗口。
> 
> 任务有没有被转发。

小白最容易犯的错，就是凭感觉排错。

看日志慢一点，但不会把问题越修越乱。

![[笔记同步助手/images/05cc51e5cbdc5b4740954d65057f9db5_MD5.png]]  

## 几个容易卡住的地方

第一个：二维码扫了，但后面没有反应。

先等 10 到 20 秒，再看状态。第一次登录会生成凭据，不一定马上完成。

第二个：窗口隐藏后，不知道服务还在不在。

看状态，不要看桌面。后台服务本来就不应该一直占着你的屏幕。

第三个：微信消息到了，但 Codex 没动作。

先确认 Codex 桌面端有没有打开，并且是不是在你要操作的项目窗口里。桥接服务不是魔法，它需要有一个可接收任务的 Codex 环境。

第四个：PowerShell 不让跑 npm。

换 \`npm.cmd\`。别急着改系统执行策略，小白阶段少动系统设置。

## 安全边界要先立住

我建议你先只在自己的电脑上用。

不要把扫码二维码给别人。

不要在微信里发密码、密钥、银行卡、后台账号这些东西。

也不要让 Codex 执行你看不懂的危险命令。

这套流程会让手机和电脑之间多一条通道。方便是方便，但权限也跟着过来了。先把边界守住，后面用起来才踏实。

![[笔记同步助手/images/f906c4ba5720e0f47eba2dfc0741a835_MD5.png]]

## 先跑最小版，别贪多

别一上来就做自动回复、群聊分发、复杂任务队列。

先跑这个最小流程：

-   安装 \`wechat-acp@0.8.0\` 和 \`codex-acp@0.16.0\`。
    
-   双击 \`start-wechat-codex.cmd\`。
    
-   手机微信扫码登录。
    
-   查看状态，确认有 PID 和 token.json。
    
-   发一条测试消息。
    
-   看到消息进入 Codex 窗口。
    
-   再让它执行一个很小的任务。
    

这个跑通以后，再加后台隐藏、任务计划、定时检查、日志监控。

我现在做这类 AI 工作流，越来越不想一口吃成胖子。

先把一个小链路打通，让它稳定跑两天。它不掉线、不误触、不乱回，再继续往上加功能。

![[笔记同步助手/images/d3af09246a5480682d565effaa323c5d_MD5.png]]

这套东西跑通以后，感觉其实挺朴素：

微信发一句。

Codex 去干活。

中间这座桥，别断，就够了。
