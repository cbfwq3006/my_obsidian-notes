| 输入式笔记与输出式流程使用说明 |                                                            |                                          |                     |
|-----------------|------------------------------------------------------------|------------------------------------------|---------------------|
|                 |                                                            |                                          |                     |
| 模块              | 解决的问题                                                      | 使用方法                                     | 产出                  |
| 输入式笔记           | 我从文章或课程中学到了什么？                                             | 按“阅读/课堂区—理解区—心得区—应用区”整理，先准确理解，再建立联系。     | 核心观点、个人理解、知识链接、应用线索 |
| 输出式流程           | 下次遇到具体场景，我应该怎么做？                                           | 从应用场景出发，用GARS梳理目标、行动、结果和标准，并补充触发条件与卡点举措。 | 可直接执行的SOP、模板、清单     |
| 自检清单            | 这份笔记是否真正可用？                                                | 完成笔记后逐项检查；不要求机械打勾，重点检查能否产生行动和工作成果。       | 质量检查结果              |
| 原始提炼            | 保留最初思考过程                                                   | 用于回看你的原始理解，不覆盖、不丢失。                      | 原始记录                |
|                 |                                                            |                                          |                     |
| 核心原则            | 输入式笔记负责“学懂”，输出式流程负责“会用”。老师的模板用于质量自检，你的手写笔记用于形成具体行动，两者结合使用。 |                                          |                     |
