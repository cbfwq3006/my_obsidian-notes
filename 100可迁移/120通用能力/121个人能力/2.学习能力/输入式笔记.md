|                      | 输出式要点   | 流程笔记从应用场景出发，以工作流程为主线，把相关知识、工具和案例串联起来，并填入场景示例。                 | 真正的输出不是多写一遍知识，而是形成下次可以直接套用的流程。      | 党建工作大量依赖通知、方案、汇报、台账和检查，可用流程笔记降低重复劳动。  | 工作汇报、活动方案、支部指导、迎检和整改闭环。          |
| 《如何在不想学习的状态下继续学习》    | 阅读区     | 有意义的事情即使暂时不想做，也需要找到可持续完成的方法。文章借助福格行为模型，从动机、能力和触发条件三个方面解决启动困难。 | 不想学习不等于懒惰或意志薄弱，可能是动机不足、任务过难或缺少触发条件。 | 过去容易要求自己硬扛，失败后产生自责；用模型分析后，可以针对具体原因调整。 | 工作后疲惫但仍需学习政策、课程或准备考试的场景。         |
|                      | 理解区—动机  | 动机既有内部驱动，也可通过期待、奖励、进度反馈、同伴分享等方式增强。                            | 外部奖励不能替代内在意义，但可以帮助启动和维持阶段性行动。       | 完成小任务后打勾、记录进度、与同事分享收获，比单纯要求坚持更有效。     | 学习进度条、小任务奖励、学习分享、成果展示。           |
|                      | 理解区—能力  | 降低执行难度：拆分复杂任务、设定最小行动、不追求一次完成，顺应个人节奏逐步推进。                      | 很多“没有毅力”其实是任务颗粒度过大，第一步难到无法启动。       | 把“学完一门课”改为“打开课程—看10分钟—写3点—形成1项行动”。    | 党建材料写作、政策学习、课程学习、长期项目推进。         |
|                      | 理解区—触发  | 增加正向触发，减少负向触发。提前准备资料、固定学习地点和时间，利用社群或同伴提醒，同时减少手机和杂事干扰。         | 环境设计比临时依靠意志力更稳定；触发器要具体、可看见、可执行。     | 资料没准备好、手机消息不断，会显著提高启动成本。              | 资料预置、固定场所、日历提醒、同伴监督、关闭通知。        |
|                      | 心得区     | 遇到困难不先与自己对抗，而是拆开来看：是动机不足、能力不足，还是缺少触发？然后分别调整。                  | 用科学模型替代自责，把“我不行”改成“哪个条件没有满足”。       | 这一思路同样适用于工作拖延、材料写作和复杂任务推进。            | 形成“提动机—降难度—建触发—做最小行动—及时反馈”的启动流程。 |
