## 📊 详细尺寸标注

### 区域分配（总高160cm）

| 区域 | 高度 | 占比 | 用途 |
|------|------|------|------|
| 顶部标题栏 | 20cm | 12.5% | 品牌logo + 主题名称 |
| 主视觉区 | 60cm | 37.5% | 人物照片/工作场景 |
| 人物信息 | 15cm | 9.4% | 姓名/部门/职务 |
| 事迹展示 | 45cm | 28.1% | 3-4条核心事迹 |
| 底部标语 | 15cm | 9.4% | 企业文化口号 |
| 边距留白 | 5cm | 3.1% | 上下边距各2.5cm |

### 横向留白

- 左右边距：各3cm
- 有效内容宽度：70cm

## 🎨 色彩规范

### 主色调

```
■ 联通红   #E60012  (主题色、标题、装饰线)
■ 深灰色   #333333  (正文文字)
■ 纯白色   #FFFFFF  (背景、反白文字)
□ 浅灰色   #F5F5F5  (信息栏背景)
```

### 色彩分配

- **顶部标题栏**：联通红背景 + 白色文字
- **主视觉区**：照片原色
- **人物信息栏**：浅灰背景 + 深灰文字
- **事迹区**：白底 + 深灰文字 + 红色项目符号
- **底部标语**：白底 + 联通红大字

## 🔧 关键改进点

### ✅ 解决的问题

1. **中间空洞** → 改为照片+事迹分区，填充率提升至85%
2. **文字难读** → 字号放大2-3倍，5米外清晰可见
3. **层级混乱** → 明确的5段式布局，视觉路径清晰
4. **品牌弱化** → logo移至顶部，面积增大3倍
5. **装饰无关** → 红色斜线改为顶部和底部装饰带，与内容呼应

### ✨ 新增优势

- 照片区采用16:9横版，符合人眼阅读习惯
- 事迹用菱形符号(◆)，层次分明
- 姓名+部门单独成区，一眼锁定主角
- 底部双层标语，既有情感冲击又有文化内涵

## 🖼️ 制作建议

### 设计软件

- **推荐**：Adobe Illustrator（矢量，适合大尺寸输出）
- **备选**：CorelDRAW、Figma

### 输出规格

- **分辨率**：300 DPI
- **色彩模式**：CMYK（印刷）
- **文件格式**：PDF（印刷厂）/ AI（源文件）

### 材质建议

- **面板**：5mm PVC发泡板 或 铝塑板
- **工艺**：UV打印 + 亚光覆膜（防反光）
- **安装**：背面铝合金框架，膨胀螺栓固定

---

## 📌 注意事项

1. **照片要求**
   - 分辨率≥3000px宽
   - 人物清晰，背景简洁
   - 优先选择工作场景照

2. **文字校对**
   - 姓名、职务务必准确
   - 事迹数据需核实
   - 避免使用生僻字

3. **色彩校准**
   - 印刷前打样确认联通红色准确度
   - 注意材质反光对色彩的影响

4. **后期维护**
   - 预留更换内容的空间（考虑做成可拆卸海报框）
   - 定期清洁，保持整洁
