# 00 临时箱自动化工作流

## 自动链路

```text
微信文章
  → 笔记同步助手
  → 自动同步到 00 临时箱/
  → 当前用户登录后后台巡检
  → projects/00临时箱自动巡检队列.md
  → Codex 摄取
  → 整合稳定知识前先确认
```

## 当前配置

- 笔记同步助手目标目录：`00 临时箱`
- 自动同步间隔：`300` 秒，即 5 分钟
- Obsidian 启动时同步：已开启
- 临时箱巡检间隔：60 分钟，即每小时一次
- 巡检脚本：`scripts/scan_obsidian_temp_box.ps1`
- 后台 watcher：`scripts/watch_obsidian_temp_box.ps1`
- 当前用户登录自启动：启动文件夹中的 `Obsidian-TempBox-Watcher.vbs`
- 巡检结果：`projects/00临时箱自动巡检队列.md`
- 巡检状态：`projects/00临时箱自动巡检状态.json`
- 后台日志：`projects/00临时箱自动巡检.log`

> 当前设备的管理员策略阻止 PowerShell 立即启动子进程，因此安装时会创建启动器，但 watcher 将在下一次用户登录时启动。手动扫描不受影响。

## 安全边界

- 不删除或覆盖 `00 临时箱/` 原始文件。
- 不自动写入 `wiki/` 的稳定概念、实体或对比页。
- 不按标题臆造正文缺失文章。
- 已有来源页的文章不重复摄取。
- 需要整合到已有稳定知识页时，先向用户确认。

## 手动检查

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\scan_obsidian_temp_box.ps1
```

## 查看后台日志

```powershell
Get-Content .\projects\00临时箱自动巡检.log -Tail 30
```

## 关闭自动巡检

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\uninstall_obsidian_temp_box_watcher.ps1
```
