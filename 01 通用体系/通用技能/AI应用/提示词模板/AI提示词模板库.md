# AI 提示词模板库

> 对标课程方法论，可直接复制使用。把 `[括号内容]` 替换为你的真实信息后再发给 AI。
> **核心原则**：你负责判断、选择和创造；AI 只负责搜索、整理和结构化。

---

## T01：梳理知识漏洞（对标第七课）

```
我的角色是：【角色名，如"党建督导考核岗"】
当前面临的核心问题是：
1. 【问题1】
2. 【问题2】
3. 【问题3】

请帮我分析：
1. 解决每个问题，分别需要什么知识？（按 事实性/概念性/程序性 分类）
2. 我目前最缺的是哪一类知识？
3. 针对最缺的知识类型，推荐3个具体的学习资源。
```

---

## T02：制定学习计划（对标第八课）

```
基于我的角色【角色名】和面临的核心问题【列出问题】，
请帮我制定一个为期【X周】的学习计划：

1. 按优先级排序，列出我最需要学习的3个知识点
2. 为每个知识点推荐：
   - 输入型材料（书/课/文章）
   - 输出型材料（实践/教别人）
3. 帮我把时间分配好：哪些用系统性时间，哪些用碎片化时间
4. 给出具体的每周任务清单（细化到"周一晚上：读XX书第3章"）
```

## T03：筛选阅读内容（对标第九课·筛选）

```
我要解决的知识漏洞是：【具体描述】
请帮我快速筛选下面这段内容中，对解决我的问题最有价值的5%：

【粘贴内容或上传文件】

要求：
- 只保留能解决我问题的内容
- 用【】标注出关键步骤/模型/原理
```

---

## T04：粗加工提炼知识（对标第九课·粗加工）

```
我从【材料来源】中筛选出了以下内容，目标是学习【程序性/概念性/事实性知识】：
【粘贴筛选出的内容】

请帮我：
1. 提炼出所有的步骤/流程/模型/原理/数据
2. 按"事实性/概念性/程序性"三类分好
3. 用我自己的话重新表述一遍（不要照抄原文）
```

---

## T05：精加工深度理解（对标第九课·精加工）

```
我正在学习【知识点】，但理解还不够深。
请用以下方法帮我精加工：
1. 举3个生活中的具体例子（不要用抽象语言）
2. 和我已有的知识【列出已有知识】建立关联
3. 回答我的追问：
   - 为什么是这个概念而不是别的？
   - 为什么不【反例】也行？
   - 这个知识能用在哪里？不能用在哪？
```

---

## T06：沉淀知识（对标第十课）

```
我刚才学完了【知识点】，现在要沉淀到Obsidian仓库的以下位置：
路径：【如"02 角色体系/党建督导考核岗/专业知识/程序性知识/"】

请帮我把刚才的内容整理成Obsidian笔记，格式如下：
- 如果是程序性知识：用三栏表格（总步骤|细分步骤|应用体会）
- 如果是概念性知识：先给定义，再给模型图（用文字描述），最后给例子
- 如果是事实性知识：用列表整理关键数据/案例

要求：直接输出可复制的Markdown格式。
```

## T07：输出应用（对标第十一课·费曼学习法）

```
我学完了【知识点】，现在要检验是否真懂了。
请扮演【完全不懂这个领域的外行，如"一个12岁的孩子"】，
我来用最通俗的话解释这个知识，你听完之后问我问题，
直到你说"我真的懂了"为止。

知识点：【描述你要解释的知识】
```

---

## T08：复习测试（对标第十二课）

```
这是我的Obsidian知识库中的一份笔记内容：
【粘贴笔记内容，或告诉AI文件路径】

请基于这份笔记给我出3道测试题：
1. 一道考查记忆的（事实性/程序性步骤）
2. 一道考查理解的（概念性/原理）
3. 一道场景应用题（给我一个虚拟场景，让我用这个知识解决问题）

我回答完后，请你批改并告诉我哪里理解错了。
```

## T09：整理体系+迁移（对标第十三课）

```
这是我的【角色名】角色下的一份SOP（程序性知识）：
【粘贴SOP内容】

请帮我：
1. 把这个SOP中可抽象的部分提炼出来，形成更通用的"高级知识"
2. 这些"高级知识"可以迁移到哪些其他场景？（列出3个）
3. 把可以迁移的部分，建议我存入通用体系的哪个位置？
```

## T10：AI全流程辅助（对标第十四课）

```
我现在要【做某件事，如"准备下周一的党建考核汇报"】，
请全程用AI辅助我完成：

1. 【制定计划】帮我梳理做这件事需要哪些知识，我还缺什么？
2. 【输入知识】我等下会把相关资料发给你，帮我筛选出5%最有价值的内容，并提炼知识点
3. 【沉淀知识】学完后帮我整理成Obsidian笔记（按三类知识分好）
4. 【复习应用】帮我出一道场景题，我现场口述怎么用，你批改
```

---

## T11：持续迭代检查（对标第十五课）

```
这是我过去【X周/X月】用知识体系法学习的记录：
【粘贴你的周计划/复盘记录，或简单描述】

请帮我做三件事：
1. 我有没有"低质量重复"？（一直在舒适圈学习，没有触及真实问题）
2. 我的通用体系里，哪些能力是短板？
3. 下周我应该非功利性地学点什么？（推荐1-2个和我当前问题无关但可能有启发的方向）
```

## AI使用的三大陷阱（⚠️ 必读）

| 陷阱 | 表现 | 解法 |
|------|------|------|
| **过度依赖AI** | 把整本书丢给AI生成摘要就觉得自己"读完了" | AI帮你省掉的是体力活，不是脑力活。"判断这个知识值不值得学"、"这个SOP适合我的场景吗"——这些需要你亲自做 |
| **提示词太模糊** | 用"帮我总结一下"得到泛泛而谈的结果 | 提示词必须具体：你是谁（角色）、要什么（输出格式）、不要什么（剔除的东西） |
| **存了不回头看** | AI拆解得再好，存进知识库后再也不打开 | 事前翻牌 + 事后对照，是让知识体系活起来的唯一方法 |
