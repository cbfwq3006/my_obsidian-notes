**bash**

复制

```bash
cd ~/obsidian-content-capture-backend && /Users/abc/.workbuddy/binaries/python/versions/3.13.12/bin/python3 -m pip install --target=./deps requests flask zhconv
```

### 第二步：启动后端服务

**bash**

```bash
cd ~/obsidian-content-capture-backend && PYTHONPATH=./deps /Users/abc/.workbuddy/binaries/python/versions/3.13.12/bin/python3 web/app.py
```
