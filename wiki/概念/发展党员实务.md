# 发展党员实务

## 概念说明

发展党员实务是将党内法规要求转化为基层支部可执行的流程、材料、会议和审核清单。

重点关注积极分子、发展对象、预备党员、政审、档案、备案/同意/审批等节点。

## 2026-07-25 实务补充

### 拟列为发展对象的关键顺序

`听取意见 -> 支委会研究 -> 上级党委同意拟列 -> 公示不少于5个工作日 -> 公示结果不影响 -> 正式列为发展对象 -> 政治审查`

### 跨年度处理

- 不因上一年度已完成部分程序而自动简化下一年度流程。
- 重新核对发展计划、现实表现、培养考察、材料有效性和上级党委要求。
- 对“发展对象能否跨年”不作脱离具体制度和事实的绝对判断。

### 公示材料

除核对适用节点外，还应留存公示文本、起止时间、地点或渠道、意见受理方式和结果说明。地方或上级党委有更严格要求的，执行最新、更高要求。
