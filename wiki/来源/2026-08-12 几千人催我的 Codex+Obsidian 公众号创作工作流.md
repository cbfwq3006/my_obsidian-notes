# 几千人催我的 Codex+Obsidian 公众号创作工作流

> 发布时间：2026-08-05 16:58

## 核心观点

文章把公众号创作拆成标题、封面、排版、配图、发布和数据分析等环节，尝试用 `Codex + Obsidian` 建立从创作到复盘的闭环。

## 关键做法

- 以本地 Markdown 作为内容和知识资产的基础。
- 用 Obsidian 管理双链笔记、资料和 LLM Wiki。
- 让 Codex 读取知识库上下文，辅助标题、封面、配图、排版和发布准备。
- 从爆款封面、文章结构和已有内容中提取可复用提示词或模板。
- 通过开源工作流把个人创作经验转成可重复运行的流程。

## 可复用启发

- 内容生产适合拆成“素材—选题—写作—视觉—排版—发布—数据复盘”流水线。
- 本地 Markdown 让内容、知识库和 Agent 执行处于同一可追溯环境。
- 工作流开源的价值不只是一段 Prompt，而是目录结构、规则、模板和执行步骤的组合。

## 注意事项
