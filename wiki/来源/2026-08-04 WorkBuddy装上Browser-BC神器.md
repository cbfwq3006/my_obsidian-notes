# WorkBuddy装上Browser-BC神器

> 原文：[[00 临时箱/给 Workbuddy 装上 Browser-BC 神器，任何操作你录屏一遍就能蒸馏成 Skill]]
> 作者：YouCore
> 来源：微信公众号「YC思维与学习」
> 发布时间：2026-08-04

## 核心痛点

让 [[WorkBuddy]] 执行浏览器任务时的常见问题：
- 在页面之间来回横跳，陷入死循环
- 搜着搜着偏离最初意图
- 明明快接近答案了，却提前收手、草草交差

**最大痛点**：好不容易摸索通了，这点经验却随对话一起蒸发。下次换个任务，又从零开始。

## 传统方法的局限

| 方法 | 局限 |
|------|------|
| 写提示词 | 一次两次还行，操作一长就描述不清 |
| 装现成 Skill | 通用 Skill 和具体操作流程总有出入 |
| 用 Skill-creator | 会话里干扰信息太多，执行质量时好时坏 |

## Browser-BC 解决方案

### 核心能力

**不用写提示词，不用描述流程，你亲手在浏览器里把操作做一遍，它就自动学成一个 Skill。**

### 工具来源

Browser-BC 是 Einsia AI 旗下 Navers Lab 开源的"浏览器行为克隆"工具。

开源地址：`github.com/Einsia/Browser-BC`

### 与传统按键精灵的区别

| 维度 | 传统按键精灵 | Browser-BC |
|------|--------------|------------|
| 录制内容 | 坐标和按键序列：点(x1,y1)、输入"xxx"、点(x2,y2) | 语义级说明书：在搜索框填入关键词，回车，等列表加载后逐条点开 |
| 适应性 | 页面布局一改，整段脚本立刻作废 | 只保留"该做什么、怎么判断进展、怎么算完成" |
| 鲁棒性 | 脆弱，依赖精确坐标、DOM选择器、临时ID | 剥离脆弱细节，页面布局怎么变都能举一反三 |

### 工作流程

四步流程：**操作轨迹记录 → 能力提取 → 能力归桶 → 技能生成**

### 核心价值

**蒸馏和执行可以分开**

- 一次用强模型蒸馏好的技能
- 交给小模型、便宜模型也能执行

### 效果验证

研究团队在真实网站上验证：
- **任务成功率**：从 32.9% 提升到 68.4%
- **几乎翻倍**

## 安装方法

### 一句话安装

把这句话发给 WorkBuddy：

```
请帮我安装 Browser-BC 工具，源代码在 https://github.com/Einsia/Browser-BC，装好后验证一下能否运行。
```

WorkBuddy 会自动完成下载、安装。成功后，桌面会多出一个叫 **JourneyForge-Local** 的工具文件夹。

### 两步配置

#### 第一步：接入模型 API

Browser-BC 的蒸馏环节要单独对接一个大模型。

- 把已有的模型 API 信息发给 WorkBuddy
- 如：DeepSeek 开放平台的 API，模型选 `deepseek-v4-flash`
- WorkBuddy 会帮你写好适配器接进去

#### 第二步：加载 Chrome 浏览器扩展

1. Chrome 地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选中 JourneyForge-Local 里的 `extension/dist/chrome-mv3` 文件夹
5. 完成

> **安装失败原因**：大概率是网络访问不了 GitHub，换个网络环境或配好代理再试。

## 使用流程

三步上手：**亲手做一遍 → 自动蒸馏 → 一句话调用**

### 第一步：录制（1分钟）

1. 在浏览器右上角拼图图标里找到 Journey Forge Local 扩展，打开
2. 填一个 **Task name**（就是要生成的 Skill 的名字，如"B站自动点赞"）
3. 点 **Start recording**
4. 像平常一样在浏览器里把任务亲手做一遍
   - 搜索、点开、填表、点赞
   - 想让 Agent 以后怎么干，就怎么演示
5. 演示完点 **Stop**，再点 **Upload**

> **注意**：不用录很久，象征性做两三遍就够。录的是"怎么做成这件事"，不是"做了多少件事"。

### 第二步：蒸馏（自动进行）

1. 回到 WorkBuddy，告诉它"录制完成，已上传"
2. WorkBuddy 会去读取上传的轨迹
3. 交给大模型清洗、蒸馏
4. 几分钟内生成一份完整的 Skill，装进 Agent 的技能库

### 第三步：调用（以后随时）

下次只需说一句话：

```
用 B 站自动点赞的 Skill，帮我把这个搜索页的 AI 视频都点了赞
```

Agent 就会照着 Skill 的步骤执行，不用再教一遍。

## 三个实战案例

### 案例一：B站批量点赞

**录制**：
1. Task name 填"B站自动点赞"
2. 在 B 站搜索"AI 视频"
3. 挨个点开视频并点赞
4. 停止、上传

**调用**：
"帮我把搜索结果里的 AI 视频都点了赞"

Agent 会自动搜索、逐条点开、点赞。

### 案例二：订房网站找性价比最高的民宿

**任务**：在订房网站输入时间、地点、人数，按评分和评分数量筛选，排序找出最优选项。

**痛点**：小模型经常栽跟头
- 不知道怎么用网站的筛选功能
- 干脆幻觉编造一个结果

**效果**：人做一遍、蒸馏成技能卡后
- 小模型照着就能稳定完成
- 先写基本信息，再逐项应用筛选器
- 最后输出可人工核查的版本

### 案例三：每周重复的高频报表下载

**场景**：每周都要进某个 SaaS 后台，按月份点击导出报表。

**传统自动化痛点**："固定流程 + 登录 + 逐页点击"

**解决方案**：
1. 在浏览器里演示一遍「打开报表页 → 选月份 → 点导出 → 下载」
2. 蒸馏成 Skill
3. 以后每周一句话，Agent 自己进后台、点导出、存文件

### 朴素标准

**但凡你每周手动重复做一遍的浏览器操作，都值得花 5 分钟录一遍，蒸馏成一个永久 Skill。**

## 行动指南

5 分钟落地步骤：

| 步骤 | 时间 | 内容 |
|------|------|------|
| 第一步 | 1分钟 | 把安装指令发给 WorkBuddy，让它装好 Browser-BC |
| 第二步 | 1分钟 | 配置好模型 API，加载好 Chrome 扩展 |
| 第三步 | 2分钟 | 挑一个每天都要重复的浏览器操作，录一遍，上传 |
| 第四步 | 1分钟 | 回到 WorkBuddy，让 Skill 生成，用一句话验证 |

## 注意事项

### 优化建议

如果录制出来的 Skill 运行不理想，大概率是当前模型蒸馏质量一般。

**解决方案**：换个更强的大模型（如 GLM-5.2、Kimi K3）重新录一遍。

### 隐私保护

Skill 里不会夹带录屏时的隐私内容（账号、密码、具体数据），清洗阶段会自动剥离。

### 适应性强

录的是"门道"不是"脚本"，网站改版也不怕，Agent 会对着新页面举一反三。

## 核心理念

> "教 Agent 新技能不再靠'说'，而靠'做'。"

> "你亲手做一遍，就是最好的 Skill。"
