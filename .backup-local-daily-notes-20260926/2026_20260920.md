#  党建优秀成果交流会
通知

市直和省部属驻焦各单位党组织、县（市）区机关工委：

为学习贯彻市第十三次党代会精神，宣传推介各单位以高质量党建促进高质量发展的生动实践，激发机关党建创新活力和党员干部干事创业热情，推动机关党建工作整体提质增效，焦作市委直属机关工委决定举办“焦作机关党建优秀创新成果展示交流活动”。现将有关事项通知如下：

一、活动时间  
2026年9月22日（周二）下午15:30  

二、活动地点  
焦作广电台一号演播厅  

三、参加人员  
1. 特邀领导；  
2. 市委直属机关工委班子成员；  
3. 参加展示交流的9家单位主要领导；  
4. 市直和省部属驻焦各单位党组织常务副书记（分管领导）、专职副书记（科室负责人）和党员代表；  

备注：党委单位每单位参加5人（含分管领导和党建工作负责人）；总支、支部单位每单位参加2人。  

5. 11个县（市、区）工委分管领导和具体负责人。  

四、活动要求  
1. 活动15:30正式开始，15:00必须签到完毕。  
2. 因电视台1号演播厅内场地有限，请合理安排交通  

具。活动当天骑电动车前往的需将电动车统一停放至指定车棚位置，禁止停放在1号演播厅门口。  

3. 到场后，各单位专职副书记（党建工作负责人），代表单位到指定地点进行签到。  
4. 参加人员着装得体。  
5. 请提前熟悉座次图，签到后入场就座（座次图后期将发送“市直机关工委党建群”）。  

请各党组织务必于9月21日下午16:30前将《参会回执》（后附件）发送邮箱 jzsjggw@126.com。
