# 党建材料写作助手 Skill

> 基于你的 wiki 知识，快速生成符合规范的党建材料

---

## 目的

让党建材料写作从"每次从头写"变成"调用模板+填充内容"，提高效率和质量稳定性。

---

## 适用场景

### 1. 工作总结类
- 党建工作总结（月度/季度/年度）
- 党支部工作汇报
- 党建亮点材料

### 2. 典型宣传类
- 先进党组织事迹材料
- 优秀党员典型材料
- 党建品牌案例材料

### 3. 分析报告类
- 入党积极分子队伍分析
- 党员队伍现状分析
- 党建工作形势分析

### 4. 制度方案类
- 党建工作制度
- 主题活动方案
- 学习计划方案

---

## 核心方法：三层拔高法

> 来源：[[wiki/来源/2026-07-12 写材料不会拔高记住这3个层次就够了]]

### 第一层：陈述事实
**做了什么** - 罗列具体工作

### 第二层：说明方法
**怎么做的** - 工作措施和做法

### 第三层：提炼价值
**有什么意义** - 效果、价值、启示

---

## 执行流程

### Step 1：确定材料类型和要求（2分钟）

**AI 提问清单**：
```
请告诉我以下信息：

1. 材料类型：
   [ ] 工作总结
   [ ] 典型事迹
   [ ] 分析报告
   [ ] 制度方案

2. 时间范围：
   - 月度/季度/年度/专项

3. 字数要求：
   - 多少字左右

4. 报送对象：
   - 上级机关/内部使用/宣传推广

5. 核心内容：
   - 主要写什么工作/事迹/问题
```

---

### Step 2：收集素材（5分钟）

**AI 自动搜索**：
```bash
# 搜索相关工作记录
grep -r "党建" "素材库/" "2026/" --include="*.md"

# 搜索相关 wiki 知识
grep -r "关键词" "wiki/来源/" --include="*.md"
```

**人工补充**：
- 具体的工作数据
- 重要的会议活动
- 典型案例和事例

### Step 3：套用结构模板（15分钟）

#### 模板 1：党建工作总结

```markdown
# [单位名称][时间]党建工作总结

## 一、基本情况
[单位党组织基本情况：党员人数、支部设置、组织架构等]

## 二、主要工作及成效

### （一）[工作类别1]
**【事实层】做了什么**
- 具体工作1
- 具体工作2

**【方法层】怎么做的**
- 采取的措施和做法

**【价值层】效果和意义**
- 取得的成效
- 产生的价值

### （二）[工作类别2]
[同上结构]

### （三）[工作类别3]
[同上结构]

## 三、工作亮点

### 1. [亮点名称]
- **做法**：[创新举措]
- **效果**：[实际成效]
- **价值**：[推广意义]

### 2. [亮点名称]
[同上结构]

## 四、存在问题
1. [问题1]：[具体表现]
2. [问题2]：[具体表现]

## 五、下步打算
1. [措施1]：[具体做法]
2. [措施2]：[具体做法]
3. [措施3]：[具体做法]
```

---

#### 模板 2：先进典型事迹材料

2. 第二层（方法层）：提炼工作措施和做法
3. 第三层（价值层）：升华到效果、价值、意义

【参考知识】

### Step 5：党建话语规范检查（5分钟）

**检查清单**：

#### ✅ 政治正确性
- [ ] 涉及党的领导的表述是否准确
- [ ] 涉及党的理论的引用是否规范
- [ ] 是否符合当前政治要求

#### ✅ 用词规范性
- [ ] 党的机构名称是否准确（党委/党组/支部）
- [ ] 程序性用词是否规范（审批/同意/备案）
- [ ] 时间节点是否符合新细则要求

**参考知识**：
- [[wiki/概念/发展党员实务]]
- [[wiki/实体/中国共产党发展党员工作细则]]

#### ✅ 文风规范性
- [ ] 是否使用书面化表达
- [ ] 是否避免口语化、网络用语
- [ ] 是否符合公文写作规范

## AI 协作完整指令

复制以下指令使用：

```
我需要写一份党建材料，请按以下步骤帮我：

## Step 1：确认需求
材料类型：[工作总结/典型事迹/分析报告/制度方案]
时间范围：[XX]
字数要求：[XX字]
核心内容：[主要写什么]

## Step 2：搜索素材
请搜索我的以下目录：
- 素材库/01-工作实践/[时间范围]
- 2026/[相关文件]
- wiki/来源/[党建相关]

提取相关的：
- 具体工作事项
- 工作数据
- 典型案例

## Step 3：套用模板
使用 [[skills/党建材料写作助手]] 中对应的结构模板

## Step 4：三层拔高
参考 [[wiki/来源/2026-07-12 写材料不会拔高记住这3个层次就够了]]
对每个要点进行：事实→方法→价值 的提升

## Step 5：规范检查
检查：
- 政治表述是否准确
- 党建用词是否规范
- 文风是否符合要求

请开始执行，生成初稿。
```

- 坚持、加强、推进、深化、提升

- 组织、开展、举办、召开

### 工作形容（拔高）
- 扎实有效、有力有序、稳步推进
- 持续深化、不断提升、全面加强
- 精准发力、靶向施策、系统推进

### 效果表述
- 取得明显成效、形成良好态势
- 呈现新气象、迈上新台阶
- 得到充分肯定、产生积极影响

## 持续优化

### 第1次使用后
- 保存生成的材料作为案例
- 记录哪些部分需要人工调整
- 优化模板和话语库

### 第3次使用后
- 提炼你的个人风格
- 建立单位特色话语库
- 形成标准化流程

### 长期
- 把历次材料沉淀为案例库
- 建立分主题的模板库
- 实现"一键生成"级别的自动化
