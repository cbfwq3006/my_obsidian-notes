# 发展党员材料审核清单 Skill

> 基于2026版《中国共产党发展党员工作细则》，确保材料规范完整

---

## 目的

把发展党员材料审核从"经验判断"变成"清单核对"，避免遗漏和错误，提高审核效率和准确性。

---

## 适用场景

- 入党积极分子材料审核
- 发展对象材料审核
- 接收预备党员材料审核
- 预备党员转正材料审核
- 党员档案检查

## 审核清单 1：入党积极分子材料

### 必备材料清单

#### ✅ 基础材料
- [ ] **入党申请书**
  - 本人亲笔书写（或打字本人签名）
  - 日期明确（年月日）
  - 内容包含：入党动机、对党的认识、个人履历、家庭主要成员和主要社会关系情况
  
- [ ] **推荐材料**
  - 党员推荐或团组织推优材料
  - 推荐人签名、日期

- [ ] **党组织备案同意材料**
  - 党委（党组）备案同意的文件或记录

#### ✅ 培养考察材料
- [ ] **入党积极分子培养考察登记表**
  - 基本信息填写完整
  - 培养联系人签名、日期
  - 每季度考察意见（至少1年，4次）
  - 党支部意见、党委意见

- [ ] **思想汇报**
  - 至少每季度1篇（1年至少4篇）
  - 本人亲笔签名、日期

#### ✅ 培训材料
- [ ] **党校培训结业证书**（如已培训）

---

### 审核要点

#### 🔍 时间节点检查
- [ ] 入党申请书日期 → 确定为积极分子时间 ≥ 6个月
- [ ] 培养考察时间 ≥ 1年
- [ ] 每季度考察意见的时间间隔是否合理

#### 🔍 程序完整性
- [ ] 是否经过推荐
- [ ] 是否党委备案同意
- [ ] 是否确定培养联系人
- [ ] 培养联系人是否为正式党员

#### 🔍 内容规范性
- [ ] 考察意见是否具体（不能只写"表现良好"）
- [ ] 思想汇报是否结合实际（不能千篇一律）
- [ ] 签名是否齐全、真实

---

## 审核清单 2：发展对象材料

### 必备材料清单

#### ✅ 积极分子阶段材料（全部）
- [ ] 入党积极分子阶段的所有材料（见清单1）

#### ✅ 发展对象新增材料
- [ ] **政治审查材料**
  - 《政治审查综合报告》
  - 本人自传
  - 函调材料（必要时）
  - 重要社会关系证明材料

- [ ] **集中培训证明**
  - 党校发展对象培训结业证书
  - 培训时间不少于3天（或24学时）

- [ ] **党内外群众意见**
  - 座谈会记录或个别谈话记录
  - 至少3-5人意见

- [ ] **党支部研究意见**
  - 支委会（或支部大会）讨论记录

- [ ] **党委（党组）同意意见**
  - 党委会议记录或批复文件

---

### 审核要点

#### 🔍 时间节点检查
- [ ] 确定为积极分子 → 确定为发展对象 ≥ 1年
- [ ] 发展对象培训是否在发展对象确定后、发展前完成

#### 🔍 政审核心内容（重点）

> 参考：[[wiki/来源/2026-07-12 政审材料到底审什么很多支部没搞明白（附模板）]]

**审什么？**
1. **政治立场**
   - [ ] 对党的理论和路线方针政策的态度
   - [ ] 在重大政治问题上的表现和立场

2. **政治历史**
   - [ ] 是否参加过邪教组织、非法组织
   - [ ] 重大政治事件中的表现（如有）

3. **现实表现**
   - [ ] 遵纪守法情况
   - [ ] 道德品行
   - [ ] 工作表现

4. **主要社会关系**
   - [ ] 直系亲属（父母、配偶、子女）政治情况
   - [ ] 主要社会关系（岗位重要、影响大的）

**不能这样审**：
- ❌ 只看有无违法犯罪记录（范围太窄）
- ❌ 只调查直系亲属（应调查主要社会关系）
- ❌ 只调查现单位（应包括原单位、户籍地）

#### 🔍 程序完整性
- [ ] 是否党委同意（不是备案！）
- [ ] 是否经过公示（第一次公示）
- [ ] 公示时间不少于5个工作日

---

## 审核清单 3：接收预备党员材料

### 必备材料清单

#### ✅ 发展对象阶段材料（全部）
- [ ] 发展对象阶段的所有材料（见清单2）

#### ✅ 接收预备党员新增材料
- [ ] **入党志愿书**
  - 《中国共产党入党志愿书》（统一制式）
  - 本人填写，字迹清楚
  - 所有栏目填写完整
  - 介绍人意见（2名正式党员）
  - 支部大会决议
  - 党委审批意见

- [ ] **支部大会记录**
  - 有表决情况（赞成、反对、弃权人数）
  - 到会有表决权的正式党员人数
  - 参会人数 > 应到会人数的1/2
  - 赞成人数 > 应到会有表决权党员的1/2

- [ ] **预审材料**
  - 基层党委预审意见

- [ ] **谈话材料**
  - 上级党组织指派专人谈话情况记录
  - 谈话人签字

- [ ] **公示材料**
  - 第二次公示记录
  - 公示时间不少于5个工作日

---

### 审核要点

#### 🔍 时间节点检查（关键）
- [ ] 确定为发展对象 → 政治审查 → 短期集中培训 → 支部公示 → 支部大会 → 党委预审 → 上级谈话 → 党委审批
- [ ] 党委审批时间：支部上报之日起3个月内（最迟不超过6个月）

#### 🔍 入党志愿书填写检查
- [ ] **入党志愿**栏：本人亲笔填写，表达入党意愿
- [ ] **本人经历**：从小学或7岁开始填写，时间连续
- [ ] **家庭主要成员**：父母、配偶、子女
- [ ] **主要社会关系**：对本人影响大的亲属
- [ ] **本人签名**：真实、清晰

#### 🔍 介绍人意见检查
- [ ] 2名介绍人均为正式党员
- [ ] 意见具体、有针对性（不能千篇一律）
- [ ] 明确写"愿意介绍XX同志加入中国共产党"
- [ ] 介绍人签名、日期

#### 🔍 支部大会决议检查
- [ ] 写明应到、实到有表决权正式党员人数
- [ ] 写明赞成、反对、弃权人数
- [ ] 写明通过决议日期
- [ ] 支部书记签名

---

## 审核清单 4：预备党员转正材料

> 参考：[[wiki/来源/2026-07-12 预备党员的教育、考察和转正]]

### 必备材料清单

#### ✅ 转正申请材料
- [ ] **转正申请书**
  - 本人亲笔书写
  - 在预备期满前主动提出
  - 内容包括：预备期表现、存在不足、努力方向

- [ ] **预备党员考察表**
  - 每季度考察意见（4次）
  - 培养联系人或党小组意见
  - 党支部意见

- [ ] **思想汇报**
  - 预备期内至少每季度1篇（1年至少4篇）

#### ✅ 转正审批材料
- [ ] **党内外群众意见**
  - 征求意见记录

- [ ] **支部大会决议**
  - 表决情况

- [ ] **党委审批意见**
  - 审批时间不超过3个月

- [ ] **公示材料**
  - 第三次公示记录
  - 公示时间不少于5个工作日

---

### 审核要点

#### 🔍 时间节点检查
- [ ] 预备期为1年（从支部大会通过之日算起）
- [ ] 转正申请在预备期满前提出
- [ ] 党委审批在支部上报后3个月内

#### 🔍 考察内容检查
- [ ] 是否参加党的组织生活
- [ ] 是否履行党员义务
- [ ] 是否发挥先锋模范作用
- [ ] 是否按期交纳党费

#### 🔍 特殊情况处理
- [ ] 如延长预备期：写明延长理由、延长时间（6个月-1年）
- [ ] 如取消预备党员资格：写明具体原因

> 参考：[[wiki/来源/2026-07-12 根据最新党员发展细则党员档案里哪些材料必须有哪些可有可无赶快对照检查]]

### 必备材料（10项）

- [ ] 1. 入党申请书
- [ ] 2. 政治审查材料
- [ ] 3. 入党积极分子培养考察登记表
- [ ] 4. 发展对象集中培训结业证书
- [ ] 5. 党内外群众意见记录
- [ ] 6. 入党志愿书
- [ ] 7. 预备党员考察表
- [ ] 8. 转正申请书
- [ ] 9. 思想汇报（关键节点）

### 可有可无材料

- 自传（不是必须）
- 全部思想汇报（保留关键节点即可）
- 推荐材料复印件（原件在支部）
- 体检表、学历证明等（不属于党员档案）

## 常见问题速查

### Q1：党委备案、同意、审批有什么区别？

> 参考：[[wiki/来源/2026-07-12 发展党员小知识（43）：新《细则》中有"党委备案""党委同意""党委审批"等表述都是什么含义需要开党委会确认吗]]

| 用词 | 含义 | 是否必须开党委会 |
|------|------|---------------|
| **备案** | 报告知晓即可 | 否（书记圈阅即可） |
| **同意** | 需要明确表态 | 建议开（正式一点） |
| **审批** | 必须研究决定 | 是（必须开会） |

---

### Q2：公示要做几次？

- **第1次**：确定发展对象时
- **第2次**：接收预备党员前
- **第3次**：预备党员转正前

每次公示时间：不少于5个工作日

---

### Q3：政审函调什么情况下必须做？

**必须函调的情况**：
- 发展对象长期外地工作、学习
- 流动性大，现单位无法了解全貌
- 与海外机构或人员有密切联系
- 有其他需要进一步了解的问题

**不一定函调的情况**：
- 本地生本地工作，情况清楚
- 档案完整，历史清楚
