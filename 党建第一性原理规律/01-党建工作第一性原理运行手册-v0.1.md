# 党建工作第一性原理运行手册 v0.1

> 证据范围：`E:\2024`、`E:\2025`、`D:\work\2026`。本版依据三年目录结构、文件名、月份和代表性材料归纳，属于“待逐项核验”的阶段成果。

## 一、第一性原理

党建工作的底层不是“临近截止日期再做材料”，而是一个持续运行的闭环：

1. 上级要求进入：收文、会议、工作要点、临时通知。
2. 责任拆解：明确责任部门、支部、负责人、交付物和截止时间。
3. 组织实施：学习、会议、活动、调研、整改、培训。
4. 留痕取证：通知、签到、照片、记录、纪要、新闻稿、台账、成果。
5. 检查评价：月度自查、季度考核、年中督导、年度考核、巡察。
6. 整改复盘：问题清单、责任清单、整改台账、销号证明。
7. 归档复用：形成模板库、案例库和下一周期预提醒。

因此，每项工作都应至少管理六个要素：`触发条件、责任人、开始时间、截止时间、交付物、证据链`。

## 二、已确认的周期规律

### 每月固定工作

- 编制并下发当月主题党日学习内容。
- 编制支委会专题学习材料。
- 视安排召开党员大会、支委会，形成会议记录和影像资料。
- 更新党委会议纪要及相关“三重一大”材料。
- 收集各支部完成情况，检查通知、记录、签到、照片是否齐全。
- 对上月未完成事项催办并销号。

建议节奏：上月最后一周收集上级要求；每月1至3日形成学习包；5日前下发；20日前完成活动；25日前催收；月底归档。

### 每季度固定工作

- 制定季度党课或基本培训计划并组织实施。
- 汇总基层党支部日常管理考核材料。
- 盘点意识形态、党风廉政建设和反腐败工作情况。
- 检查党建与业务融合、议事决策清单、重点任务落实情况。
- 形成季度问题清单和下一季度行动项。

建议节奏：季度首月5日前定计划；第二个月开展中期检查；季度末月20日前收材料，25日前完成评价和整改清单。

### 年度固定工作

- 1月：上年度党建考核材料、自评报告、党费标准、培训统计、会议纪要归档。
- 1至3月：上年度组织生活会、民主评议党员、书记抓党建述职评议及问题整改台账。
- 3月：年度党建重点任务、精神文明建设重点任务、责任分解和考核指标。
- 5至7月：纪律教育、专题党课、“七一”表彰、评优评先、党课统计。
- 7至9月：年中督导、意识形态自查、党建任务完成情况复盘。
- 10至12月：四季度考核、年度党建考核迎检、书记述职、意识形态年度报告、培训工作报告、次年计划。

## 三、专项工作的触发规律

### 发展党员

触发条件：年度发展计划、人员递交申请、培养周期到点、上级统计通知。

动作链：需求统计 -> 申请人登记 -> 积极分子确定 -> 培养考察 -> 发展对象民主评议与政审 -> 预备党员接收 -> 教育考察 -> 转正 -> 全套材料归档。

关键原则：不能只设一个截止提醒，必须按个人培养时间轴设置多个节点提醒。

### 巡察与整改

触发条件：巡察通知、反馈意见、上轮整改复查、微巡察计划。

动作链：迎检清单 -> 资料责任分解 -> 问题底稿 -> 反馈部署会 -> 整改责任清单 -> 定期调度 -> 销号证明 -> 成果运用。

关键原则：收到巡察通知当天建立台账；每个问题必须同时保留整改动作与证明材料。

### 考核与述职

触发条件：考核要点下发、季度末、年度末、上级述职通知。

动作链：指标拆解 -> 责任到人 -> 日常收证 -> 预检查 -> 缺口补齐 -> 自评 -> 上报 -> 反馈整改。

关键原则：考核材料应在日常工作发生时归档，而不是年末集中补材料。

### 意识形态与精神文明

触发条件：季度分析、半年/年度报告、专项检查、重大节庆和宣传任务。

动作链：任务分解 -> 阵地检查 -> 活动实施 -> 风险研判 -> 情况报告 -> 资料归档。

## 四、工作台账标准字段

每项工作统一记录：

- 事项名称
- 工作类别
- 触发来源和原文链接/文件
- 周期类型：月度、季度、年度、临时
- 责任领导、责任部门、经办人
- 启动日期、内部截止、正式截止
- 前置依赖
- 交付物清单
- 证据材料清单
- 当前状态
- 风险和卡点
- 催办记录
- 归档位置
- 下一次触发日期

## 五、提醒设计原则

- 正式截止日前设置三层提醒：提前14天启动、提前7天检查、提前2天收口。
- 月度例行工作设置固定重复提醒。
- 发展党员、巡察整改等流程工作按节点提醒，不采用单一重复提醒。
- 会议类事项进入飞书日历；交付和催办类事项进入飞书任务。
- 所有提醒先进入候选清单，经确认时间后再创建。
