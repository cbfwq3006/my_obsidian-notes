# 事项SOP与证据链清单 v0.1

## 主题党日

流程：收集必学内容 -> 确定主题和形式 -> 编制学习包 -> 下发通知 -> 支部实施 -> 催收材料 -> 台账归档。

证据链：上级要求、正式通知、学习材料、签到、活动记录、照片、新闻稿、完成情况表。

## 支委会

流程：确定议题 -> 准备学习和研究材料 -> 召开会议 -> 形成记录 -> 落实决议事项 -> 归档。

证据链：议题清单、学习材料、会议记录、决议事项清单、落实证明。

## 党员大会

流程：明确议题和参会范围 -> 发通知 -> 准备主持词和材料 -> 召开 -> 表决或形成决议 -> 记录归档。

证据链：通知、议程、签到、主持词、会议记录、表决材料、照片、决议。

## 党课与培训

流程：制定计划 -> 确定讲授人和主题 -> 准备讲稿课件 -> 组织实施 -> 考勤或测试 -> 汇总统计。

证据链：计划、通知、讲稿、课件、签到、照片、学习记录、培训统计。

## 组织生活会与民主评议

流程：制定方案 -> 集中学习 -> 征求意见 -> 谈心谈话 -> 对照检查 -> 召开会议 -> 民主测评 -> 汇总结果 -> 整改。

证据链：通知方案、学习记录、意见清单、谈心谈话记录、对照检查材料、签到、会议记录、评议表、结果报告、整改清单。

## 发展党员

流程：申请入党 -> 确定积极分子 -> 培养考察 -> 确定发展对象 -> 政治审查和培训 -> 接收预备党员 -> 预备期考察 -> 转正。

证据链：各阶段会议记录、票决或评议材料、培养考察记录、政审、培训证明、公示、请示批复、志愿书。

## 党建考核

流程：拆解指标 -> 建证据目录 -> 日常收集 -> 季度自查 -> 年度预审 -> 自评上报 -> 反馈整改。

证据链：考核要点、责任分解、自评表、逐项证明材料、问题清单、整改报告。

## 书记抓党建述职

流程：收集履职数据 -> 梳理亮点 -> 对照问题 -> 分析原因 -> 制定措施 -> 审核上报 -> 评议整改。

证据链：述职通知、报告、成绩数据、问题依据、会议材料、评议结果、整改台账。

## 意识形态

流程：责任分解 -> 阵地管理 -> 风险研判 -> 专题研究 -> 半年/年度报告 -> 问题整改。

证据链：制度办法、责任清单、党委研究记录、风险研判记录、阵地检查、情况报告、整改材料。

## 巡察整改

流程：接收反馈 -> 分解问题 -> 制定措施 -> 定期调度 -> 收集证明 -> 审核销号 -> 成果运用。

证据链：反馈意见、部署会议、责任清单、整改台账、会议纪要、整改前后对比材料、销号审批、长效制度。

## 通用质量检查

- 文件中的日期、单位、姓名、职务一致。
- 通知、记录、照片和台账的时间逻辑一致。
- 会议人数满足规定，签到与记录相符。
- 问题、措施、责任人、截止时间一一对应。
- 电子版与盖章扫描版均可定位。
- 文件名包含年月、事项、单位和版本。
- 同一事项只有一个明确的最终版。
