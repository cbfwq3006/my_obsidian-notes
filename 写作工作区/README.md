# 写作工作区

> 建立"素材积累→思考加工→快速成文"的可持续写作系统

---

## 📁 文件夹说明

```
写作系统/
├── 素材库/
│   ├── 01-工作实践/        ← 工作中的问题、解决方案、案例
│   ├── 02-阅读笔记/        ← 好文章、书籍的关键观点
│   ├── 03-对话记录/        ← 有价值的对话内容
│   ├── 04-灵感闪念/        ← 随时冒出的想法
│   └── 05-数据事实/        ← 数据、案例、新闻事件
├── 写作工作区/
│   ├── 待加工素材/         ← 需要深度思考的素材
│   ├── 待写文章/          ← 已加工好的素材，准备成文
│   └── 已发布文章/         ← 完成并发布的文章
└── templates/
    ├── 每日素材收集.md      ← 每天5分钟素材记录
    ├── 素材加工模板.md      ← 深度思考，形成观点
    └── 文章草稿模板.md      ← 30分钟快速成文
```

---

## 🔄 工作流程

### 每日流程（5分钟）

1. 下班前打开 `templates/每日素材收集.md`
2. 填写今天的工作实践、触动观点、灵感闪念
3. 保存到 `素材库/` 对应分类

### 每周流程（1小时）

#### 周日上午（30分钟）：素材加工

1. 浏览本周素材，选3-5条有价值的
2. 使用 `templates/素材加工模板.md`
3. 用5Why追问 + 提炼独特视角
4. 保存到 `写作工作区/待写文章/`

#### 周日下午（30分钟）：快速成文

1. 选1个已加工的素材
2. 使用 `templates/文章草稿模板.md`
3. 先写骨架（10分钟）→ AI补充（10分钟）→ 人工优化（10分钟）
4. 保存到 `写作工作区/已发布文章/`

### 每月流程（30分钟）

1. 回顾本月文章
2. 提炼常用的写作模板
3. 更新 [[我的写作模板库]]

---

## ⚠️ 核心原则

### 1. 素材积累：先记录，不评判
- ❌ "这个好像没用，不记了"
- ✅ "先记下来，以后说不定能用"

### 2. 思考加工：深度来自追问
- ❌ 直接让AI写
- ✅ 先用5Why追问 + 形成独特视角

### 3. 快速成文：你是导演，AI是助手
- ❌ AI写什么我全盘接收
- ✅ 我定观点和结构，AI帮我扩写
