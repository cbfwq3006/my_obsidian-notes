# 我的写作模板库

> 从实践中提炼的常用写作结构，持续更新

---

## 模板1：问题分析型

**适用场景**：分析工作中的问题、社会现象

**结构**：
1. 引入：一个具体的场景/案例
2. 现象：这个问题普遍存在
3. 原因：用5Why分析根本原因
4. 方法：给出可执行的解决方案
5. 总结：升华到更高层次的思考

## 模板2：方法论分享型

**适用场景**：分享工作方法、思维模型

**结构**：
1. 痛点：大家都遇到的问题
2. 传统做法的局限
3. 我的新方法（3-5步）
4. 实际效果/案例
5. 注意事项

**示例文章**：
- [[示例文章2]]

---

## 模板3：观点表达型

**适用场景**：表达独特观点、反驳常见误解

**结构**：
1. 常见观点
2. 我的不同看法
3. 支撑论据（数据/案例/逻辑）
4. 反驳可能的质疑
5. 结论

## 模板4：案例拆解型

**适用场景**：分析成功/失败案例

**结构**：
1. 案例背景
2. 关键决策点
3. 为什么这样做（底层逻辑）
4. 可复用的方法
5. 适用边界

## 模板5：清单工具型

**适用场景**：提供实用清单、工具

**结构**：
1. 为什么需要这个清单
2. 清单的使用场景
3. 清单内容（分类展示）
4. 使用示例
5. 注意事项

## 如何提炼新模板

每完成3-5篇文章后：
1. 回顾文章结构
2. 提取共同模式
3. 总结为可复用模板
4. 添加到此文档
